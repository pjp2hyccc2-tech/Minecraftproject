# 霊撮 ―REISATSU―

Minecraft Java 版 **Forge 1.20.1** 用の、ステルス撮影ホラー MOD です。

> 十一月三日（火）、深夜。国道沿い、魔のカーブの手前に建つファミリーレストラン「ひだまり」。
> 深夜営業をやめてから、閉店作業の店員たちが同じことを言う。
> 鍵をかけた自動ドアが、チャイムと一緒にひとりでに開く。誰もいないのに水が流れている。
> テーブルのメニューが、朝には床に散らばっている。
>
> 霊媒師・八雲トキは、あなたに古いインスタントカメラ **霊写機** を手渡す。
> 「顔が写れば、余白に名前が浮かぶ。名前があれば、送ってやれる。……でも、急いではだめ」
> 七日間、毎晩。一晩に、ひとりずつ。
> ――ただし、**霊に気付かれてはいけない**。気付かれた霊は写真に写らない。そして、あなたを連れて行こうとする。

---

## 必要なもの

| | |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Forge | 47.x（47.3.0 で動作確認） |
| 影MOD（推奨） | **Oculus（1.20.1 版）＋ Embeddium**、または OptiFine<br>動作確認: Oculus 1.20.1-1.7.0 / Embeddium 0.3.31 |
| メモリ | 3GB 以上を推奨 |

影MODなしでも遊べます（MOD 側で夜の霧・暗がり・画面効果・フラッシュを描画します）。
影MODがあると、専用シェーダー **ReisatsuShaders** で、蛍光灯の明滅、濡れた駐車場の反射、鏡の向こう、
ファインダー越しの視界、フラッシュの光が本来の姿になります。

## 導入

1. `reisatsu-1.0.0.jar` を `.minecraft/mods` フォルダに入れる
2. 影を使う場合は Oculus と Embeddium も同じフォルダに入れる
3. 起動すると **ReisatsuShaders** が `shaderpacks` フォルダに自動で入り、ほかのシェーダーを選んでいなければ自動で有効になります
4. **部屋を暗くして、ヘッドホンで**。誰もいない店の冷蔵庫のうなり、時計の音、遠くの水音、
   そして呼び出しボタンの「ピンポーン」。音がいちばんの手がかりで、いちばんの恐怖です

## 演出（音と映像）

### 音
- 効果音・BGM の 262 ファイル（164 種）は、すべてこの MOD のために一から合成したものです。
- **部屋の響きと、壁の向こうの音**: OpenAL の EFX で、いる部屋に合わせて残響が変わります（タイル張りのトイレはよく響き、
  休憩室は吸われ、冷蔵室はほとんど響かない）。壁やドアの向こうで鳴った音は、こもって聞こえます。
  厨房の包丁の音は、通路からは鈍く、開いたスイングドアやデシャップ越しにははっきりと。
  （`config/reisatsu-client.toml` の `[sound] acoustics` で切り替え。Sound Physics Remastered が入っているときは自動で譲ります）
- 入店チャイム、呼び出しボタン、店内放送のチャイム、店内 BGM は、オリジナルのメロディです。閉店が近づくと、
  同じメロディが遅く、歪み、オルガンの短調に変わっていきます。
- 「いらっしゃいませ」「もういいかい」「みーつけた」「お客様……」――霊たちの声は合成音声を加工したものです（字幕付き）。
- 閉店後の店は静かです。冷蔵庫のうなり、時計の音、蛇口のしずく。その静けさが、呼び出しボタンの「ピンポーン」を怖くします。

### 映像（ReisatsuShaders）
- 雨上がりの駐車場: 濡れたアスファルトと水たまりに、看板・自動販売機・ナトリウム灯が映り込みます
- 店内: 緑の誘導灯、ドリンクバーとケーキケースの明かり、ブラインド越しの街灯。点けた蛍光灯は青白く、壊れたものは明滅します。
  床は明かりを映し、懐中電灯の光の中に埃が舞います
- 女子トイレの鏡は暗く、その奥に「鏡の向こう」が見えます
- 霊は半透明で、輪郭が青白くにじみます。肉眼ではほとんど見えないものも、ファインダー越しにははっきり写ります
- ファインダー: 古いカメラ越しの視界（粒子、周辺減光、わずかな歪み）。シャッターを切ると、フラッシュが一瞬だけ店内を照らします
- 恐怖が高まると視野が狭まり、色がにじみ、霊が迫ると画面が呼吸するように歪みます

影MODなしでも、MOD 側で霧・暗がり・画面効果・フラッシュを描きます。

## 始め方

- **新しいワールドを作って入ると、すぐに一日目の夜、「ひだまり」の駐車場から始まります**（オープニングのあと操作できます。2回目以降はスキップ可）。
  持ち物・場所・ゲームモードは保存され、七日目の夜が明けると元のワールドに戻ります。
- コマンド: `/reisatsu start`（開始）　`/reisatsu leave`（中断して元の場所へ）　`/reisatsu reset`（最初からやり直す）
- **セーブして終了すると、次に入ったときはその夜の最初から**やり直しです（撮った写真・メモ・残りのお札はそのまま）。
- 自動で始めたくない場合は `config/reisatsu-common.toml` の `autoStart = false`。

## 流れ ―七日間―

十一月三日（火）から九日（月）まで、七つの夜。毎晩、霊媒師の車のそばで目を開けると、画面に
「二日目の夜　十一月四日（水）」のような表題が浮かび、八雲さんがその夜の手がかりを話します（SPACE で飛ばせます）。
フィルムは毎晩 10 枚まで足しておいてくれます。店は毎晩、閉店作業のあとの状態に戻っています。

| 夜 | 日付 | すること |
|---|---|---|
| 一日目 | 十一月三日（火） | **観察の夜**。霊は現れず、何も写りません。店で起きる **霊障** を五種類、自分の目と耳で確かめる（左上「霊障を確かめる 0/5」）。確かめたら八雲さんのところへ |
| 二日目 | 十一月四日（水） | **来店者**。午前二時の合図のあと、扉がひとりでに開く |
| 三日目 | 十一月五日（木） | **給仕**。誰もいないテーブルのお冷や、暗がりの「いらっしゃいませ」 |
| 四日目 | 十一月六日（金） | **かくれんぼの子**。笑い声、散らばるメニュー――「もういいかい」 |
| 五日目 | 十一月七日（土） | **鏡の女**。女子トイレの水の音、すすり泣き |
| 六日目 | 十一月八日（日） | **料理長**。割れる皿、ひとりでに点く火、近づくと止む包丁の音 |
| 七日目 | 十一月九日（月） | **店長**。閉店の放送、点く照明、歪んだ店内音楽。最後の一枚のあと、除霊 |

二日目からは、その夜の霊ひとりだけが店にいます。ただし、すぐには姿を見せません。しばらく店の中にいて、
その霊の **異変（サイン）を二つ確かめると**、どこかに現れます（左上「異変を探る」→「〜を撮影する」）。
どこにいるのかを探し、気付かれずに顔を撮り、**写真を八雲さんに渡すと**、名前を読み、その人の話をして、
「おやすみなさい」――暗転して、次の夜へ。

見たもの・聞いたものが数えられるのは、**同じ部屋にいるか、それが見える場所にいるとき**（18 ブロック以内）。
数えられると左上に「記録：閉めたはずの自動ドアが開いた」のように出て、業務報告書の一覧にも印が付きます。
霊撮帳（J）の「七夜」のページに、それぞれの夜に誰を送ったかが残ります。

## 操作

| 操作 | 内容 |
|---|---|
| 右クリック（霊写機） | ファインダーを**構える／下ろす**。構えている間だけ見えるものがいる |
| 構えて**左クリック** | シャッター。フィルムを1枚使う。フラッシュが焚かれる |
| 構えて**ホイール** | ズーム（遠くの顔を大きく） |
| 右クリック（懐中電灯） | 点灯／消灯。**灯りは、あちらにも見える** |
| **スニーク** | 足音を殺す。扉やロッカーも静かに |
| **V（長押し）** | 息を止める。すぐそばにいるものに、呼吸を聞かれない。長くは続かない |
| **J** | 霊撮帳（撮った写真・集めたメモ・心得） |
| 右クリック | 調べる・拾う・扉・ロッカーに隠れる／出る・分電盤 |

## 霊撮の心得

> 一、霊に気付かれてはならない。気付かれた霊は、写真に写らない。
> 一、霊は光と音に敏い。灯りは控え、足音を殺すこと。
> 一、ファインダー越しにしか見えないものがいる。
> 一、顔が写らなければ、名は浮かばない。
> 一、気付かれたら、逃げなさい。隠れなさい。お札が身代わりになるのは三度まで。

写真は撮った瞬間にカメラから出てきて、ゆっくり現像されます。
**霊がこちらに気付いていない**、**顔がこちらを向いている**、**枠の中に収まっている**――そのとき余白に、赤く名前が浮かびます。
気付かれていれば、写るのは滲んだ影だけです。

## 画面の見かた

- 左上: その夜の目的（例:「霊障を確かめる 3/5」「異変を探る」「料理長を撮影する」「霊媒師のもとへ戻る」）。
  何かを確かめたときは、その下に「記録：……」
- 右下: 残りのフィルムとお札
- 画面中央の**目**: 近くの霊がどれだけあなたに気付いているか（閉じた目 → 半目 → 見開いた目 → 赤）
- ファインダーの中: 霊感計（針が振れるほど近い）、ズーム、残り枚数。霊が枠の中にいると円が赤くなる

## 店の中

客席、待合・レジ、厨房、冷蔵室、休憩室、事務所、倉庫、トイレ……。
**分電盤**で照明の回路を切り替えられます（明るいと見つけやすい。あなたも、あちらも）。
入口横の**鍵スイッチ**を店の鍵で回すと、自動ドアが動き出します。何が来ても、開きます。
休憩室のロッカーには隠れられます。入るところを見られていなければ、見つかりません。

フィルムは足りなくなります。店のどこかに、予備のフィルムパックがあります。

## 捕まると

顔。暗転。気がつくと駐車場で、八雲さんがお札を一枚燃やしています。その夜は、そのまま続きます。
お札は **七日間で三枚だけ**。捕まるたびに **霊障** が強まり、霊はあなたに気付きやすくなります。お札がなくなったら――。

## アイテム

| アイテム | 使い方 |
|---|---|
| 霊写機 | 構えて撮る。肉眼では見えないものが写る |
| フィルムパック | 右クリックで装填（+5枚） |
| 霊の写真 | 霊媒師に渡すと、名前を読み、その人の話をしてくれる |
| 懐中電灯 | 唯一の明かり。近くに何かいると、ちらつく |
| お札 | 捕まったとき、一度だけ身代わりになる（七日間で三枚） |

## 設定

`config/reisatsu-client.toml`

| 項目 | 内容 |
|---|---|
| `[accessibility] flashReduction` | 点滅・フラッシュ・グリッチを抑える（光過敏の方向け） |
| `[accessibility] jumpscares` | 全画面のジャンプスケア画像を表示する |
| `[accessibility] screenEffects` | 恐怖の画面効果（ビネット・ノイズ・揺れ）の強さ 0.0〜1.5 |
| `[shaders] installShaderPack` | ReisatsuShaders を自動で導入・選択する |
| `[sound] acoustics` | 部屋の残響と遮蔽（壁の向こうの音がこもる） |

`config/reisatsu-common.toml` の `[game]`: `spiritSpeed`（追ってくる速さ）、`awarenessRate`（気付かれる速さ）、`autoStart`

## 開発者向け

- 設計: `docs/DESIGN.md`。ソースは `src/main/java/com/reisatsu`（world / entity / game / client / ...）
- 夜の流れ: `game/Nights`（各夜の始まり・霊の出現・終わり・再開）、`game/Week`（暦と各霊のサイン）、`game/Director`（霊障と「確かめた」の判定）
- ビルドは GitHub Actions（`tools/ci.sh`）。CI ではサーバーの自動テスト（`debug/SelfTest`: 店の全チェック `WorldCheck` ＋
  偽プレイヤーによる七日間の通しプレイ: 一日目の霊障と判定、各夜のサイン→出現→撮影→手渡し、途中のセーブ＆再開、
  捕まって続く夜、閉店、お祓い、両エンディング）と、クライアントの自動撮影ツアー（`client/AutoShots`: オープニング、
  夜の表題、記録の表示、夜の終わり、店内全室、6体の霊、撮影、霊撮帳、捕まる、閉店、お祓い、エンディング）が走ります
- デバッグコマンド: `/reisatsu status`、`/reisatsu debug night <1..7>`（その夜の始まりへ。それまでの夜は済んだことに）、
  `/reisatsu debug manifest|talk|peaceful|fear|give|film|spawn|pose|face|awareness|validate|capture|caught|circuit|tp|event|noise|closing|exorcism|ending|skipintro`
- 言語ファイルは `tools/gen_lang.py` で生成（ja_jp / en_us）
