# 殺人喜 -SATSUJINKI- 【R18】

Minecraft **Java 1.20.1 / Forge 47.x** 用 MOD。あなたはデスゲームの主催者。集められた参加者（NPC）を、
巨大ミキサー・剣山プレス・回転ノコギリ・ギロチンで惨殺し、「喜」ポイントと殺戮ランクを稼ぐ。

> **R18：** 過激な暴力・流血・残酷表現を含みます。18歳未満はプレイできません。フィクションです。

## 導入
1. Forge 1.20.1（47.x）をインストール
2. `satsujinki-1.0.0.jar` を `.minecraft/mods/` に入れる
3. 起動 → R18 警告で「18歳以上です」を選ぶ

## 遊び方
- 初回ログイン時に **主催者セット** が配られる（端末・主催者の手・リモコン・各種罠キット・招待状）
- **処刑場設置キット** を地面に使う → 中央の **主催者端末** を右クリック → 人数を決めて **デスゲーム開始**
- 参加者は恐怖で逃げ惑い、命乞いし、ヤンキーやマッチョは殴りかかってくる
- **主催者の手**：右クリックでつかむ → もう一度右クリックで投げる（スニークでそっと落とす）
- 罠は右クリック／レッドストーン／**主催者リモコン**（スニーク＋右クリックでリンク）で起動
  - 大型ミキサー：放り込むとミンチ。血のスープが溜まりガラスが血塗れに
  - 剣山プレス：3×3の鉄板が剣山に叩きつけられ、ぺしゃんこに
  - 回転ノコギリ：上に立った者を真っ二つ
  - ギロチン：上に投げ込むと首枷で固定 → 起動で斬首、首が飛ぶ
  - 剣山：高所から落とすと串刺し
- 殺し方の種類・連殺（5秒以内）・ランク（D→C→B→A→S→SS→SSS「殺人喜」）で獲得ポイント倍増
- ポイントは端末の **購買** で罠や招待状に交換、**記録** で戦績確認

## コマンド
`/satsujinki start [人数]` `/satsujinki stop` `/satsujinki points <n>` `/satsujinki clean` `/satsujinki kit` `/satsujinki stats`

## 設定
`config/satsujinki-client.toml`（流血パーティクル量・画面の血・カメラ揺れ・吹き出し・R18警告・BGM）
`config/satsujinki-common.toml`（血痕ブロック・死体の残る時間・初期ポイント・制限時間 など）

## ビルド
JDK 17 で `./gradlew build` → `build/libs/satsujinki-1.0.0.jar`。
アセットは `tools/` のスクリプトで生成（`tools/art/*.py`, `tools/audio/gen_sounds.py`, `tools/gen_data.py`, `tools/gen_lang.py`）。
