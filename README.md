# 霊撮 ―REISATSU―

Minecraft Java 版 **Forge 1.20.1** 用の、ステルス撮影ホラー MOD です。

> 十一月二日、深夜。国道沿い、魔のカーブの手前に建つファミリーレストラン「ひだまり」。
> 深夜営業をやめてから、閉店作業の店員たちが同じことを言う。
> 鍵をかけた自動ドアが、チャイムと一緒にひとりでに開く。誰もいないのに水が流れている。
> テーブルのメニューが、朝には床に散らばっている。
>
> 霊媒師・八雲トキは、あなたに古いインスタントカメラ **霊写機** を手渡す。
> 「顔が写れば、余白に名前が浮かぶ。名前があれば、送ってやれる」
> ――ただし、**霊に気付かれてはいけない**。気付かれた霊は写真に写らない。そして、あなたを連れて行こうとする。

---

## 必要なもの

| | |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Forge | 47.x（47.3.0 で動作確認） |
| 影MOD（推奨） | **Oculus（1.20.1 版）＋ Embeddium**、または OptiFine |
| メモリ | 3GB 以上を推奨 |

影MODなしでも遊べます（MOD 側で夜の霧・暗がり・画面効果・フラッシュを描画します）。
影MODがあると、専用シェーダー **ReisatsuShaders** で、蛍光灯の明滅、濡れた駐車場の反射、鏡の向こう、
ファインダー越しの視界、フラッシュの光が本来の姿になります。

## 導入

1. `reisatsu-1.0.0.jar` を `.minecraft/mods` フォルダに入れる
2. 影を使う場合は Oculus と Embeddium も同じフォルダに入れる
3. 起動すると **ReisatsuShaders** が `shaderpacks` フォルダに自動で入り、ほかのシェーダーを選んでいなければ自動で有効になります
4. **部屋を暗くして、ヘッドホンで**。誰もいない店の冷蔵庫のうなり、時計の音、遠くの水音、
   そして呼び出しボタンの「ピンポーン」。音がいちばんの手がかりで、いちばんの恐怖です

## 始め方

- **新しいワールドを作って入ると、すぐに夜の「ひだまり」の駐車場から始まります**（オープニングのあと操作できます。2回目以降はスキップ可）。
  持ち物・場所・ゲームモードは保存され、夜が明けると元のワールドに戻ります。
- コマンド: `/reisatsu start`（開始）　`/reisatsu leave`（中断して元の場所へ）　`/reisatsu reset`（最初からやり直す）
- セーブして終了しても、次に入ったときは続きから再開します。
- 自動で始めたくない場合は `config/reisatsu-common.toml` の `autoStart = false`。

## 操作

| 操作 | 内容 |
|---|---|
| 右クリック（霊写機） | ファインダーを**構える／下ろす**。構えている間だけ見えるものがいる |
| 構えて**左クリック** | シャッター。フィルムを1枚使う。フラッシュが焚かれる |
| 構えて**ホイール** | ズーム（遠くの顔を大きく） |
| 右クリック（懐中電灯） | 点灯／消灯。**灯りは、あちらにも見える** |
| **スニーク** | 足音を殺す。扉やロッカーも静かに |
| **V（長押し）** | 息を止める。すぐそばにいるものに、呼吸を聞かれない。長くは続かない |
| **J** | 霊撮帳（撮った写真・集めたメモ・心得） |
| 右クリック | 調べる・拾う・扉・ロッカーに隠れる／出る・分電盤 |

## 霊撮の心得

> 一、霊に気付かれてはならない。気付かれた霊は、写真に写らない。
> 一、霊は光と音に敏い。灯りは控え、足音を殺すこと。
> 一、ファインダー越しにしか見えないものがいる。
> 一、顔が写らなければ、名は浮かばない。
> 一、気付かれたら、逃げなさい。隠れなさい。お札が身代わりになるのは三度まで。

写真は撮った瞬間にカメラから出てきて、ゆっくり現像されます。
**霊がこちらに気付いていない**、**顔がこちらを向いている**、**枠の中に収まっている**――そのとき余白に、赤く名前が浮かびます。
気付かれていれば、写るのは滲んだ影だけです。

## 画面の見かた

- 左上: いまの目的（例:「霊を撮影する 0/5」）
- 右下: 残りのフィルムとお札
- 画面中央の**目**: 近くの霊がどれだけあなたに気付いているか（閉じた目 → 半目 → 見開いた目 → 赤）
- ファインダーの中: 霊感計（針が振れるほど近い）、ズーム、残り枚数。霊が枠の中にいると円が赤くなる

## 店の中

客席、待合・レジ、厨房、冷蔵室、休憩室、事務所、倉庫、トイレ……。
**分電盤**で照明の回路を切り替えられます（明るいと見つけやすい。あなたも、あちらも）。
入口横の**鍵スイッチ**を店の鍵で回すと、自動ドアが動き出します。何が来ても、開きます。
休憩室のロッカーには隠れられます。入るところを見られていなければ、見つかりません。

フィルムは足りなくなります。店のどこかに、予備のフィルムパックがあります。

## 捕まると

顔。暗転。気がつくと駐車場で、八雲さんがお札を一枚燃やしています。
捕まるたびに **霊障** が強まり、霊はあなたに気付きやすくなります。お札がなくなったら――。

## アイテム

| アイテム | 使い方 |
|---|---|
| 霊写機 | 構えて撮る。肉眼では見えないものが写る |
| フィルムパック | 右クリックで装填（+5枚） |
| 霊の写真 | 霊媒師に渡すと、名前を読み、その人の話をしてくれる |
| 懐中電灯 | 唯一の明かり。近くに何かいると、ちらつく |
| お札 | 捕まったとき、一度だけ身代わりになる |
| 店の鍵 / 事務所の鍵 | 鍵スイッチと裏口 / 事務所の扉 |

## 設定

`config/reisatsu-client.toml`

| 項目 | 内容 |
|---|---|
| `flashReduction` | 点滅・フラッシュ・グリッチを抑える（光過敏の方向け） |
| `jumpscares` | 全画面のジャンプスケア画像を表示する |
| `screenEffects` | 恐怖の画面効果（ビネット・ノイズ・揺れ）の強さ 0.0〜1.5 |
| `installShaderPack` | ReisatsuShaders を自動で導入・選択する |
| `acoustics` | 部屋の残響と遮蔽（壁の向こうの音がこもる） |

`config/reisatsu-common.toml`: `spiritSpeed`（追ってくる速さ）、`awarenessRate`（気付かれる速さ）、`autoStart`

## 開発者向け

- 設計: `docs/DESIGN.md`。ソースは `src/main/java/com/reisatsu`（world / entity / game / client / ...）
- ビルドは GitHub Actions（`tools/ci.sh`）。CI ではサーバーの自動テスト（`debug/SelfTest`: 店の全チェック `WorldCheck` ＋
  偽プレイヤーによる一晩の通しプレイ）と、クライアントの自動撮影ツアー（`client/AutoShots`: オープニング、店内全室、
  6体の霊、撮影、霊撮帳、捕まる、閉店、お祓い、エンディング）が走ります
- デバッグコマンド: `/reisatsu status`、`/reisatsu debug peaceful|fear|give|film|spawn|pose|face|awareness|validate|capture|caught|circuit|tp|event|noise|closing|exorcism|ending|skipintro`
- 言語ファイルは `tools/gen_lang.py` で生成（ja_jp / en_us）
