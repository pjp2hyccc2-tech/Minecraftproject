# ETERNAL REALM

**14 DAYS TO ETERNITY.** — Minecraft Java Edition 1.20.1 / Forge 47.x 上で動く、オンライン・ファンタジーアクションRPG（MOD＋専用ディメンション）。

> 開発状況（0.6.0 作業中）: 企画書の主要システムを**すべて実装済み**。CI（ビルド・ユニットテスト約1060件・ヘッドレスサーバーの GameTest 122件）は合格。
> **実機クライアントでの目視・プレイ確認とマルチプレイ確認はまだ**です（見た目・音・手触りの調整が必要な箇所があり得ます）。
> 詳細は [docs/ROADMAP.md](docs/ROADMAP.md) と [docs/TEST_PLAN.md](docs/TEST_PLAN.md)。

## 遊べるもの

- **世界アストリア**: 専用ディメンション。王都アルセリアを中心に7地域（エルダーフォレスト、サンドリア砂漠、ノルディア雪原、ドラゴニア火山、
  セレスティア天空大陸、終焉の塔）が同心円状に広がり、24種のバイオームと14種の地形装飾。ボス撃破で次の地域が解放（シーズン単位）
- **6職業**: ナイト／アサシン／メイジ／レンジャー／プリースト／魔剣士。職業ごとに4スキル（スキルツリー・ポイント）、専用の衣装（職業衣装表示）
- **アクション戦闘**: 弱/強攻撃・コンボ・回避・ガード・パリィ・武器スキル・職業スキル。6武器種（片手剣・両手剣・双剣・槍・杖・弓）。
  **魔法と弓の攻撃は敵を押し返さない**（ノックバックなし。近接の攻撃は行動ごとの強さで押す）。
  **Z の武器スキルは武器ごとに固有の武技**（名品180・ティア武器42・ボス武器9。見た目・素材に合った形・効果・演出）。
  **全アクティブスキル（187）と必殺技（33）に派手な光の演出**（職業ごとの魔法陣・三日月の斬撃・属性の新星や火柱・落雷・空の魔法陣から降る矢、
  必殺技は巨大な光の剣・大十字・隕石・日蝕・九頭の蛇など専用のフィナーレ。魔法弾と矢は属性の光をまとって飛び、地面の領域は一生分光り、爆発は炸裂する。
  一人称・三人称どちらでも見やすく、設定 `combat.skillEffects` で切替）。
  狙うスキルは**長押しでロックオン**（狙った敵の縁が白く光り、離すとその敵へ）。闘技場以外では攻撃が他のプレイヤーをすり抜ける
- **レベル上限100**（サーバー設定 `character.maxLevel`）
- **装備**: 7ティア×10部位＝70種に加え、名品の武器180本（各武器種30）・ボス武器・ヌシ30体の武器・防具30セット。レア度5段階・付加効果・
  強化（+10）・厳選・製作。カバン（E）と装備画面（C、武器・防具4部位・アクセサリー2・お守り1）、拾った物は自動でカバンへ（拾得表示つき）。
  **レア度が高いほど特殊性能と武技が強く**（最大×1.30）、装備ごとに必要レベル（レア度で+0〜+5）
- **金枠の遺宝**: ダンジョンのボス・災厄・ヌシ・放浪する大物の64体から約0.1%で、その姿をかたどった武器・防具・アクセサリー・お守り（計448）。
  必ずレジェンダリーでその必要レベルで最強、金色の枠で表示され、落ちるとサーバー全員に告知
- **モンスター**: フィールドごとに13種＋強敵、ダンジョンのウェーブ、ボスの手下（計174種、うち100種は魔物図鑑の専用の見た目、
  145種が専用アニメーション付きの体）。Lv30以上と強敵は地面に予告の出る特技を使う。レベル帯・ドロップ表、LUKで良いドロップ。
  **フィールドの魔物は固定の生息地（157か所、2026-11-11 に広さ2倍）に湧く**: 2026-11-12 から**生息地の1.5倍の範囲に、以前の3.5倍の数**が現れ
  （1か所18〜46体。ほかの生息地の中心部・転移碑・王都・ヌシの縄張り・災厄の巣・ダンジョンの入口には湧かない）、魔物どうしは5ブロック以上離れ、
  こちらが攻撃するか**5ブロック以内に近づくと襲ってくる**（その少し外では振り向いてうなる）。弱い種ほど転移碑の近く、倒すと1〜2秒で戻る。世界地図に生息地（外側の薄い輪が湧く範囲）・レベル・落とし物
- **ヌシ（中ボス）30体**: 各フィールド3体のうち**同時に出るのは2体まで**。倒されなかったヌシは**20分ごとに消え**、休んでいた別のヌシが現れる
  （倒されたヌシは次の入れ替えまで出ない。戦闘中なら終わるまで待つ）。縄張りを歩き、特技3つ・仲間を呼ぶ・激昂、ボス戦と同じHPバーと戦功ランキング
- **フィールドの脅威**: 魔物を倒すと瘴気が溜まり、満ちると各フィールド専用の災厄ボス（10体）が顕現。放浪する大物（15体）が時々現れる
- **乗り物**: 王都の厩舎長から買う。月鬣の軍馬（Lv10、全力疾走の約2倍）・蒼翼のグリフォン（Lv30、空を飛べる）・
  星輪の魔導二輪（Lv50、軍馬の約1.5倍）に加えて、**馬5種・グリフォン5種の新しい品種**（それぞれ固有の特技）:
  花角の森跳び（Lv15、大跳躍）・潮鬣の海駆け（Lv20、水面を走る）・風羽の天馬（Lv25、滑空）・焔鬣の駿馬（Lv35、全力疾走が続くと加速）・
  聖角の白馬（Lv45、空中でもう一度跳ぶ）／金鬣のグリフォン（Lv35、地上も速い）・夜梟のグリフォン（Lv40、手を離しても高さを保つ）・
  嵐羽のグリフォン（Lv45、急降下で加速）・氷晶のグリフォン（Lv55、高く飛べる）・虚星のグリフォン（Lv65、最速の上昇と飛行）。
  U で呼ぶ／降りる、I で選ぶ。馬とグリフォンは1頭ずつ**個体差**（品種ごとに4つの毛色＋珍しい1色・たてがみや翼の形・
  個体値30〜100とグレードC〜SS）。厩舎長が並べる4頭から選び（並べ直しは値段の5%）、個体値は買ってから明かされる。
  **騎獣の証書**にして掲示板やオークションで売買できる（品種ごと）
- **転移碑55か所**: 各フィールドに5〜6か所。触れて記録し、記録した転移碑の間を移動できる（復活地点にもなる）
- **ダンジョン8つ＋最終レイド**: 自動生成のインスタンス（9テーマ）、ウェーブ・扉・ボス戦（予兆・フェーズ・シールド・召喚・激昂）、
  ノーマル/ハード/EX、タイムアタック
- **ボス34体**: ダンジョンのボス9体＋フィールドの災厄10体・放浪する大物15体。専用のアニメーション付きモデル。
  最終ボス「終焉の王」は10〜20人・4フェーズ（設定で少人数も可）。大勢で戦うボス（最終レイド・災厄・放浪する大物）のHPは1.5倍
- **ストーリー**: プロローグ〜全9章〜エンディング（スタッフロール）。地域カード、ボスの台詞、町の人々の会話が進行で変化
- **クエスト41件**: メイン・サイド・デイリー。クエスト受注はクエストNPCとの会話または冒険手帳
- **伝説の旅人（シングルプレイで仲間になる4人）**: かつてこの国を単独で護りきった **流離の魔女ロザリンド**、ドラゴンを鉄剣だけで退けた
  **竜退けの騎士ジークヴァルト**、全てのダンジョンEX級を踏破した唯一の存在 **踏破の魔剣士ケイレン**、疫病の王国を聖なる魔法で
  生き返らせた **救国のシスター・マリエル**。フィールドの生息地で戦い、王都の道具屋や宿にもいる。声をかけて誘うとパーティーに入り、
  どこへでも一緒に冒険する（4人同時も可）。肩書き通りの強さ（Lv100、魔物の攻撃はほとんど通らず、倒れても死なない）と、
  1人5つの技（通常攻撃2・スキル2・必殺1）を専用の高精細モデルのアニメーションと光の演出で（流星雨・千夜の天蓋、不動の誓い・
  竜退けの一閃、瞬閃・無尽剣界、癒しの聖域・王国再誕の祈り）（[docs/modules/travellers.md](docs/modules/travellers.md)）
- **町**: 道具屋・鍛冶屋・オークション会場・郵便・ギルド受付・門番（ダンジョン）など。王都の中では**ミニマップに町の人の役目のアイコンと名前**
  （依頼受付・道具屋・鍛冶屋など）が出る。お店や役所は内装を作り込み、2階のある建物は階段で上がれる
- **運河の王都**（2026-11-11 再建、城はそのまま）: 町を横切る**大運河**（太鼓橋・屋根付き橋・船着き場とボート・水門）、曲がりくねる路地と
  路地をまたぐ部屋の**旧市街**、宿屋**星灯りの館**、ガラスの丸天井の下に10軒の店が並ぶ**商店回廊**、市場の下の**地下**（運河から流れ込む
  滝・地下水路・密輸の船着き場・古い貯水槽・倉庫・本棚の隠し扉の奥の闇市。入口は運河の排水口・跳ね上げ戸・古井戸）。路地や運河に
  風に揺れる**飾り紐**（三角旗・洗濯物・提灯）、店の絵が描かれた**吊り看板**、水に浮かぶ**灯篭**
- **市場**: 王都のオークション会場に **取引掲示板**（固定価格。名前・分類・レア度・レベル・金枠で絞り込み、6通りの並び替え、
  出品画面に相場）と **オークション**（サーバー全体で同時に5件、待機列あり。入札・即決は O キーでどこのフィールドからでも、
  入札額は預かり・上回られたら即返金、終了間際の入札で延長、落札品と売上はオンラインならその場・オフラインならメールボックス）
- **宿屋の部屋（プレイヤーハウス）**: 星灯りの館の女将ロゼッタから部屋を借りる（1人1部屋）: 屋根裏部屋 1,000G・運河の見える部屋 5,000G・
  書斎の間 12,000G・星見の塔の部屋 25,000G・貴賓のスイート 50,000G。入れるのは借りた本人だけ。館の客室の扉（43枚）のどれからでも
  自分の部屋へ入り、部屋の扉から来た場所か王都へ戻る。主に荷物の置き場: 絵の札で分類できるチェスト、樽・書棚・防具立て・額縁、
  **仕分け机**（部屋の保管物すべての一覧・分類のタブ・名前の検索・取り出し・「全部しまう」で札どおりに片付け）。住み替え（中身は
  同じ名前の家具へ移る、差額払い／安い部屋なら差額の半分が戻る）と返却（空にして半額が戻る）
- **自室へ帰還**: Home キーか冒険手帳（K）の「自室」ボタン。3秒の詠唱（動く・攻撃を受けると中断）で世界のどこからでも自分の部屋へ。
  戦闘中・ダンジョンやレイド・ボス戦・対人戦・倒れている間は使えない。着いたあと60秒は再使用できない
- **パーティー（5人）/レイド（20人）・ギルド・ランキング（9部門）・シーズン（14日）・英雄の記録**
- **音楽と効果音**: 地域・ダンジョン・ボス・最終ボス・エンディングのオリジナル曲、ジングル、47種の効果音
- **シェーダー**: Oculus＋Embeddium とシェーダーパックで動作する前提の見た目（粒子・発光は標準の描画経路のみ使用）

## 操作（初期設定）

| キー | 内容 |
|---|---|
| 左クリック / R | 弱攻撃（コンボ） / 強攻撃（長押しで溜め） |
| 右クリック長押し | ガード（タイミングよく受けるとパリィ） |
| 左Alt | 回避 |
| Z | 武器スキル（武器ごとの武技） |
| V / G / B / H / N / J | 職業スキル1〜6（H は必殺技） |
| （スキルキー長押し） | 狙うスキルのロックオン: 照準に近い敵の縁が白く光り、離すとその敵へ撃つ（短押し・範囲攻撃はすぐ発動） |
| 1 / 2 / 3 | クイック使用: 回復薬（足りない分に合う大きさを自動で選ぶ）／スタミナトニック／帰還の巻物 |
| E / C | カバン / 装備（画面右下のアイコン。キーはアイコンの右下に表示） |
| K | 冒険手帳（ステータス・職業・スキル・クエスト・パーティー・ギルド・ランキング） |
| O | オークション会場（どこからでも入札・即決。出品の登録と開始は王都の会場で） |
| M | 世界地図（ドラッグで移動・ホイールで拡大縮小） |
| U / I | 乗り物を呼ぶ・降りる / 乗り物を選ぶ（乗っている間: Space でジャンプ（グリフォンは上昇）、スニークで降りる（グリフォンは空中で下降）） |
| Home | 自室へ帰還（3秒の詠唱。もう一度押すとやめる。冒険手帳の「自室」ボタンでも同じ） |
| Y / = / - | ミニマップの表示切替 / 拡大 / 縮小 |
| クリック / Space / Enter | NPCとの会話を進める（Esc で飛ばす） |
| Enter | 画面上部の会話ボックスを進める |

**画面（HUD）**: バニラのホットバー・ハート・満腹度・経験値バーは使いません。左上に自分の枠（Lv・名前・HP・EXP・状態効果）と
パーティー、上中央にボス、右上にミニマップと脅威、下中央にスキルとクイック使用、右下に装備とカバン（乗り物を持てばその左に乗り物）。どの画面サイズでも重ならない配置です。
手に持つのは常に装備中の武器（インベントリの1枠目）。**空腹はなく、HPは自然に回復しません**（回復は回復薬・回復スキル）。
クリエイティブ／スペクテイターではバニラの表示に戻ります。

キー割り当てはオプション → 操作設定 → ETERNAL REALM で変更できます。

## 主なコマンド

- `/party invite|accept|leave|raid|...`, `/p <メッセージ>` — パーティー
- `/guild create <タグ> <名前>|invite|accept|leave|...`, `/g <メッセージ>` — ギルド
- `/auction`（オークション会場を開く。O キーと同じ）, `/mail`（メールボックス）。出品は王都のオークション会場の競売係から開く掲示板・会場の画面で
- `/dungeon leave` — ダンジョンから離脱
- `/ranking [部門]`, `/season`
- `/eternalrealm outfit job|tier` — 防具を職業衣装／装備本来の外見で表示
- 管理者: `/eternalrealm setup town`（アストリアのない世界で町のNPCを配置）, `/er admin ...`
- テスト用（管理者）: `/er admin test all [プレイヤー]` — Lv・所持金を上限に、ステータスとスキルのポイントをすべて未使用で最大に、
  宿屋の客室5室とギルドハウス20軒をすべて見学できるように開放（女将の「見学」、ギルド門の広場の門、`/er admin test tour <room|guild> <間取り>`）。
  `max` / `unlock` / `lock` / `status` で個別に（[docs/modules/testkit.md](docs/modules/testkit.md)）
- テストボット（管理者）: `/er admin bots spawn [数]`（既定 30）— 本物のプレイヤーとしてログインする単色の AI。職業に就き、
  道具屋で売り買いし、宿で休み、パーティを組んで Lv に合う生息地で狩りをする。`list` / `send <town|shop|inn|hunt|return>` /
  `chat on|off` / `remove`（ログアウト）/ `purge`（部屋とランキングの記録も片づける）（[docs/modules/testkit.md](docs/modules/testkit.md) §4）

## 導入

1. Minecraft 1.20.1 + Forge 47.x（CurseForge のプロファイルなど）
2. `eternalrealm-<版>.jar` を `mods` フォルダへ
3. （任意）影MOD: CurseForge で **Oculus** と **Embeddium** を追加し、シェーダーパック（例: Complementary Shaders、BSL）を `shaderpacks` に入れる
4. サーバー設定: `config/eternalrealm-server.toml`（シーズン、モンスター出現、`keepInventory`、少人数でのダンジョン `ignorePartySize` など）

## ビルド

```bash
./gradlew build                 # コンパイル + ユニットテスト + build/libs/eternalrealm-<版>.jar
./gradlew runGameTestServer     # ヘッドレスサーバーでMODを起動し、ゲーム内テストを実行
./gradlew runClient             # 開発用クライアント
```

ネットワークが制限された環境では、Minecraft非依存部分だけを `tools/offline-test.sh` でコンパイル・テストできます。
アート・音楽・ワールド生成データは `tools/art`, `tools/art_entities`, `tools/audio`, `tools/gen-worldgen-data.py` などの生成スクリプトで再生成できます（出力は毎回同一）。
