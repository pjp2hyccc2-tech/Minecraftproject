# 冥婚 ―MEIKON―

Minecraft Java 版 **Forge 1.20.1** 用の、攻略型・和風ホラー MOD です。

> 大正の山奥、婚礼の前夜に白無垢のまま死んだ娘・小夜（さよ）。
> あなたの名が書かれた「赤い封筒」――冥婚の招待状を開いた瞬間、
> 永遠に明けない夜の屋敷「隠り世（かくりよ）」へ引きずり込まれる。
> 嫁入り行列の **七つの鈴** を集め、中庭の **縁切りの鳥居** で鳴らせ。
> 花嫁に、見つかる前に。

---

## 必要なもの

| | |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Forge | 47.x（47.3.0 で動作確認） |
| 影MOD（推奨） | **Oculus（1.20.1 版）＋ Embeddium**、または OptiFine<br>動作確認: Oculus 1.20.1-1.7.0 / Embeddium 0.3.31 |
| メモリ | 3GB 以上を推奨 |

影MODなしでも遊べます（MOD 側で専用の空・霧・明かりを描画します）。

## 導入

1. `meikon-1.0.0.jar` を `.minecraft/mods` フォルダに入れる
2. 影を使う場合は Oculus と Embeddium も同じフォルダに入れる
3. 起動すると、専用シェーダー **MeikonShaders** が `shaderpacks` フォルダに自動で入ります。
   ほかのシェーダーを選んでいなければ自動で有効になります。
   なっていなければ「設定 → ビデオ設定 → シェーダーパック」で `MeikonShaders` を選んでください。
4. 部屋を暗くし、**ヘッドホン**で遊んでください。音で花嫁の位置がわかります。

## 始め方

- ワールドに入ると足元に **赤い封筒** が届きます。右クリックで開き、「封を切り、中へ入る」。
- コマンドでも開始できます: `/meikon start`
- 途中でやめるとき: `/meikon leave`（元の場所・持ち物・ゲームモードに戻ります）
- セーブして終了しても、次に入ったときは続きから再開します。

## 操作

| 操作 | 内容 |
|---|---|
| 右クリック | 提灯を灯す／消す、調べる、扉、拾う、押入れに入る |
| ダッシュ | 速いが**足音が響く**。スタミナが尽きると荒い息で居場所がばれる。鈴を持って走ると鈴が鳴る |
| スニーク | 足音を殺す。**押入れの中では Shift 長押しで息を止める**（長くは続かない） |
| J キー | 拾った手記を読み返す |
| 鈴を持って右クリック長押し | 鳥居の前で、縁切りの儀式（七つ揃ってから） |

## アイテム

| アイテム | 使い方 |
|---|---|
| 提灯 | 唯一の灯り。油が減っていく。灯すと遠くから**見つかりやすく**、消すと**影が寄ってくる** |
| 菜種油 | 提灯に油を足す |
| 鈴 | 七つ集めて鳥居で鳴らす |
| 清め塩 | 投げつけると花嫁を一度退ける。床に使えば盛り塩（しばらく通れない） |
| 護符 | 持っていれば、捕まったとき一度だけ身代わりになる |
| おはじき | 投げると落ちた場所で音が鳴り、花嫁を誘える |
| 燐寸 | 燭台・行灯に火を灯す |
| 蔵の鍵／人形の首／手記 | 謎解きに使う。手記にはヒントが書かれている |
| お守り | 持っていると恐怖が和らぐ |

## 攻略のヒント（軽いネタバレ）

- 最初の部屋（灯明の間）は安全です。ここには花嫁も入ってこられません。
- 鼻歌（かごめかごめ）が聞こえたら、花嫁は近くを歩いています。
- 恐怖度が上がりすぎると、あなたの荒い呼吸を花嫁に聞かれます。明かりの下で落ち着いて。
- 押入れに**入るところを見られたら**、戸を開けられます。
- 市松人形は、**見ている間は動きません**。
- 影法師は提灯の光に弱い。
- 鈴は 3 つが部屋の鈴台に。残り 4 つは蔵・仏間（燭台を灯す順番）・人形の間・中庭の井戸。
- 鈴が増えるほど屋敷は変わっていきます。七つ目を取ったら、鳥居まで走れ。
- 結末は二つあります。婚礼の間の盃には、気をつけて。

## 設定（config フォルダ）

`meikon-common.toml`

| 項目 | 既定値 | 内容 |
|---|---|---|
| `brideSpeed` | 1.0 | 花嫁の速さ（0.6 で易しく、1.3 で難しく） |
| `fearRate` | 1.0 | 恐怖度の上がりやすさ |
| `giveEnvelope` | true | 初参加時に赤い封筒を配る |

`meikon-client.toml`

| 項目 | 既定値 | 内容 |
|---|---|---|
| `flashReduction` | false | 点滅・グリッチ演出を抑える（光過敏の方は true に） |
| `jumpscares` | true | 全画面のジャンプスケア画像 |
| `screenEffects` | 1.0 | 恐怖演出（周辺減光・ノイズ・揺れ）の強さ |
| `installShaderPack` | true | MeikonShaders を自動で導入・選択する |

## 注意

- **大きな音・突然の画面演出（ジャンプスケア）・点滅表現**があります。
- 屋敷の中では体力・空腹は減りません。捕まると灯明の間で目を覚まします（集めた鈴は残ります）。
- 隠り世ではブロックの破壊・設置はできません（アドベンチャーモード）。
