# ひとりかくれんぼ ―HITORI KAKURENBO―

Minecraft Java 版 **Forge 1.20.1** 用の、一人称ホラー MOD です。

> 十一月三日（火）、午前二時二十分。小雨。
> 築五十年の木造アパート「コーポ白樺」二〇三号室で、あなたはひとりで暮らしている。
> 古い掲示板のスレッドを印刷した。【検証】ひとりかくれんぼ やり方まとめ【閲覧注意】。
> 実況していた人たちのように、アクションカメラで部屋を撮りながらやってみることにした。
>
> ぬいぐるみの綿を抜いて、米と、自分の爪を詰める。赤い糸で縫って、名前をつける。
> 午前三時。「最初の鬼は、わたしだから」。
> ――そして塩水を口に含んで、押し入れに隠れる。
> ノートパソコンの画面には、誰もいないはずの、あなたの部屋が映っている。

---

## 必要なもの

| | |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Forge | 47.x（47.3.0 で動作確認） |
| 影MOD（推奨） | **Oculus（1.20.1 版）＋ Embeddium**、または OptiFine |
| メモリ | 3GB 以上を推奨 |

影MODなしでも遊べます（MOD 側で暗がり・霧・画面効果・カメラの赤外線映像を描きます）。

## 導入

1. `hitori-1.0.0.jar` を `.minecraft/mods` フォルダに入れる
2. 影を使う場合は Oculus と Embeddium も同じフォルダに入れる
3. 起動すると専用シェーダー **HitoriShaders** が `shaderpacks` フォルダに自動で入り、ほかのシェーダーを選んでいなければ自動で有効になります
   （`config/hitori-client.toml` の `installShaderPack = false` で止められます）
4. **部屋を暗くして、ヘッドホンで**。いちばん怖いのは、押し入れの中で聞く音です

## 始め方

- **新しいワールドを作って入ると、すぐに二〇三号室の洋室、午前二時二十分から始まります**（オープニングのあと操作できます。二回目以降は短くなります）。
  持ち物・場所・ゲームモードは保存され、夜が終わると元のワールドの元の場所に戻ります。
- **セーブして終了しても、次に入ったときは同じ夜の同じところから**続きます（押し入れに隠れていたなら押し入れの中から。人形もそのまま）。
- コマンド: `/hitori start`（開始）　`/hitori leave`（中断して元の場所へ）　`/hitori reset`（夜を最初から）　`/hitori status`
- 自動で始めたくない場合は `config/hitori-common.toml` の `autoStart = false`。

## 流れ

手順は、机の上の **印刷した手順書**（**J** でいつでも読めます）のとおりです。どの手順も、部屋の中で実際にやります。
左上に「次：米を詰める」のように今の手順が出て、手順書のチェックリストに印が付いていきます。

**準備（午前二時二十分から。三時までは時計が速く進みます）**

| | 手順 | どこで・何を |
|---|---|---|
| 1 | 人形を用意する | 洋室の棚のぬいぐるみ（白いうさぎ） |
| 2 | 綿を抜く | 机の裁縫箱のはさみで、和室のちゃぶ台の上で |
| 3 | 米を詰める | DK の米袋 |
| 4 | 爪を入れる | 脱衣所の鏡の棚の爪切り |
| 5 | 赤い糸で縫う | 裁縫箱の赤い糸。余りはぐるぐる巻きつける |
| 6 | 風呂に水を張る | 浴室の蛇口（少し時間がかかります） |
| 7 | 塩水を用意する | DK の塩を、流しでくんだコップの水に |
| 8 | 定点カメラを置く | 洋室のカメラバッグから。好きな場所に最大4台（手順書のおすすめ：浴槽、廊下、和室、玄関）。ノートパソコンで映りを確かめる |
| 9 | テレビをつける | 和室のブラウン管テレビ。砂嵐 |

**儀式（午前三時ちょうどに）**

| | 手順 |
|---|---|
| 10 | 人形に名前をつける（最初は「みーちゃん」） |
| 11 | 人形を持って「最初の鬼は（自分の名前）だから」と三回言う（**R**） |
| 12 | 人形を水を張った浴槽に入れる |
| 13 | 家中の電気を消す（各部屋のスイッチ、または玄関のブレーカー）。テレビはつけたまま |
| 14 | テレビの前で目を閉じ、十数える（**R**） |
| 15 | 包丁を持って浴室へ行く |
| 16 | 「〇〇みつけた」と言って、刺す |
| 17 | 「次は〇〇が鬼だから」と言って、その場を離れる（**R**） |
| 18 | 塩水を口に含み、押し入れに隠れる |

**隠れる**：人形が **鬼** になって、部屋を探しはじめます。押し入れの中からノートパソコンで定点カメラの映像を見て、
ふすまの隙間から覗き、息を殺し、耳を澄ませてください。

**終わらせ方**：塩水を口に含んだまま押し入れを出て、人形を探し（もう浴槽にはいません。カメラで探す）、
**塩水を吹きかけ**（**R**）、「私の勝ち」と三回言い（**R**）、人形を持って、**流しか、水を抜いた浴槽で燃やす**（ライターは DK の引き出し）。

## 操作

| 操作 | 内容 |
|---|---|
| 右クリック | 使う・調べる・拾う（切る、詰める、縫う、カメラを置く、スイッチ、扉、押し入れに入る／出る、刺す、火をつける） |
| **R** | 儀式の言葉を言う／数える／塩水を吹きかける（その場に合わせて） |
| **V（長押し）** | 息を止める。呼吸の音が消える。長くは続かない（塩水も少しずつ減る） |
| **C** | カメラアプリ（ノートパソコンかスマホを持っているとき。押し入れの中でも） |
| **J** | 手順書（手順・チェックリスト・守ること） |
| スニーク | 足音を殺す。ふすまも静かに開け閉めする |
| スニーク＋右クリック（カメラ） | 置いたカメラを回収する（三時まで） |
| 右クリック（スマホ） | スマホの画面（カメラ・ライト・マナーモード）。着信中は電話に出る／スニーク＋右クリックでライト |

### カメラアプリ
画面がそのカメラの映像に切り替わります（体は今いる場所のまま）。**1〜4 / A・D** でカメラを切り替え、**右クリック・ESC・C** で閉じます。
暗い部屋は赤外線のモノクロ映像になり、聞こえる音もそのカメラのマイクの音になります（自分のすぐそばの音は、こもって聞こえます）。
カメラ越しに見る人形は、コマ落としのようにぎこちなく動きます。**自分の目で見ている間は、動きません**。
映像は録画されていて、ちゃんと終わらせた翌日の午後、ノートパソコンで見返すことになります。

### 押し入れ
ふすまを右クリックして入ります。中は暗く、狭く、ふすまの隙間から細い光が入ってきます。

- **覗く**：ふすまの方を向いて **右クリック長押し**。ふすまが少しだけ開き、隙間から和室が見えます。小さな音がして、**光が動く**
- **出る**：右クリック（ふすまを開ける音がします）
- 隠れていれば姿は見られません。人形は **音** で探します。呼吸、あえぎ、スマホの振動、身動き、覗くときのふすま、画面の光。
  疑いが強くなると、押し入れの前に来て、じっと聞いています

### 塩水
口に含んでいる間（右下のコップ）、声は出せず、呼吸もこもって小さくなります。
人形がふすまの前まで来ても、**口に塩水が残っていれば、ふすまは開けません**。立ったまま、長い間、そこにいます。
話す・あえぐ・吹き出すと、口の塩水はなくなります。足すのはコップからだけです。

## 守ること

> 一、必ず一人で行うこと。
> 一、隠れている間は、塩水を口から出してはいけない。声を出してはいけない。
> 一、始めたら、家から出てはいけない。
> 一、始めたら、必ず終わらせること。（二時間以内）
> 一、終わったら、人形を燃やすこと。

破ると「守ること」が画面に出ます。結末の言葉も、破った数で変わります。

## 結末

四つあります。**終了**（ちゃんと終わらせた）と、そうでなかった三つ――**鬼**、**外へ**、**未完**。
どれも、最後にカメラが何かを映しています。

## 画面の見かた

| 場所 | 表示 |
|---|---|
| 左上 | 今の手順（「次：米を詰める」「隠れる」「人形を探す」）、準備の進み具合 |
| 右上 | 時計（三時までは速く進みます。五時で夜明け） |
| 右下 | 口の塩水（コップ）と、息 |
| 下中央 | 声と、聞こえたもの（字幕） |
| カメラアプリ | REC・カメラ番号と部屋・日時・電池・赤外線 |

## 設定

`config/hitori-common.toml`

| 項目 | 既定 | 内容 |
|---|---|---|
| `autoStart` | true | ワールドに入るとすぐ始める |
| `dollSpeed` | 1.0 | 人形の速さ（0.7 でやさしく、1.3 で難しく） |
| `awarenessRate` | 1.0 | 隠れ場所を疑う速さ（0.5〜1.5） |
| `prepClockRate` | 4.0 | 三時までの時計の速さ |
| `nightClockRate` | 2.0 | 三時からの時計の速さ（五時で夜明け） |
| `mouthMinutes` | 10 | 口の塩水がもつ時間（実時間・分） |

`config/hitori-client.toml`

| 項目 | 既定 | 内容 |
|---|---|---|
| `flashReduction` | false | 点滅・明滅・映像の乱れを止める（光過敏の方へ） |
| `jumpscares` | true | 画面いっぱいのおどかし画像 |
| `screenEffects` | 1.0 | 恐怖の画面効果（周辺減光・粒子・揺れ）の強さ |
| `installShaderPack` | true | HitoriShaders を shaderpacks に入れる |
| `acoustics` | true | 部屋の響きと壁越しのこもり、押し入れとカメラのマイク（Sound Physics Remastered があれば譲ります） |

## 開発

- ビルドは GitHub Actions（`bash tools/ci.sh "メッセージ"`）。結果はブランチ `ci-<branch>` に（ビルドログ、セルフテスト、スクリーンショット）
- `-Dhitori.selftest=true`（専用サーバー）: 偽プレイヤーで夜を一通り（準備の全手順、儀式、隠れる、人形の目覚めと探索、塩水、終わらせ方、四つの結末、女、霊障、セーブ）
- `-Dhitori.shots=true`（クライアント）: 部屋と各場面のスクリーンショットを撮って終了
- デバッグコマンド（OP）: `/hitori debug step <手順>`、`phase`、`clock <hh:mm>`、`cameras`、`doll spawn|pose|state|still|suspicion|tub|remove`、
  `woman <n>|closer|remove`、`event <霊障>`、`ending <good|oni|soto|mikan>`、`hide`、`unhide`、`peek`、`call`、`message <n>`、`light`、
  `fixture tv|lights|bath|fusuma`、`fear`、`mouth`、`peaceful`、`director`、`give`、`log`
- 言語ファイルは `tools/gen_lang.py` から生成します（字幕は `tools/audio/subtitles_{ja,en}.json`）
- 設計: `docs/DESIGN.md`
