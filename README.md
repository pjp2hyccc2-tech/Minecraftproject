# Clockwork Diver（クロックワーク・ダイバー）

Minecraft Java Edition **1.20.1 / Forge 47.x** 用のスチームパンク時計修理MODです。

スチームパンクの街角にある自分の時計修理工房に、さまざまな依頼人が不思議な時計を持ち込みます。
修理台で「時視の眼鏡」をかけて不良部品を見つけたら、体を小さくして時計の中へ潜り込み、
自分の体で直しに行きましょう。

## 導入

1. Minecraft 1.20.1 に Forge 47.x（47.2 以降推奨）をインストール
2. `clockworkdiver-1.1.0.jar` を `.minecraft/mods` フォルダに入れる
3. Forge のプロファイルで起動し、ワールドに入る

## 遊び方（チュートリアル）
1. 初めてワールドに入ると **工房の鍵** がもらえます。右クリック（またはチャットの［工房へ向かう］をクリック）で工房へ。
2. しばらくすると依頼人 **グレゴリー老** が来店します。右クリックで話しかけ、「引き受ける」。
3. 画面に出る **「修理台」** ボタンを押すと修理台へ移動し、**眼鏡をかけます**。
4. マウスで動く眼鏡のレンズを時計の上で動かすと、文字盤が透けて中の機械が見えます。
   赤く光る部品にレンズを合わせ続けると正体が判明します。
5. 部品を選んで「この部品に潜る」→ 体が小さくなって時計の中へ！
6. 中で修理を終えると元の大きさに戻ります。全部直したら依頼人に渡して報酬（真鍮貨）をもらいましょう。

## 物語「時を継ぐ修理工」（全5章・20話）
チュートリアルのあと、物語の依頼人が順番にやって来ます。**Jキー**の「修理日誌」で、あらすじ・各話の要約・受け取った思い出の品を確認できます。

一年前に消えた師匠エリアスの工房を継いだあなた。直す時計の奥から「黒い歯車」――時喰いの卵が見つかり始め、街の時が少しずつ喰われていく。卵を撒く灰色の男、大時計塔に潜む「時喰いの女王」、そして師匠の行方とは。

| 章 | 話 | 見どころ |
|---|---|---|
| 第一章 歯車の街の新米時計師 | 1〜4 | 時間制限つきの駅の時計、記憶の欠片、調律鐘パズル、初めてのボス |
| 第二章 灰色の影 | 5〜8 | 埃詰まり、怪盗の盗品時計、早鐘の子時計、黒殻の時喰い |
| 第三章 師の足跡 | 9〜12 | 暗闇の星辰儀、オルゴールの少女、怪盗の告白、裏拍の探知機 |
| 第四章 狂い出す大時計 | 13〜16 | 止まりゆく街、枯れない花、逆さ時計の日記、女王の影 |
| 第五章 時を継ぐ者 | 17〜20 | 時計塔前の広場から大時計へ、三段変化する女王、師匠の最終試験、エンディング |

- 物語の時計には **手掛かり**（紫に光る）が隠れていることがあります。修理台のレンズで見つけて読みましょう。
- 時計の中に **記憶の欠片** が落ちていることがあります。触れると持ち主の思い出が蘇ります（全部集めると修理完了）。
- 各話のクリアで **思い出の品** を受け取ります。いくつかの話では工具が強化されます。
- 第五章は工房の向かいのアーチを抜けた **大時計塔前の広場** が舞台です。仲間たちが集まっています。
- 物語のあとも、依頼人は不思議な時計を持ってやって来ます。エンディングは修理日誌から見直せます。

## 時計の中：戦闘と修理
時計の中では全てが脱進機の **拍（チク・タク）** で動いています。画面上部の振り子が中央の宝石を通る瞬間に行動すると **「ジャスト！」**。
- **ジャスト攻撃**：ダメージ1.5倍〜3倍、コンボと蒸気圧がたまる。拍を外すと威力が落ちコンボが途切れる
- **蒸気爆発**（レンチ右クリック・蒸気40）：周囲の敵を吹き飛ばす。ジャストなら範囲・威力アップ
- **ピストンダッシュ**（Shift+右クリック・蒸気25）：無敵時間つきの突進
- **蒸気口** の上に立つと蒸気が回復
- 危なくなったら **R 長押し** で脱出。倒れても時計の外に弾き出されるだけ（アイテムは失いません）

| 故障 | 修理内容 |
|---|---|
| 錆び付き | 歯車の上の錆の塊をレンチで砕く（ジャストなら一撃）。錆ダニが湧く |
| 歯欠け | 光る歯車小鬼を倒して歯を取り返し、受け口にはめる |
| ネジの緩み | 巨大ネジのネジ山を登り、頭の溝を拍に合わせて回す |
| ゼンマイ切れ | クランクを回して巻き上げる。敵が近づくと緩む |
| 埃詰まり | 埃の山は叩いても崩れない。蒸気爆発でまとめて吹き飛ばす。埃蛾が埃を運び戻す |
| 調律狂い | 4つの調律鐘が光って奏でる旋律を覚え、同じ順に拍に合わせて打ち返す |
| 時喰いの巣 | ボス「時喰い」。殻はジャスト攻撃でしか砕けない。HP半分で拍が速くなる |

物語の依頼には、部品ごとに **仕掛け** があります（修理台で部品を選ぶと「⚠」で確認できます）。

| 仕掛け | 内容 |
|---|---|
| 時間制限 | 画面上の時計が0になると失敗 |
| 早鐘 | 拍がとても速い |
| 裏拍 | チク・タクの音の「間」が叩きどき（振り子は裏拍に合わせて動く） |
| 暗闇 | 灯りが消えている。眼鏡が敵の輪郭を映す |
| 大群 / 強化個体 | 敵が多い / 黒い靄をまとった強い敵 |
| 蒸気口なし | 蒸気はジャストでしか溜まらない |
| 精密作業 | 拍を外すと修理が一段階戻る |

ボスには「時喰い」のほか、**黒殻の時喰い**（闇に紛れて背後に現れる）、**女王の影**、**時喰いの女王**（拍を早め、最後は拍を裏返す）がいます。

真鍮貨は修理台の「改良」タブでレンチ・蒸気タンク・レンズの強化に使えます。

## コマンド
- `/clockwork workshop` 工房へ ／ `/clockwork leave` 元の場所へ ／ `/clockwork bench` 修理台へ ／ `/clockwork abort` 時計から脱出
- `/clockwork story` 物語の進み具合を表示
- 管理者用：`/clockwork story set <1-21>`（その話へ移動。21で完結）、`/clockwork story skip`、`/clockwork story keepsakes`
- 管理者用：`/clockwork dive <rust|teeth|screw|spring|nest|dust|tuning> [timed fast offbeat dark swarm elite novents precision frag3 shadow shade queen]`
- 管理者用：`/clockwork customer [時計の種類]`、`/clockwork complete`、`/clockwork tutorial reset`

## ビルド

```
./gradlew build      # build/libs/clockworkdiver-1.1.0.jar
```

`tools/` のスクリプトでテクスチャ・効果音・JSON・言語ファイルを再生成できます
（`gen_textures.py` → `gen_textures_story.py`、`gen_sounds.py` → `gen_sounds_story.py`、`gen_json.py`、`gen_lang.py`）。
物語の本文は `tools/story_text.py` にまとまっています。
