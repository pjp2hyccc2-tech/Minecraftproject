# ArchiQuest ─ 一級建築士への道（Minecraft Forge 1.20.1 MOD）

マイクラで建物を建てながら、**一級建築士試験**（学科：計画・環境設備・法規・構造・施工＋設計製図）の内容を、
AI先生「アーキ先生」と一緒に楽しく学べるMODです。

- **建築中アドバイス**：ブロックを置くと、そのブロックに関係する試験知識を教えてくれる（ガラス→採光1/7、階段→蹴上げ23cm、コンクリート→かぶり厚さ…）
- **高さの節目演出**：高く建てると「高さ20m突破！避雷設備が必要（法33条）」のように画面に表示
- **建築診断スケール**：建物を右クリックすると、建築面積・延べ面積・高さ・階数を測り、部屋ごとに **天井高2.1m／採光1/7／換気1/20／出口** を判定。敷地を指定すれば **建ぺい率・容積率** も診断
- **建築チャレンジ**：「はじめての居室」「快適な2階建て住宅」「建ぺい率・容積率を守れ！」など、基準を満たす建物を建てる“ミニ製図試験”
- **クイズ＆模擬試験**：本番と同じ四肢択一。模試は本番の出題比率（20:20:30:30:25）で出題し、合格すると合格証書がもらえる
- **教科書GUI**：30レッスンの「かみくだき解説」「マイクラで例えると」「試験に出るポイント」「ゴロ合わせ」
- **AI先生**：Claude API（またはOpenAI互換API／Ollamaなどのローカルモデル）につなぐと、自由な質問・建物の講評・問題の深掘り解説をAIが担当。**APIキーなしでも内蔵の教科書から答える「オフライン先生」で動きます**

> 1ブロック＝1m として計算します。マイクラの「2マス天井」は2.0mなので、天井高2.1mの基準はアウト！ そんな“マイクラと現実の違い”から覚えられます。

## ビルド方法（jarを作る）

1. **JDK 17** をインストール（例：Eclipse Temurin 17）。
2. **Forge 1.20.1 の MDK** をダウンロードして展開
   - https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html の「Mdk」
3. 展開したMDKフォルダの中の `src` フォルダを削除し、このzipの中身
   （`src`・`build.gradle`・`settings.gradle`・`gradle.properties`）をMDKフォルダに**上書きコピー**。
4. MDKフォルダでターミナル（コマンドプロンプト）を開いて実行：
   - Windows：`gradlew build`
   - Mac / Linux：`./gradlew build`
5. `build/libs/archiquest-1.0.0.jar` ができるので、`.minecraft/mods` フォルダに入れて、Forge 1.20.1 で起動！

開発用にそのまま起動して試すなら `gradlew runClient`。

**うまくいかないとき**
- `build.gradle` でエラーが出る場合：MDK付属の `build.gradle` / `settings.gradle` をそのまま使い、`gradle.properties` と `src` だけを置き換えてください（このMODはMDK標準の構成です）。
- 文字化けする場合：Java・リソースはすべて UTF-8 です（同梱の `build.gradle` でUTF-8を指定済み）。

## 遊び方

初めてログインすると **教科書** と **建築診断スケール** がもらえます（クラフトも可）。

| アイテム | 使い方 | レシピ（不定形） |
|---|---|---|
| 一級建築士の教科書 | 右クリック または **Kキー** で教科書GUI | 本＋レンガ |
| 建築診断スケール | 建物を右クリック→診断／**スニーク＋右クリック×2で敷地指定**／スニーク＋空中右クリックで敷地リセット | 鉄インゴット＋棒＋黄色の染料 |
| 模試合格証書 | 模擬試験に合格するともらえる記念品 | ─ |

### コマンド（`/archi` だけでも使い方が出ます。チャットのボタンはクリックできます）

| コマンド | 内容 |
|---|---|
| `/archi quiz [科目]` | 1問クイズ。科目：`planning` 計画 / `environment` 環境・設備 / `law` 法規 / `structure` 構造 / `construction` 施工 / `design` 設計製図 |
| `/archi exam [問題数]` | 模擬試験（既定10問、5〜30問）。`/archi exam quit` で中断 |
| `/archi challenge` | 建築チャレンジの一覧（ボタンで挑戦開始） |
| `/archi ask <質問>` | アーキ先生に質問（例：`/archi ask 建ぺい率って何？`） |
| `/archi analyze` | 見ている建物を診断（スケールと同じ） |
| `/archi review` | 最後に診断した建物をAI先生が講評 |
| `/archi explain <問題ID>` | 問題をAI先生がじっくり解説（クイズの後のボタンから） |
| `/archi lessons [科目]` / `/archi lesson <ID>` | 教科書の目次／レッスンをチャットに表示 |
| `/archi tip [科目]` | ランダムな豆知識 |
| `/archi stats` | 称号・科目別の正答率・模試成績 |
| `/archi advice on\|off` | 建築中アドバイスのON/OFF |
| `/archi ai status` / `/archi ai reset` | AIの設定状況／会話の記憶をリセット |
| `/archi reload` | （OPのみ）教材データの再読み込み |

## AI先生の設定（任意）

一度起動すると `.minecraft/config/archiquest-common.toml` ができます。`[ai]` を編集してください（ゲーム中に保存しても反映されます）。

**Claude API を使う（おすすめ）**
```toml
[ai]
	provider = "anthropic"
	apiKey = "sk-ant-xxxxxxxx"   # Claude Console で発行したキー
	model = ""                    # 空なら claude-haiku-5-5（速くて安いモデル）
```
APIキーは設定ファイルに書く代わりに、環境変数 `ARCHIQUEST_API_KEY`（または `ANTHROPIC_API_KEY`）でも指定できます。

**ローカルLLM（Ollama など）やOpenAI互換APIを使う**
```toml
[ai]
	provider = "openai"
	model = "llama3.1"
	endpoint = "http://localhost:11434/v1/chat/completions"
	apiKey = ""                   # ローカルなら空でOK
```

- `autoAdviceWithAI = true` にすると、建築中アドバイスもAIが考えます（API利用料が増えるので既定はOFF）。
- API利用料は各サービスの料金体系に従って発生します。設定ファイル（APIキー）は人に渡さないでください。
- マルチプレイでは、**サーバー側**の設定が使われます。

## 教材を自分で追加する

`config/archiquest/` フォルダを作って、好きな名前の `.json` を置くと、起動時（または `/archi reload`）に追加されます。
同じIDなら上書きです。形式は `src/main/resources/assets/archiquest/knowledge/` の各ファイルと同じです。

```json
{
  "questions": [
    {
      "id": "my_001", "subject": "law", "difficulty": 1, "lesson": "law_lighting",
      "question": "居室の天井高の最低限度は？",
      "choices": ["2.0m", "2.1m", "2.4m", "3.0m"], "answer": 1,
      "explanation": "居室の天井高は2.1m以上（施行令21条）。"
    }
  ]
}
```
`answer` は0から数えた正解の番号です（出題時に選択肢はシャッフルされます）。
