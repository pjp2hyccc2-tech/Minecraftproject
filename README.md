# MINECRAFT BESIEGE

**BUILD × FIGHT × DESTROY — マシンを作り、戦い、すべてを壊せ。**

Minecraft Java Edition **1.20.1 / Forge 47.x** 用の、物理攻城兵器ビルダー MOD です。
始動ブロックからパーツをつないでマシンを組み立て、ワンキーで物理シミュレーションを開始。
車輪で走り、大砲で城門を撃ち抜き、火炎放射器で村を燃やし、壊れたら一瞬で元通りにリセットできます。

ゲームの流れは「設計 → 出撃 → 破壊 → リセット → 改良」。そこに Minecraft らしさとして、
本物のブロック世界を壊せる破壊表現、TNT・火薬樽・花火スラスター・ラヴェジャーなどの
Minecraft 要素、サバイバル用レシピ、作戦テーブルから行く専用ディメンション「攻城の地」を加えています。

---

## 動作環境とインストール

| 項目 | 内容 |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Mod Loader | Forge 47.x（47.3.0 で動作確認） |
| Java | 17 |
| 前提 MOD | なし |

1. Forge 1.20.1 をインストールします。
2. `mcbesiege-1.0.0.jar` を `.minecraft/mods/` に入れます。
3. Forge プロファイルで起動します。言語を日本語にすると UI もすべて日本語になります。

> マルチプレイの場合は、サーバーとクライアントの両方に入れてください。

---

## はじめかた（3分）

1. クリエイティブで新しいワールドを作ります。
2. **B** キーでパーツ一覧を開き、**始動ブロック**を地面に置きます。上面の矢印がマシンの前方です。
3. 始動ブロックに **木材ブロック** を足して車体を作り、両側面に **木の車輪** を付けます。
4. **R** キーでシミュレーション開始。**↑ / ↓** で前進・後退します。
5. もう一度 **R**（または操縦画面の「リセット」）で、壊れたマシンも組み立て直後の状態に戻ります。

前輪を、車体の側面に付けた **ステアリングヒンジ** の先に取り付けると **← / →** でハンドルが切れます。
大砲（**C** で発射）を載せれば攻城兵器の完成です。

## 操作

### ビルドモード

| キー / 操作 | 機能 |
|---|---|
| **R** | シミュレーション開始（見ている始動ブロック、なければ近くの始動ブロック）。自分のマシンが動いていればリセット |
| **B** | パーツ一覧（ビルダー画面）。クリックでパーツを入手（クリエイティブ／ミッション中） |
| **M** | ミラー配置の ON / OFF（始動ブロックを中心に左右対称に置かれる） |
| **G** | 動いているマシンの操縦画面に戻る |
| 始動ブロックを素手で右クリック | シミュレーション開始 |
| **レンチ** でパーツを右クリック | キー割り当て・スライダー・トグルの設定画面（「同種すべてに適用」あり） |
| **レンチ** をスニーク+右クリック | パーツの向きを回転（ヒンジ類はまずピン軸を回転） |
| **レンチ** で空中を右クリック | ビルダー画面 |
| レンチを持っている間 | マシンの重心（青い印）を表示 |

### シミュレーション（操縦画面）

| キー / 操作 | 機能 |
|---|---|
| パーツに割り当てたキー | パーツが動作（すべてのキーがマシンに送られます） |
| マウスドラッグ | カメラをマシンの周りで回転 |
| マウスホイール | ズーム |
| **R** / 「リセット」 | マシンを組み立て直後の状態に戻す |
| 「その場に設置」 | 今の位置にマシンをブロックとして置き直す |
| **Esc** / 「操縦終了」 | 操縦画面を閉じる（マシンは動き続け、**G** で戻れる） |

画面左上に現在使えるキーの一覧と、マシンの耐久（残りパーツ数）が表示されます。

**座席**: 座席の近く（約2.5ブロック以内）に立ってシミュレーションを始めると乗り込みます。
乗車中は **WASD = ↑←↓→**、**スペース = Space** としてマシンを操縦できます。

## マシン作りのルール

- マシンは必ず **始動ブロック** から始まり、すべてのパーツは始動ブロックにつながっている必要があります（1台に始動ブロックは1つ）。
- パーツには取り付け面があります。ブロック類は全面、板・車輪・武器などは **背面だけ**、関節パーツは **背面と前面** で接続します。
- 関節パーツ（ヒンジ、ステアリング、回転ブロック、ボールジョイント、サスペンション、ピストン、デカップラー）は、
  土台側と先端側が別々の剛体になり、その間が関節になります。
- **接続ツール**（ブレース／スプリング／ロープ）は、パーツを2回クリックしてつなぎます。離れたパーツ同士も接続できます。
- 最大パーツ数は 600（設定で変更可能）。

### 設計図

設計図を始動ブロックに右クリックするとマシンを保存、地面に右クリックすると複製を設置します（向きは自分の向きに合わせて回転）。
サバイバルでは設置時に手持ちのパーツを消費します。

## パーツ一覧（45種）

カッコ内は初期キー。すべてレンチで変更できます。

**基本**: 始動ブロック／木材ブロック／補強木材／木の柱／木の板／座席

**装甲**: 鉄ブロック／鋼ブロック／鉄板／石ブロック

**移動**: 木の車輪・鉄の車輪・大型タイヤ（↑ 前進・↓ 後退、自動ブレーキ・トグル・逆回転・速度設定あり）／
小型キャスター（動力なし）／グリップパッド（高摩擦）／氷の滑り板（ほぼ摩擦ゼロ）

**機械**: ヒンジ（自由関節）／ステアリングヒンジ（← →、制限角・自動復帰あり）／ステアリングブロック（← →、無制限）／
回転ブロック（常時回転 or キー）／ボールジョイント／サスペンション（バネ・ダンパー調整）／ピストン（H）／
デカップラー（J で切り離し）／グラバー（触れた物をつかむ、V で放す）

**武器**: 大砲（C、反動あり）／弩（C、弾数制限）／火炎放射器（Y）／爆薬（TNT）／火薬樽／
投石用弾（X で放す）／ロケット（K）／回転刃／ドリル（ブロックを掘る）／ハンマー／スパイク

**飛行**: プロペラ（回転ブロックで回すと推力）／ウィング（揚力）／飛行ブロック（U、花火スラスター）／風船／バラスト

**自動化**: タイマー（T で起動 → 遅れてテンキー1）／センサー（前方を検知 → テンキー2）／
高度計（設定高度で → テンキー3）／論理ゲート（AND/OR/XOR など、テンキー1・2 → テンキー4）

**接続ツール**: ブレース（固定）／スプリング（L で縮む、投石機に）／ロープ＆ウインチ（O で巻き上げ・P で繰り出し）

**道具**: レンチ（キーマッパー）／設計図

自動化パーツは「キーを押す」ことで他のパーツを動かします。出力キーを他のパーツの入力キーに合わせれば、
自動で撃つ砲台や、時間差で切り離す多段ロケットが作れます。

## 物理・破壊

- 独自の剛体物理エンジン（関節、モーター、バネ、衝突、摩擦、スリープ）でマシン全体を計算します。
- 強い衝撃を受けたパーツは壊れ、関節は大きな力でちぎれます。マシンはその場で分裂します。
- 木のパーツは燃え、炎は隣のパーツに燃え広がり、燃え尽きると炭になって崩れます。溶岩や火にも反応します。
- 爆薬・火薬樽・ロケットは爆発し、周りのパーツを吹き飛ばし、連鎖爆発します。
- 水に入ると浮力がかかります（木は浮き、鉄は沈む）。
- 速いマシン、砲弾、ドリルは **ワールドのブロックを実際に壊します**（硬いブロックほど壊れにくい）。
  ハチミツブロックはよく止まり、スライムブロックは跳ね、氷は滑ります。
- 自分のマシンでは自分はダメージを受けません（設定で変更可）。

## ミッション（攻城作戦）

**作戦テーブル** を右クリックすると作戦一覧が開きます。「出撃！」を押すと専用ディメンション「攻城の地」の
戦場へ移動し、黄色と黒のビルドゾーンの中でマシンを作って攻略します（パーツは **B** で自由に入手）。

| 島 | ミッション | 目的 |
|---|---|---|
| 第一の島：辺境の村 | はじめての攻城 ★ | かかしの上の攻城目標を破壊 |
| | 風車を壊せ ★ | 風車の攻城目標2つを破壊 |
| | 前哨基地を掃討せよ ★★ | 略奪者を全滅 |
| | 城門を破れ ★★ | 城門を突破し、中庭の目標3つを破壊 |
| | 宝を運べ ★★ | 重い宝物を金のゴールまで運ぶ |
| 第二の島：王の領地 | 谷を越えろ ★★★ | 谷を越えてゴールに到達 |
| | 三つの塔 ★★★ | 3つの塔の頂上の目標を破壊 |
| | ラヴェジャー討伐 ★★★ | ラヴェジャーと護衛を倒す |
| | 王の城 ★★★★ | 城の目標4つを破壊し、守備兵8体を倒す |

クリアすると「攻城成功！」と花火で祝福され、作戦一覧に記録されます。
`/mcbesiege leave` で元いた場所に戻ります（ミッション用に入手したパーツは回収されます）。

| コマンド | 内容 |
|---|---|
| `/mcbesiege reset` | 自分のマシンをリセット |
| `/mcbesiege resetall` | 全マシンをリセット（OP） |

## 設定（`config/mcbesiege-common.toml`）

| セクション | キー | 初期値 | 内容 |
|---|---|---|---|
| physics | `gravity` | 20 | マシンの重力（ブロック/秒²） |
| | `substeps` / `iterations` | 8 / 4 | 物理の精度（上げると安定・重くなる） |
| | `jointStrength` | 1.0 | 関節の強さの倍率 |
| | `waterDensity` | 0.8 | 水の密度 |
| machines | `maxParts` | 600 | 1台あたりの最大パーツ数 |
| | `impactDamage` | 0.05 | 衝撃ダメージの倍率 |
| | `maxDebris` | 64 | 残す破片の上限 |
| | `ownerImmune` | true | 自分のマシンで自分が傷つかない |
| destruction | `machinesBreakBlocks` | true | マシン・砲弾・ドリルがブロックを壊す |
| | `explosionsBreakBlocks` | true | 爆発がブロックを壊す |
| | `fireGriefing` | true | 火炎放射器がブロックに火をつける |
| | `blockDrops` | false | 壊れたブロックをドロップする |
| | `blockToughness` | 1.0 | ブロックの壊れにくさの倍率 |

サーバーでワールドを壊されたくない場合は `destruction` の項目を false にしてください。

## ソースからのビルド

```
./gradlew build
```

`build/libs/mcbesiege-1.0.0.jar` が生成されます。テクスチャ・モデル・言語ファイルは `tools/` の
Python スクリプト（`gen_textures.py`、`gen_assets.py`、`gen_lang.py`）から生成しています。

GitHub Actions（`.github/workflows/build.yml`）では、ビルドに加えて専用サーバーでの自動テスト
（車の走行、ステアリング、大砲でのブロック破壊、爆発、リセット、全ミッションの生成）と、
クライアントのスクリーンショット撮影を行います。
