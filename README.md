# 遭難 ―SOUNAN―

Minecraft Java 版 **Forge 1.20.1** 用の、山岳遭難ホラー MOD です。

> 十一月二日、午後四時四十分。帰らず山の下山道。
> 「おーい」――誰かに呼ばれた気がして、道を外れた。足元が崩れた。
> 気がつくと夜の杉林。霧。バッグがない。
> 手元にあるのは、**圏外のスマホ**と**懐中電灯**だけ。
>
> 失くしたバッグを探し、中の道具を使い、**この山を抜けろ**。
> 木の陰から覗くもの。背後を歩くもの。灯りを持って呼ぶもの。小屋で眠るもの。
> 近づいてはいけない。振り返ってはいけない。ついて行ってはいけない。

---

## 必要なもの

| | |
|---|---|
| Minecraft | Java Edition 1.20.1 |
| Forge | 47.x（47.3.0 で動作確認） |
| 影MOD（強く推奨） | **Oculus（1.20.1 版）＋ Embeddium**、または OptiFine<br>動作確認: Oculus 1.20.1-1.7.0 / Embeddium 0.3.31 |
| メモリ | 3GB 以上を推奨 |

影MODなしでも遊べます（MOD 側で暗い霧・懐中電灯の明かり・画面効果を描画します）。
ただし本作の**懐中電灯の光線・霧の中の光の筋・月明かり・暗視カメラ・恐怖の画面効果**は、
専用シェーダー **SounanShaders** で真価を発揮します。

## 導入

1. `sounan-1.0.1.jar` を `.minecraft/mods` フォルダに入れる
2. 影を使う場合は Oculus と Embeddium も同じフォルダに入れる
3. 起動すると専用シェーダー **SounanShaders** が `shaderpacks` フォルダに自動で入り、
   ほかのシェーダーを選んでいなければ自動で有効になります。
   なっていなければ「設定 → ビデオ設定 → シェーダーパック」で `SounanShaders` を選んでください。
4. **部屋を暗くして、ヘッドホンで**遊んでください。
   左右の耳で鳴る囁き、背後の足音、虫の声が止む瞬間――音がいちばんの手がかりで、いちばんの恐怖です。
   BGM と環境音は「環境/自然」、やつらの音は「敵対的なモブ」の音量で鳴ります。この2つは下げないでください。

## 演出（音と映像）

### 音
- 効果音・BGM の 224 ファイルは、すべてこの MOD のために一から合成したものです。
- 低いドローンの下に**バイノーラルビート**を入れています。左右の耳にわずかに違う周波数を流すと、頭の中にうなりが生まれます。ヘッドホンだと頭の芯がざわつきます。
- 微分音でずらした弦の**不協和音**、終わりなく上がり続けるように聞こえる音（シェパードトーン）、ざらついて震える弦、不規則な低い心音。
  恐怖と危険が増すほど、これらの層が重なっていきます。
- 片耳だけで聞こえる囁き、背後の足音、名前を呼ぶ声。虫の声がふっと止んで**無音**になり、耳鳴りと耳が詰まる感じが残ります。
- 自分の鼓動と呼吸は、画面の心拍数どおりのテンポで鳴ります。

### 映像（SounanShaders）
- 懐中電灯の光：中心が強く縁が柔らかい光、反射板のリング、レンズの曇り。霧に光の筋が浮かび、筋の中を塵が舞います
- 窪みに溜まって流れる霧と、杉の枝の隙間から落ちる月明かりの筋
- 光を当てると**やつらの目が光ります**。暗視カメラでは、赤外線の中に浮かび上がります
- 心拍に合わせて脈打つ視野の狭まり、色のにじみ、視界の端の暗闇に浮かぶ顔
- 危険が迫ると画面が呼吸するように歪み、影が赤黒く染まり、懐中電灯がちらつきます
- スマホの暗視カメラ：緑がかった灰色の画面に、魚眼のゆがみ・走査線・ノイズ

影MODなしでも、MOD 側で霧・ビネット・粒子ノイズ・暗視カメラ・霧の向こうの灯りを描きます。
重いときは、シェーダー設定のプロファイルを **LOW** にしてください（霧と光の筋の品質が下がります）。

## 始め方

- **新しいワールドを作って入ると、すぐに夜の帰らず山から始まります**（約15秒のオープニングのあと操作できます）。
  持ち物・場所・ゲームモードは保存され、ゲームを終えると元のワールドに戻ります。
- コマンドでも開始できます: `/sounan start`　途中でやめる: `/sounan leave`
- セーブして終了しても、次に入ったときは続きから再開します。
- 自動で始めたくない場合は `config/sounan-common.toml` の `autoStart = false`。

## 操作

| 操作 | 内容 |
|---|---|
| 右クリック（懐中電灯） | 点灯／消灯。電池は減っていく（満タンで約10分） |
| 右クリック（スマホ）/ **P キー** | スマホを開く（地図・カメラ・ライト・メッセージ・電話・メモ）。開いている間もゲームは進む |
| スニーク＋右クリック（スマホ） | スマホのライトを点ける／消す（電池の減りが速い） |
| カメラ中: 右クリック | フラッシュ撮影　／　スニーク＋右クリックで戻る |
| **J キー** | 拾ったメモを読み返す |
| 右クリック | 調べる・拾う・扉・使う |
| ダッシュ | 速いが**足音が響く**。スタミナが尽きると荒い息で動けなくなる |
| **スニーク** | 足音を殺す。扉も静かに開けられる。**小屋の中では必ず屈んで歩くこと** |

懐中電灯は左手（オフハンド）に持てば、右手でスマホを使いながら照らせます。

## 画面の見かた

- 左下の **♥ 数字** は心拍数。暗闇、気配、遭遇で跳ね上がります。高いほど視界が狭まり、手が震え、
  呼吸の音が「やつら」にも聞こえるようになります。明かりの下や休める場所では落ち着きます。
- 懐中電灯を持っていると、ホットバーの右に電池残量が出ます。
- スマホの画面上部に時刻・電波（圏外）・バッテリー。

## 山の掟（帰野地区自治会）

> 一、夜の山で、灯りを持つ者に呼ばれても、決してついて行ってはならない。
> 一、木の陰から覗くものと、目を合わせてはならない。灯りを向けてもならない。
> 一、背中に気配を感じたら、決して振り返らず、そのまま歩き続けること。
> 一、小屋の主を起こしてはならない。小屋では音を立てず、屈んで歩くこと。
> 一、祠の前を通る者は、御神酒を供えること。供えぬ者は霧に迷う。
> 一、御山様に会ったなら、火を焚け。御山様は火を嫌う。

これがそのまま、生き延びるための攻略法です。

## アイテム

| アイテム | 使い方 |
|---|---|
| 懐中電灯 | 唯一の頼り。電池が切れかけると暗く、ちらつく。**近くに何かいると明滅する** |
| スマホ | 地図（GPS・歩いた跡。電波の入る場所で地図データが落ちてくる）、暗視カメラ（**肉眼では見えないもの**が写る）、ライト、メッセージ、電話、メモ |
| 予備電池 | 懐中電灯の電池を交換 |
| モバイルバッテリー | スマホを +60% 充電 |
| 熊鈴 | 鳴らすと覗くものは逃げ、背中のものも離れる。5回まで。大きな音が出る |
| ロープ | 崖の杭に結んで下へ降りる |
| 登山地図 | 古い紙の地図。現在地は書いていない |
| 発煙筒 | 40秒間、赤い火が燃える。**御山様は火を嫌う** |
| お守り | 一度だけ、捕まったときに身代わりになってくれる |
| 古い鍵・御神酒 | 山のどこかで |

## 捕まると

画面が暗転し、最後に通った休める場所で目を覚まします。
ただし、**捕まるたびにスマホの日付が進んでいきます**。一日。九日。二か月。三年――。
**5回捕まると、神隠しに遭います**。

## エンディング

- **END 1 ― 下山**：一度も捕まらずに山を抜ける
- **END 2 ― 同行者**：捕まったことがある状態で山を抜ける
- **END 3 ― 神隠し**：5回捕まる

登山口の近くには、遭難者の慰霊の掲示板があります。読んでみてください。

## 設定（`config/sounan-client.toml`）

| 項目 | 内容 |
|---|---|
| `flashReduction` | 点滅・ストロボ・グリッチを抑える（光過敏の方向け） |
| `jumpscares` | 捕まったときの全画面の顔を表示する |
| `screenEffects` | 心拍・ビネット・揺れなどの画面効果の強さ（0〜1.5） |
| `installShaderPack` | SounanShaders を自動で shaderpacks に入れる |

難易度は `config/sounan-common.toml` の `monsterSpeed`（やつらの速さ）、`fearRate`（心拍の上がりやすさ）で調整できます。
シェーダーの細かい設定（霧の濃さ・光の筋の品質・粒子ノイズなど）は、シェーダーパック画面の「シェーダー設定」から変えられます。

## ヒント（ネタバレ控えめ）

- 迷ったら**ピンクの目印テープ**を探す。……ただし、全部が正しいとは限らない。
- 暗闇で立ち止まるより、灯りを持って歩き続けるほうが心拍は落ち着く。
- 遠くの灯りが手を振っていても、近づかないこと。
- 虫の声が止んだら、何かが近くにいる。
- 祠の先の霧で何度も同じ場所に戻されるなら、村のどこかに探し物がある。
- 圏外のスマホも、高い場所なら――。
- 長いトンネルでは、立ち止まらないこと。そして、火を。

## コマンド（管理者向け・デバッグ）

`/sounan status` 進行状況　`/sounan tp <場所>` 場所へ移動（start, bag, village, shrine, hut, pylon, tunnel_n, parking ほか）
`/sounan debug peaceful true` やつらを出さない　`/sounan reset` 進行をリセット
