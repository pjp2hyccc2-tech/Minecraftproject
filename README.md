# BirdieCraft – アーケードゴルフMOD（Minecraft Forge 1.20.1）

3クリック式スイングゲージ、風、ライ（芝の状態）、スピン、パワーショット、CPU対戦、マルチプレイ、
そしてオリジナルコース10種類を収録したアーケードゴルフMODです。
キャラクター・コース・テクスチャ・効果音はすべてこのMODのためのオリジナルです。

- 対応：Minecraft 1.20.1 / Forge 47.2.0 以降（47.x）
- 必要：クライアントとサーバーの両方に導入（マルチプレイ時）

---

## はじめかた

1. `birdiecraft-1.0.0.jar` を `.minecraft/mods` フォルダに入れて、Forge 1.20.1 で起動します。
2. クリエイティブタブ「バーディークラフト ゴルフ」から **ゴルフクラブ** と **ゴルフバッグ** を取り出します
   （サバイバルでも鉄インゴット1個＋棒2本でクラブを作れます）。
3. **Gキー**（またはゴルフバッグを右クリック）でゴルフメニューを開きます。
4. 「コース」タブで好きなプリセットコースを選び **「ここに建設」** を押します。
   目の前（向いている方向）に9ホールのコースが自動で建設されます（約540×320ブロック。広い場所で実行してください）。
   - シングルプレイでは誰でも、サーバーではOP権限のある人が建設できます。
5. 「プレイ」タブでコースを選んで **シングル / CPU対戦 / ロビー作成（マルチ）** を選べば試合開始です。

試合の外でクラブを持って右クリックすると、その場から打てる **練習場モード** になります（飛距離を計測できます）。

## 操作方法

| 操作 | キー |
|---|---|
| スイングゲージ（開始 → パワー決定 → インパクト） | **右クリック**（クラブを持った状態）／ B キー |
| クラブ変更 | マウスホイール ／ Z・V キー |
| ショットモード（ノーマル → パワーショット → アプローチ） | P キー |
| スピン（↑トップ ↓バック ←→曲げ） | 矢印キー（パター時は↑↓で距離レンジ変更） |
| ピン方向を向く | Y キー |
| スイングをキャンセル | Backspace |
| スコアカード表示 | H キー |
| ボールカメラ切替（オフ／自分／全員） | N キー |
| ゴルフメニュー | G キー |

キーはすべて「設定 → 操作設定」から変更できます。

### スイングゲージ（3クリック）
1. 1回目のクリックでマーカーが右へ進みます（パワー）。
2. 2回目のクリックでパワーが決まり、マーカーが左へ戻ってきます。
3. 左端の **青いゾーン** で3回目をクリック。中央の **白いライン** なら **パーフェクトインパクト**（飛距離アップ＋パワーショットのストック＋1）。
   早すぎると右へ、遅すぎると左へ曲がります。
- ゲージ上の🚩マークは「ピンまでの距離に必要なパワー」の目安です（風・高低差・転がりは含みません）。
- 地面の白いリングは「パワー100％・無風」の落下地点、黄色いリングは今のパワーでの落下地点です。

## ゲームシステム

- **クラブ14本**：1W〜SW、パター。飛距離と弾道の高さがそれぞれ違います（1ブロック＝2ヤード）。
- **ライ**：ティー、フェアウェイ、カラー、グリーン、ラフ、深いラフ、バンカー、カート道、氷 など。
  ラフやバンカーではパワーが減り（例：ラフ 84〜94％）、インパクトゾーンも狭くなります。
- **風**：ホールごとにランダム（0〜11m/s）。右上の矢印が自分から見た風向きです。
- **スピン**：トップスピンでランが伸び、バックスピンでグリーン上で止まる・戻ります。左右スピンでボールを曲げられます。
- **パワーショット**：飛距離+10％、ゲージが速くインパクトゾーンが狭い。ラウンド開始時3回分、パーフェクトで+1。
- **アプローチモード**：ゲージの最大を半分にして、短い距離を正確に打てます。
- **グリーンの傾斜**：パター選択時、グリーン上に流れる矢印が表示されます（青＝ゆるい／黄＝普通／赤＝急）。
- **ペナルティ**：池・溶岩＝1打罰で手前にドロップ、OB（ゴルフ用ブロック以外で止まる・場外）＝1打罰で打ち直し。
- **スコア演出**：バーディー、イーグル、アルバトロス、ホールインワン、チップイン、ナイスオン など。
- **ボールカメラ**：打ったボールをカメラが追いかけます（Nキーで切替）。
- **ホールマップ**：画面左にコースの全体図と各プレイヤーのボール位置を表示します。

### プレイスタイル（メニュー「スタイル」タブ）
| スタイル | 特徴 |
|---|---|
| バランス | 標準 |
| パワー | 飛距離+7％、インパクトゾーンが狭い |
| コントロール | インパクトゾーンが広い、飛距離−5％ |
| スピン | スピン量+45％ |

## 3つのモード

- **シングルプレイ**：1人でストロークプレイ。コース別の自己ベストが記録されます。
- **CPU対戦**：CPUゴルファー1〜3人と対戦（ビギナー／アマチュア／プロ／レジェンド）。
  CPUは本物の物理演算で風・傾斜・ハザードを読んでショットを選び、難易度に応じたミスをします。
  オリジナルキャラクターのリク・ハナ・テツ・ミアがスイングアニメーション付きで登場します。
- **マルチプレイ**：ホストが「ロビー作成」→ 他のプレイヤーはメニューの「マルチ」タブから参加 → ホストが「試合開始」。
  CPUを混ぜることもできます。順番はゴルフのルール通り（ティーショットはオナー順、その後はピンから遠い人から）。
  持ち時間（初期設定90秒）を過ぎると自動でショットされます。

## オリジナルコース（10種類・各9ホール）

| コース | テーマ | 難易度 |
|---|---|---|
| サンライズ・メドウ | 草原・広いフェアウェイ | ★ |
| コーラルベイ・リンクス | 海辺・白砂・ヤシ・強風 | ★★ |
| メープル・リッジ | 紅葉の丘陵 | ★★ |
| さくら渓谷 | 桜・池・石灯籠 | ★★ |
| デザート・ミラージュ | 赤砂・サボテン・オアシス | ★★★ |
| フロスト・ピーク | 雪原・トウヒ・凍った池 | ★★★ |
| ボルケーノ・アイル | 黒砂・玄武岩・溶岩 | ★★★★ |
| ミストウッド | ダークオーク・巨大キノコ・狭いフェアウェイ | ★★★★ |
| キャニオン・クロス | 渓谷越え・打ち下ろし | ★★★★ |
| ロイヤル・クラウン | 長く狭い選手権コース | ★★★★★ |

固定シードで生成されるので、何度建設しても同じレイアウトになります。

### 自分でコースを作る
- `/golf generate <名前> [ホール数] [テーマ]` … ランダムなコースを生成（テーマ：meadow, coast, autumn, sakura, desert, snow, volcanic, mystic, canyon, royal）
- **コース設計ワンド**：金床でワンドに名前を付け（＝コース名）、ティーマーカー → カップの順に右クリックでホールを追加。
  スニーク＋右クリックでパー変更、グリーンを右クリックで傾斜の向き（スニークで強さ）を設定できます。
- コースに使うブロック：ティーグラウンド、ティーマーカー、フェアウェイ芝（縞模様用に2色）、カラー、グリーン、カップ、ピンフラッグ、ラフ各種、深いラフ、バンカー各種、カート道、OB杭。

## コマンド

```
/golf preset <プリセットID>       プリセットコースを目の前に建設
/golf generate <名前> [ホール数] [テーマ]
/golf courses                     コース一覧
/golf play <コース>                シングルプレイ
/golf vs <コース> [CPU数] [強さ]    CPU対戦（beginner/amateur/pro/legend）
/golf host <コース>                ロビー作成
/golf join <試合番号> / start / leave
/golf style <balanced|power|control|spin>
/golf delete <コース>              （OP）
```
`/birdie` でも同じコマンドが使えます。

---

## 設定（config/birdiecraft-common.toml / birdiecraft-client.toml）
持ち時間、最大打数（パー＋5）、天然の地面をOBにするか、風の強さ倍率、パワーショット数、建設速度、
ボールカメラ、落下地点表示、ピンの光の柱、ホールマップ表示 などを変更できます。

## ソースからビルドする場合
JDK 17 をインストールして、このフォルダで次を実行します。
```
gradlew build        （Windows）
./gradlew build      （Mac / Linux）
```
`build/libs/birdiecraft-1.0.0.jar` ができます。GitHubにpushすると、同梱の GitHub Actions でも自動ビルドされます。
