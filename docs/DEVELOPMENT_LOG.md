## 2026-11-08 — 0.5.1: 剣を振るとクライアントが落ちる不具合の修正

### 不具合
- 実機で剣を振った瞬間にクライアントがクラッシュ（`ArrayIndexOutOfBoundsException: Index 10 out of bounds for length 10`、
  `HumanoidModel.poseRightArm`）。
- 原因: 攻撃モーション用の腕ポーズ（Forge の拡張 enum `HumanoidModel.ArmPose`）を、最初に攻撃した時点で遅延生成していた。
  `HumanoidModel` の `switch` が使う対応表はその時点の `ArmPose.values()`（バニラ10個）の大きさで作られるため、
  後から足した11個目（序数10）は表に入らず、そのポーズで描画するたびに落ちる。

### 修正
- `WeaponAnimations.init()` でクライアント初期化時（`FMLClientSetupEvent` の `enqueueWork`、メインスレッド）に一度だけ生成し、
  描画中には決して生成しない（未生成ならバニラのポーズで描画）。

### 配布（0.5.1）
- GitHub Actions（`hotfix/0.5.1` 29a680e）: コンパイル・ユニットテスト成功、GameTest 44件すべて成功。
- `eternalrealm-0.5.1.jar`（13,873,438 バイト、SHA-256 `f6c77f38…2f7e`）を `mods/eternalrealm-0.1.0.jar` に上書きし、読み戻してハッシュ一致を確認。

### 影MOD（シェーダー）
- インスタンスには Oculus 1.8.0 と Embeddium 0.3.31 が入っていたが、`shaderpacks` が空だったため影が出ていなかった。
  オーナーの許可のもと、Complementary Reimagined r5.9.2（公式 GitHub、改変なし）を `shaderpacks` に置き、`config/oculus.properties` で選択。
  個人のプレイ用の導入で、再配布はしていない（リポジトリにも含めない）。
- Oculus の初期キー（K＝影の切替、R＝シェーダー再読込）が ETERNAL REALM の K（冒険手帳）・R（強攻撃）と重なり、強攻撃のたびに
  シェーダーが再読み込みされる状態だった → オーナーの `options.txt` で切替を F8、再読込を未割り当てに変更。0.5.2 からは MOD 側でも
  初回に自動で移動してチャットで知らせる（`KeyConflicts`）。
