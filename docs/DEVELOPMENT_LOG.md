  `HumanoidModel` の `switch` が使う対応表はその時点の `ArmPose.values()`（バニラ10個）の大きさで作られるため、
  後から足した11個目（序数10）は表に入らず、そのポーズで描画するたびに落ちる。

### 実装
- **プレイ報告の修正**: ボス撃破後の崩れ落ちる演出が途中で止まっていた（撃破の瞬間に戦闘の更新を止めていた）→ 演出が最後まで進み、報酬と出口が出る。
  王都の縁の地形のなじませ幅を広げ、地面の判定から木や水を除外。フィールドの湧き（上限・速さ・群れ）を約3倍。バニラのmobは自然湧き・地形生成の動物も含めて停止。
- **復活システム**（`revival`、`RevivalService`、`RevivalScreen`）: アストリアとダンジョンでは致命傷で死なずに「戦闘不能」になり、その場に倒れる
  （無敵・魔物とボスに狙われない・行動不可・三人称視点・体の上に「✝ 戦闘不能」）。復活画面から
  「その場で復活」（永久花の花びら、HP50%）／「帰還地点で復活」（フィールドは記録済みの最寄りの転移碑、王都は広場、ダンジョンは入口。2秒後から選べ、フィールド60秒・王都10秒・ダンジョン30秒で自動）、
  または仲間が花びらを使って蘇生。フィールドで倒れると設定の経験値ペナルティ（既定は次のレベルまでの5%、レベルは下がらない）。
  「強くなるには」に推奨レベル・未使用ポイント・回復薬・未強化装備・パーティの助言。パーティ枠に戦闘不能の表示。`/kill` や奈落は通常の死亡のまま。
- **永久花の花びら**（`everbloom_petal`）: 道具屋で400G。倒れた仲間に右クリックで蘇生。ボーナス宝箱・ヌシ・災厄からも出る。
- **ボス戦の画面**（`BossHudOverlay`）: バニラのボスバーを置き換え。名前・Lv・難易度、色の変わる多段HPバー（×N、削れた分は白く遅れて消える）、
  フェーズの印、激昂までの時間、シールド／無敵の表示、攻撃の詠唱バー（技名と溜まり具合）、右側に戦功ランキング（自分の行を強調）。
  戦闘ごとに与ダメージ・被ダメージ・戦闘不能・先制・とどめを記録し、点数で「殊勲」を決める（`boss.Contributions`）。
- **クリア報酬画面**（`DungeonResults`、`DungeonResultScreen`）: 「DUNGEON CLEAR」と評価（S〜C：制限時間の使い方と戦闘不能の回数）の判子、
  クリアタイム、パーティの与ダメージと被ダメージ（殊勲に王冠）、報酬が1つずつ枠に入る演出、伏せた3枚から1枚選ぶボーナス宝箱（評価が高いほど中身が良い）。
  殊勲者には強化石2個とボス素材1個を追加。選ばずに出ると1枚が自動で選ばれる。退出までの時間を20秒→45秒にし、すぐ出るボタンを追加。
- **フィールドの脅威**（`world.field.FieldThreats` / `Miasma`、`FieldThreatService`）:
  - **ヌシ**: 各フィールド2体（計20体、名前つき）。フィールドの強敵／普通の魔物の上位個体（体力6〜14倍・攻撃1.35倍・Lv+2、紫の炎のオーラ）で、縄張りを歩き回る。
    近づくと現れ、人がいないと眠り、倒されると7〜16分後に再び現れる。与ダメージ3%以上の人に素材・装備（確率）・花びら（確率）・経験値・ゴールド、殊勲者は上乗せ。結果は小さな画面で表示。
  - **瘴気**: 魔物を倒すとフィールドの瘴気が溜まる（普通8・強敵25・ヌシ150、10秒ごとに1自然に溜まる、満タン1000）。ミニマップの下にゲージ。
  - **災厄**: 瘴気が満ちると全員に「兆し」の告知、そのフィールドの霧が紫に濃くなる。60秒後に顕現し、誰かが巣に近づくと巣が平らな「爪痕」に変わってボス戦が始まる（近くの人は途中参加）。
    鎮めるとフィールドが10分間「浄化」され魔物の経験値+25%。誰も戦わないまま5分、または20分経つと去る。報酬は貢献者全員、結果はクリア報酬画面で表示。
    現在の災厄の体はダンジョンのボス（b1〜b8）の流用で、名前・称号は災厄ごと。専用の見た目は今後の魔物追加で作る。
  - **討伐手配書**（地図の上のボタン）: 全フィールドの推奨Lv・瘴気と状態・災厄・ヌシ2体（出現中／再出現までの時間）。地図にも出現中のヌシと目覚めた災厄の印。
- **スキルツリー**（別ブランチ `agent/skill-tree` から統合、`docs/modules/skills.md`）: 職業ごとに54個（3系統×6段、キャラクターLv1/8/18/24/30/40で解放）、
  前提スキル（例: ファイアボールLv5 → エクスプロージョン）、プリーストに聖属性の攻撃系統「審判」、スキルLv5まで、職業マスターで有料リセット、6つのスロット。
  職業ごとに使える武器を制限（ナイト: 片手剣・両手剣・槍／アサシン: 片手剣・双剣／メイジ: 杖／レンジャー: 双剣・弓／プリースト: 片手剣・杖／スペルブレード: 片手剣・両手剣）。
