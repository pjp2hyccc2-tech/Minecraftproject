# 乗り物（mounts）

オーナーの依頼（2026-11-11）: 「この3つの画像の乗り物を実装して、バイクはLv50、馬はLv10、鳥はLv30で買えるようにして。鳥は飛べる。
馬は速い、バイクはさらに早い移動が可能になる。」

| 乗り物 | id | 購入 | 価格 | 速さ（全力疾走との比） | 特徴 |
|---|---|---|---|---|---|
| 月鬣の軍馬（Moonmane Charger） | `horse` | Lv10 | 1,500 G | 約2.0倍（0.57 ブロック/tick） | ジャンプ約2.5ブロック |
| 蒼翼のグリフォン（Azurewing Griffin） | `griffin` | Lv30 | 12,000 G | 空で約2.0倍（地上は約1.1倍） | 飛べる |
| 星輪の魔導二輪（Starwheel Arcbike） | `bike` | Lv50 | 40,000 G | 約3.0倍（軍馬の約1.5倍） | ジャンプ約1.8ブロック、曲がると車体が傾く |

全力疾走 = バニラの地上の全力疾走（移動速度0.1×1.3、摩擦0.546で約0.286 ブロック/tick）。価格はその時点の稼ぎに合わせた（Lv10前後の
ゴールドの入り方で数回の冒険、Lv50の装備強化1〜2回分）。

## 買う
- 王都の **厩舎長ハルヴァン**（`NpcRole.STABLE_MASTER`、南門の内側、大通りの西の広場。ブループリントに `npc.stable_master` があればそこ）。
- メニュー（`MountStable`、サーバーのチェスト型メニュー）: 3頭それぞれに説明・速さ・飛べるか・価格・必要Lv。Lvが足りないものは
  赤字で「Lv○○になると購入できる」。買えるものは1回目のクリックで「もう一度クリックで購入」、2回目で購入（高い買い物の誤クリック防止）。
  持っているものはクリックで「次に呼ぶ乗り物」にする。下に所持金。
- 判定はすべてサーバー（`MountService.buy` → 純粋な `MountRules.purchase`: 所持済み → Lv不足 → ゴールド不足の順）。ゴールドを
  引いてから記録し、記録できなければ返す。
- 所有はキャラクターの拡張データ `mounts`（`MountOwnership`: `{"owned":[...],"selected":"..."}`）に保存。なくならない・消耗しない。
  シーズンが変わると新しいキャラクター（Lvもゴールドも最初から）なので、乗り物も買い直し（転移碑の記録や衣装と同じ扱い。D-MOUNTS）。

## 呼ぶ・降りる
- **U**（`key.eternalrealm.mount`）: 乗っていれば降りる。呼んでいる途中なら中止。それ以外は選んでいる乗り物を呼ぶ。
- **I**（`key.eternalrealm.mount_choose`）: 持っている乗り物の一覧。クリックで選んでその場で呼ぶ（別の乗り物に乗っていれば降りてから）。
- 呼び出しは **1秒**（20 tick、足元に光の粒）。1ブロック以上動く・戦闘になる・ボス戦に入る・水に入る・倒れると中止。
- 呼べない場所と状態（`MountRules.call`、優先順）: 持っていない／ダンジョン・レイド（ダンジョンの次元すべて）／戦闘不能／ボス戦の参加中／
  戦闘中（直近に攻撃した・された、`CombatDriver.inCombat`）／水・溶岩の中／乗り物の体が入らない狭さ。
- 乗っている間にダンジョンに入る（転移）とその時点で降りる（転移は騎乗を解く）。ボス戦が始まると乗り物は退く（「ボス戦が始まり、乗り物は退いた」）。
- 乗り物は乗り手がいなくなると消える（降りた・ログアウト・死亡・転移・サーバー停止）。エンティティは保存されない（`noSave`）。

## 操作（乗っている間）
| 操作 | 軍馬・二輪 | グリフォン |
|---|---|---|
| W/S/A/D | カメラの向きに進む・下がる（後退は約1/3）・横へ | 同じ（空中も） |
| Space | ジャンプ | 上昇（地上なら飛び立つ） |
| スニーク | 降りる | 空中は下降。地上で降りる（着地したときに押したままなら、一度離してからもう一度） |
| 何もしない | 惰性で止まる | 空中ではゆっくり滑空して下がる |

- 動きは `MountMotion`（純粋）: 目標速度へ一定割合で近づく加速、入力がなければ惰性、重力と空気抵抗、水中は遅く浮く。
- 乗り物は乗り手のクライアントが動かす（バニラの乗り物と同じ。`ServerboundMoveVehiclePacket`）。サーバーは見張りだけ:
  20 tick ごとの平均の速さが上限の1.35倍＋0.25を3回続けて超える、または飛行の上限より6ブロック以上高くで沈まずに3回続く → 降ろしてログ。
- **飛行の上限**（`MountRules.flightCeiling`）: 周囲（±12ブロックの9点）の一番高い地面＋32、ワールドの天井の8ブロック下まで。
  上限を超えていれば自然に沈む。ダンジョンの次元では呼べないので、飛んでダンジョンやボス部屋を飛ばすことはない。最終エリアも
  ボス戦の中では乗れない。
- 乗っている間は落下ダメージなし（乗り物も乗り手も）。空中で降りた（落ちた）乗り手は着地まで（最大20秒）落下ダメージなし。
  天井に頭が入っても窒息ダメージなし。
- 乗り物はダメージを受けず、狙われず（`isAttackable`/`canBeSeenAsEnemy`/`isPickable` が false、`CombatHits.isValidTarget` にも入らない）、
  押されず、爆発でも飛ばない。**大きな攻撃で落馬はしない**（決めたこと: 移動のための乗り物なので、魔物の群れの横を通り抜けられるように）。
  乗り手は攻撃されれば普通にダメージを受ける（回避は騎乗中は使えない: 既存の制限）。
- **乗ったままは戦えない**: 乗り手の攻撃（通常攻撃・スキル・矢や魔法）が当たると、その一撃は無効になり乗り手は降りる
  （「戦うには乗り物から降りる」）。速い乗り物で通り過ぎながら叩く戦い方を防ぐ。

## 見た目と動き
- モデルは `tools/art_entities/rig_mounts.py`（3つのリグ）と `generate_mounts.py` で生成（テクスチャ2倍密度、発光レイヤー付き）。
  参考画像に合わせた自作のデザイン（紋章は独自の四芒星）。`MountBodies.java`（鞍の高さと位置、当たり判定、車輪の半径）も生成。
- 軍馬: 待機（呼吸・首・耳・尾）、常歩（4拍子）、駆歩（体の揺れ、たてがみと尾がなびく）、ジャンプの姿勢。速さで重みをつけて混ぜる。
- グリフォン: 地上では翼をたたむ。空中では羽ばたき（上昇・飛び立ちは速く、巡航はゆっくり）と滑空を混ぜ、上昇・下降で体が傾く。
- 二輪: 車輪が走った距離だけ回り（青い輪は発光）、曲がると車体が傾いてハンドルが切れる。旗と吊り下げ旗が風になびく。加速で発光が強まる。
- HUD: 装備アイコンの左に乗り物アイコン（選んでいる乗り物の絵と U キー）。乗っている間は青い枠。持っていなければ表示しない。
  `HudLayout` の `mount()`（重なりのテスト対象）。

## 通信
新しいパケットはない（プロトコル版は変えない）。`UiActionPacket` の操作 `mount.toggle`・`mount.choose`（引数なし）、
`UiDataPacket` のチャンネル `mount_state`（`{"owned":[...],"selected":"...","riding":"..."}`、変わったときと1秒ごとの確認）。
→ [NETWORK_PROTOCOL.md](../NETWORK_PROTOCOL.md) 付録。

## コード
- 純粋（`mount`）: `MountKind`（id・必要Lv・価格・性能）、`MountMotion`、`MountRules`、`MountOwnership`、`MountBodies`（生成）。
- サーバー（`mount.forge`）: `MountEntity`、`MountEntities`（エンティティ型 `eternalrealm:mount_horse` ほか）、`MountService`、`MountStable`。
- クライアント（`client.mount`）: `MountClient`（キー・モデル・描画の登録）、`MountInput`、`MountModel`、`MountRenderer`。

## テスト
- オフライン: `MountMotionTest`（速さの順、向き、惰性、ジャンプ、水、飛行・上限・滑空・下降）、`MountRulesTest`（購入・呼び出しの判定、
  上限、所有のJSON、文言の ja/en と lang）、`HudLayoutTest`（乗り物アイコンの位置）。
- GameTest `MountGameTests`: Lvごとの購入（足りなければゴールドを取らない）・所持済み・ゴールド不足・選択、退出と再入場で所有と選択が残る／
  呼ぶと乗っている、乗り物は傷つかず狙われない、鞍の上からの攻撃は当たらず降りる、降りると消える、戦闘中とダンジョンでは呼べない／サーバーの物理で二輪＞軍馬＞全力疾走／
  グリフォンが上限まで上がり超えない・滑空はゆっくり・下降は速い・空中で降りると落下ダメージなし、軍馬はジャンプしても飛ばない。
