# テスト用キット（test kit）: 最大化と見学用の屋敷

オーナーの依頼（2026-11-11）:「テスト用に、すべての部屋とギルドハウスの開放とお金をマックスとレベルとステータスポイント、
スキルポイントをマックスにするコマンドを実装して」

管理者（権限2）だけが使えるテスト用のコマンド。キャラクターを一度で最大にし、宿屋の客室5室とギルドハウス20軒を
**すべて見学できる** ようにする。どれもゲームと同じサービスを通すので、検証・保存・画面の更新は普通に遊んだときと同じ。

| 場所 | 内容 |
|---|---|
| `player.PlayerDataService#maxOut`（純粋） | レベルを上限へ、所持金を上限へ、ステータスとスキルのポイントをすべて戻す |
| `estate.Showcase`（純粋） | 見学用の屋敷のキー（持ち主 = 種類と間取りから決まる固定の id） |
| `estate.forge.Showcases` | 見学パス（プレイヤーの永続データ）、見学できる間取りの登録、建てる・入る・状況 |
| `estate.forge.EstateService#mayAccess` | 見学用の屋敷にはパスを持つ人（とクリエイティブの管理者）だけが入れる |
| `estate.forge.InnService` / `ui.estate.InnScreen` | 女将の画面の「見学」ボタン（パスを持つ人だけ） |
| `guild.house.forge.GuildGates` / `GuildHouseEvents` | パスを持つ人は門から見学用のハウスへ。見学用のハウスでは鐘は誰も呼ばず、金庫は開き、出し入れは記録しない |
| `testkit.TestKitCommands` | `/eternalrealm admin test ...`（`/er` でも同じ） |

## 1. コマンド（権限2、プレイヤーを省くと自分）

| コマンド | 内容 |
|---|---|
| `/er admin test all [<プレイヤー>]` | 下の `max` と `unlock` を一度に |
| `/er admin test max [<プレイヤー>]` | Lv を上限（設定の `levelCap`、既定 100）に、所持金を上限（9,999,999,999 G）に。割り振り済みのステータスと習得済みのスキルはすべて戻し、上限の全ポイントが未使用になる（既定で ステータス 297・スキル 218）。スキルの装備欄は職業の初期に戻る。職業はそのまま |
| `/er admin test unlock [<プレイヤー>]` | すべての部屋とギルドハウスを開放: 見学パスを渡し、まだない見学用の建物（客室5・ギルドハウス20）を建てはじめる |
| `/er admin test lock [<プレイヤー>]` | 見学パスを取り上げる（見学中なら外へ出る）。建物はそのまま残る |
| `/er admin test tour <room\|guild> <間取り>` | どこからでもその見学用の建物へ（候補は Tab で出る）。まだなければ建てはじめ、進み具合を表示 |
| `/er admin test status` | 見学用の建物の完成数・建築中（%）・未着手、パスを持つオンラインのプレイヤー |

- `max` はレベルを直接上げるので、獲得 EXP（ランキング）は増えない（`/er admin level set` と同じ）。
- 権限のないプレイヤーには `admin` 以下が見えず、実行もできない。

## 2. 見学用の屋敷（showcase）

- 客室とギルドハウスは「1人1部屋」「1ギルド1軒」なので、自分の部屋やハウスとは別に、**間取りごとにもう1つ** 見学用の建物を
  屋敷の次元に建てる。持ち主は `UUID.nameUUIDFromBytes("eternalrealm:showcase/<種類>/<間取り>")`（`Showcase.owner`）: 再起動しても
  同じ建物が見つかり、プレイヤーやギルドの id（ランダム、またはプレイヤー名から作る id）と重なることはない。
- 建てる仕組み・区画・保護・保管・模様替えの照合は普通の屋敷とまったく同じ（[estates.md](estates.md)）。建築は1件ずつ順番に進むので、
  25件を全部建て終えるまで少しかかる（その間も建ち終えたものから入れる）。見学用の建物は取り壊さない。中にしまった物はそのまま残る。
- **入れる人**: 見学パスを持つ人と、クリエイティブの管理者（どの屋敷にも入れる）。パスを取り上げられた人は 0.5 秒ごとの見張りで外へ。
- **見学パス**: プレイヤー自身の永続データ（`eternalrealm_showcase_pass`）。プレイヤーと一緒に保存され、死んでも残る。
- **入り方**
  - 客室: 宿屋の女将の画面で部屋を選び「見学」（自分が借りている部屋とは別。準備中は「準備中 n%」）。または `tour room <間取り>`。
  - ギルドハウス: ギルド門の広場で、自分のギルドが持っていない間取りの門をくぐる → その見学用のハウスへ（まだなければ建てはじめ、
    進み具合を表示して押し戻す）。自分のギルドの間取りの門は今までどおり自分のハウスへ。または `tour guild <間取り>`。
  - 着くと「見学: <間取り>」の表示。出るときは部屋の扉のメニュー、ハウスの帰りの門（どちらも来た場所へ）。
- **見学用のハウスの中**: 掲示板は見ている人のギルドのもの（ギルドがなければ空）、集合の鐘は誰も呼ばない（その旨を表示）、
  金庫はパスを持つ人なら開く、チェストの出し入れは記録しない（どのギルドのものでもない）。案山子・作業台・噴水などはそのまま。

## 3. テスト

- 純粋: `ShowcaseTest`（25件それぞれ別の固定の持ち主、プレイヤーやギルドの id は見学用にならない、持ち主から間取りを引く、
  不正な名前）、`PlayerDataServiceTest#theTestKitMaxesTheCharacterOutWithEveryPointUnspent`（上限・所持金・全ポイント未使用・
  職業はそのまま・獲得 EXP は増えない・設定の上限が低いサーバー・保存）。
- GameTest `TestKitGameTests`: 本物のコマンド（`/er` の別名から）で権限なしは何も変わらず、権限2で最大化される。パスを持つ人は
  門で待たされたあと見学用のハウスに入り、帰りの門で出る。客室の見学、女将の画面の「見学」はパスを持つ人だけ、パスのない人は
  どこにも入れない、パスを取り上げると外に出される。

## 決定事項（Decisions）

- **「開放」= すべての間取りに入れること**: 部屋とハウスは1人（1ギルド）1つの決まりなので、それを崩さずに全部を確かめられるよう、
  間取りごとの見学用の建物を別に建てる方式にした。自分の部屋やハウスはそのまま（所持金が上限なので、借りる・買う・模様替えも
  そのまま試せる）。
- **パスで入れる**（権限だけで入れない）: 管理者が普通にギルド門の広場を歩いても、パスがなければ門は今までどおり。テストのときだけ
  `unlock` で開き、`lock` で戻す。
- **持ち主は固定の id**: 見学用の建物を覚えておく表がいらず、何度 `unlock` しても同じ建物を使う。
- **ポイントの最大 = 上限レベルで得る全ポイントを未使用に**: 割り振りを戻すので、テストのたびに自由に振り直せる。上限を超えるポイントは
  作らない（ゲームの決まりのまま試す）。
