# 伝説の旅人（travellers）: シングルプレイで仲間になる4人

オーナーの依頼:

- 2026-11-12（最初）: 4人のキャラクターを隠し要素としてフィールドに出現させ、AIを備えて実際に冒険したり宿にいたり買い物したり
  するように。シングルプレイの際だけ出現。言動・アニメーション・スキルや魔法の見た目と効果も高品質に。
- 2026-11-12 12:13: 4人の肩書きを変えて作り直す。**かつてこの国を単独で護りきった流離の魔女**、**ドラゴンを鉄剣だけで退けた騎士**、
  **全てのダンジョンEX級を踏破した唯一の存在の魔剣士**、**治療法の見つからなかった疫病が蔓延した王国を聖なる魔法で生き返らせた
  シスター**。シングルプレイだけで、見掛けて声をかけたらパーティーに入れて共に冒険できる。ステータスは肩書き通りの強さ。装備は
  それぞれ特殊な装備にして、テクスチャやアニメーションに力を入れて派手に。魔女とシスターは綺麗なお姉さん、騎士と魔剣士は格好よく。
- 2026-11-12 12:16: スキルや必殺にも演出を入れて、4人それぞれ特別なものを格好よく、綺麗に。

4人は **オリジナルのキャラクター**（名前・姿・技・台詞すべて）。最初の依頼の画像は他社作品の登場人物だったので、その再現はしていない
（[DECISIONS.md](../DECISIONS.md) の D-TRAVELLERS）。

- **肩書き通りの強さ**: 4人ともレベル上限（Lv100、パーティー枠の表示も Lv100）。HP はどのプレイヤーより高く、魔物の一撃は
  「その魔物がプレイヤーに与えるダメージ × 受けるダメージ率」しか通らない（騎士は15%、誓いの間はさらに×0.3）。
- **技の強さは相手に合わせて測る**: 1撃 = 「敵のレベルに見合ったプレイヤーの軽い一撃（`MonsterScaling.referenceLightHit`）× 技の倍率」。
  ふつうの魔物はその一撃およそ4回分の HP なので、どのレベルでも通常攻撃2〜3回、強いスキルなら1つで倒れる。必殺は範囲の敵それぞれに
  およそ12回分（エリートもほぼ一撃）。ボスは **35%**（`BOSS_SHARE`）しか受けない: 伝説の旅人は助けるが、ボス戦はプレイヤーの戦いのまま。
- **とどめはプレイヤーのもの**: 仲間の一撃はプレイヤーの一撃として扱う（経験値・お金・ドロップ・クエストの討伐数）。ダメージの数字も
  プレイヤーに見える（スキルは色つき、会心は大きく）。
- **傷つけられるのは魔物とボスだけ**: プレイヤー・落下・炎・窒息などでは減らない（奈落などの「無敵を貫く」ダメージだけは通る）。
- **倒れても死なない**: HP が尽きると **戦闘不能**（その場に倒れる。魔物は狙わなくなる）。15秒で HP 4割で起き上がる。シスターの
  聖域・必殺なら **その場で全快** で起き上がる。戦っていない間は毎秒最大HPの2%回復。
- 縮尺: ロザリンド 1.0、ジークヴァルト 1.06、ケイレン 1.0、マリエル 0.98（当たり判定も追従）。

## 2. 技（スキルと必殺）

それぞれ **通常攻撃2つ**（交互）、**スキル2つ**、**必殺1つ**。技を出すと体がその技のアニメーションを演じ、振り下ろした瞬間に
打撃が入る（`HeroBodies.hits`）。スキルは掛け声（会話ボックス、肖像つき。同じ人は12秒に1回まで）、必殺は必ず掛け声とアクションバーの技名。
光の演出は2層: サーバーのパーティクル（シェーダーパックでも見える）と、クライアントの **光の演出**（`HeroFx`。加算合成の光の帯・
輪・星・リボンを各自の色で。シェーダーパック使用中は省く）。大技は近くのプレイヤーの画面を揺らす。

倍率は1撃あたり（×回数）。CT はクールタイム。

### 戦い方（`Travellers.choose`）

- **必殺**: 敵が3体以上固まっている、ボスかエリート、または味方のHPが4割を切った（ロザリンド・ジークヴァルト・ケイレン）。
- **ジークヴァルト**: 誰かが敵に狙われている・敵が3体以上 → 不動の誓い。ほかの敵が仲間を狙っていればそちらを優先して引き受ける。
- **マリエル**: 戦っていなくても仲間を見ている（プレイヤーが倒れた → 王国再誕の祈り、仲間が倒れた・誰かの HP が6割を切った →
  癒しの聖域）。戦いの中では、誰かが倒れた・HP が35%を切った・2人以上が傷ついた → 王国再誕の祈り、HP が7割を切った → 癒しの聖域。
  誰も傷ついていなければ浄化の光柱と光の弾・光の槍で戦う。
- **ロザリンド・ケイレン**: スキルが使えれば使い、なければ通常攻撃を交互に。ロザリンドとマリエルは近づかれると下がる。
- 敵の選び方: 近さを基本に、プレイヤーを狙っている敵、仲間を狙っている敵（騎士は特に）、プレイヤーが殴った敵を優先する。

## 3. 暮らしと出会い

- **シングルプレイだけ**: 統合サーバー（シングルプレイのワールド）で、LAN に公開しておらず、ワールドの持ち主1人しかいないとき。
  LAN に公開した・ほかの人（テストボットを含む）が入った → その場で姿を消す（仲間の記録は残り、シングルプレイに戻ればまた現れる）。
  専用サーバーには出ない。
- **巡り**: フィールド（6〜10分）→ 道具屋（2〜4分）か宿（3〜6分、夜は6〜10分）→ … → フィールド。フィールドでは生息地の1つに
  いて、そこの魔物と戦い、合間に狩り場を歩く。狩り場は6割の確率でプレイヤーから240ブロック以内の生息地、直前と同じ場所は選ばない。
  巡りはワールドに保存され、ワールドを閉じている間は進まない。
- **出現**: 居場所から56ブロック以内にプレイヤーが来ると現れる（近くで見ていれば転移碑の旅のような光と音）。104ブロック離れると消える。
  体はワールドに保存されない。次の場所へ移るときは光と共に旅立つ（戦い・会話の最中は少し待つ）。
- **道具屋**: 店主の近くに立ち、ときどき言葉を交わして買い物をする（硬貨の光と音）。**宿**: 女将のいるロビーで休む。
- **出会い**: 初めて7ブロック以内で姿が見えると、出会いの台詞（3行、肖像つき）、「〈肩書き〉〈名前〉と出会った（伝説の旅人 n/4）」の
  知らせ、そして **「一緒に来てほしい／またの機会に」の選択肢**。出会った人はキャラクターの拡張データ（`travellers_met`）に残る。
- **話しかける**（右クリック）: 立ち止まって向き直り、居場所ごとの台詞（各3つ）と、もう一度「一緒に来てほしい」の選択肢。

## 4. 仲間（パーティー）

- 「一緒に来てほしい」を選ぶと承諾の台詞、加入の身振り（それぞれの決めポーズと光）、「〈肩書き〉〈名前〉がパーティーに加わった！」。
  4人全員を同時に連れて歩ける。仲間はキャラクターの拡張データ（`travellers_party`）に残り、ワールドを出入りしても、ログインし直しても、
  ディメンションを移っても（ダンジョン・王都・フィールド）プレイヤーの隣に現れる。
- **隊列**: プレイヤーの後ろ、左右に1人ずつ・その後ろに2人。離れると急ぎ足、24ブロック以上離れた・引っかかった・飛んで行かれたら
  光と共にプレイヤーの隣へ移る。
- **戦い**: プレイヤーから14ブロック以内の魔物とボスに向かい、それぞれの役割で技を使う。プレイヤーが22ブロック以上離れると戦いを
  やめて戻る。
- **パーティー枠**: 仲間は「✦名前 Lv100」でHPと戦闘不能が見える。ほかのプレイヤーとパーティーを組んでいなくても、仲間だけの
  パーティーとして表示される。パーティーの頁（冒険手帳）では肩書きが出て、**別れる** ボタンがある。
- **別れる**: 仲間に話しかけると「このまま一緒に／ここで別れる」の選択肢。別れると別れの台詞と共に旅立ち、自分の巡りに戻る（また会えば
  誘える）。
- **管理コマンド**（チート有効のシングルプレイ）: `/er admin travellers summon [rosalind|siegwald|kaylen|mariel]` で全員（または1人）を
  その場に呼んで仲間にする（出会い済みにもなる）。`/er admin travellers part` で全員と別れる。

## 5. 見た目とアニメーションの作り方

- **英雄リグ**（`tools/art_entities/rig_hero.py`）: 町のNPCの2倍の細かさ（1単位2テクセル、顔は16×16）、101部位・120箱、
  テクスチャ 512×256（＋発光層 `_glow`）。腕は細身（女性）と標準、胴は標準と幅広（騎士）、肘・膝の関節、指先までの装備
  （杖・魔導書・鉄剣・ルーンの剣と鞘・幻の刃・聖女の杖・祈祷書・光輪・マント・コートの裾・ドレス…）。
- **4人の絵**（`hero_cast.py` の姿と部位、`hero_looks.py` の配色と描画、`hero_paint.py` の描画の道具）: 顔（女性は2列の瞳と
  まつげ・唇、男性は2×2の瞳・鋭い眉・古傷）、髪（頭頂・前髪・房・長い流れ）、布（陰影・ひだ・縁取り・刺繍）、金属（鋼の照り返し・

- 純粋 `TravellersTest`: 4人それぞれ体（1単位2テクセルのテクスチャと発光層）・96×96の肖像・名前・肩書き・出会い・居場所ごとと仲間の台詞・
  誘い・承諾・断り・別れ・倒れる・起きる・技の名前と掛け声が日英そろう / 1人5つの技（通常2・スキル2・必殺1）、どの技にも

  役割ごとの技の選び方 / 隊列 / 巡り・滞在時間・狩り場 / 計画と記録の読み書き。
- GameTest `TravellerGameTests`: テストサーバーはシングルプレイではないので出ない / ケイレンが魔物に向かって技で斬る（英雄の体）/

## 決定事項（Decisions）

- **他作品のキャラクターは再現しない**: 名前・姿・技・台詞はすべてオリジナル（D-TRAVELLERS）。肩書きはオーナーの指定どおり。
- **専用の英雄リグ**: 町のNPCの体（8×8 の顔、4スロット）では「派手な装備」「戦いのアニメーション」が描けないので、2倍の解像度と
  12スロットのリグを別に作った。技の打撃はアニメーションの打撃の瞬間に合わせる（見た目と当たりがずれない）。
- **強さは相手に合わせる**: 固定のダメージだと序盤は強すぎ終盤は弱すぎるので、敵のレベルに見合ったプレイヤーの一撃の倍数にした。
  ボスは35%: 4人がいてもボス戦はプレイヤーが主役。
- **死なないが倒れる**: 伝説の存在なので死なない。ただし倒れる（戦闘不能）ことで、シスターの蘇生や騎士の守りに意味がある。
- **仲間はキャラクターに記録し、体は保存しない**: 体は必要なときに監督（`TravellerDirector`）が連れてくる。ワールドに古い体が残らず、
  ディメンションを移っても隣に現れる。
- **パーティー枠は仮想パーティー**: ほかのプレイヤーとのパーティーの仕組み（招待・リーダー・レイド）には入れず、枠の表示にだけ加える。
- **名前は「伝説の旅人」（travellers）**: フィールドの「放浪する大物」（`world.field.Wanderers`、[field_threats.md](field_threats.md)）と
  取り違えないように。
