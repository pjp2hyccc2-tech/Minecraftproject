# マップ（`world.map` / `client.map` / `ui.map` / `world.forge.MapSync`）

ミニマップ（HUD右上）と世界地図（M）。地形の色はクライアントが読み込んでいるチャンクから、アストリアの全図は純粋モジュールの
レイアウト（`AstoriaLayout`）から自前で描き、クライアントが知り得ない情報（解放済み地域・パーティーの位置・NPCのクエスト印・
ダンジョンの見取り図）だけをサーバーが1秒ごとに送る。

## 1. 操作

| キー（初期設定） | 内容 |
|---|---|
| M | 地図を開く（フィールドマップ）→ もう一度で全域マップ → もう一度で閉じる（冒険手帳の「地図」ボタンからも開ける） |
| Tab（地図を開いているとき） | フィールドマップ ⇔ 全域マップ |
| N | ミニマップの表示切替（設定に保存） |
| = / - | ミニマップの拡大／縮小（半径 32・48・64・96・128 ブロックの5段階、設定に保存） |

世界地図: ドラッグで移動、ホイールでカーソル位置を中心に拡大縮小、矢印キーでも移動、「現在地」で自分の位置へ、フィールドをクリック（ドラッグせずに）
するとそのフィールドマップ、カーソルを合わせると詳細
（地域名・推奨レベル・封印/未踏・その場所のバイオーム・座標、マーカーの名前など）。キーはオプション → 操作設定 → ETERNAL REALM で変更できる。

クライアント設定 `config/eternalrealm-client.toml` の `[minimap]`: `enabled`（表示）, `size`（直径 64〜192、既定96）, `zoom`（0〜4）,
`rotate`（自分の向きに合わせて回転。既定は北が上）, `coordinates`（座標の表示）。

## 2. ミニマップ（`client.map.Minimap`, `ChunkColors`, `ui.map.MinimapOverlay`）

- 丸い地図。画面右上（状態異常アイコンが出ているときはその下）に表示。F3 デバッグ画面と GUI 非表示（F1）では隠れる。
- 地形: 読み込み済みチャンクの最上部ブロックの地図色（草・葉・水はバイオームの色で着色）、北側との高低差で陰影（バニラ地図と同じ規則）、
  水は深さで暗く。`DynamicTexture`（256×256ブロック）は折り返す窓（`world.map.ScrollingWindow`、2026-11-13 D-LIGHTWEIGHT）:
  ワールドのブロック (x, z) はいつもテクセル (x mod 256, z mod 256) にあり、描くときは繰り返すテクスチャ座標 x / 256, z / 256 で
  描く。プレイヤーが動くと新しく見えた帯だけ、新しいチャンク色ができるとそのチャンクだけ塗って、その部分だけ送る（最短2tickごと。
  256ブロック以上の移動・次元や洞窟モードの切り替えでは全部を一度塗り直す）。チャンク色は1tickあたり最大5チャンク（初回10）を
  近い順に計算し、最大1600チャンクをLRUで保持。足元の3×3チャンクは2秒ごとに再計算し、変わっていたときだけ塗り直す。
- 洞窟モード: ダンジョン次元・天井のある次元・地下深く（地表より12ブロック以上下で空が見えない）では、足の高さの床を表示する
  （壁は暗く、何もない所は透明）。これでダンジョンの部屋と通路がそのまま地図になる。洞窟モードでは `rotate` を無視して北を上にする。
- マーカー: 自分（矢印）、北（N）、パーティーメンバー（範囲外は縁に固定、リーダーは金色）、町のNPC（クエスト印 `!` 受注可 / `?` 報告可）、
  ダンジョン入口（封印中の地域は灰色）、王都、終焉の塔、ダンジョン内の罠（赤い三角）、クエストの道案内（黄色い点々と、行き先の
  金の星。行き先が地図の外なら縁に金の三角。§7）。
- 下段: 現在の地域名（地域色）と推奨レベル、ダンジョン内ではダンジョン名と「部屋 2/4」「ボスの間」、道案内中は「▶ 森の賢者と話す 238m」、
  座標。

## 3. 世界地図（`ui.map.WorldMapScreen`, `AtlasTexture`, `FieldMaskTexture`, `world.map.AtlasPainter`, `FieldMaskPainter`）

2つのタブ。
- **フィールドマップ**（最初に開く）: 自分のいるフィールドの範囲（`FieldLayout.regionBounds`）に合わせて拡大し、フィールドの外を暗いベールで覆い、
  境界をそのフィールドの色の線で描く（`FieldMaskPainter` が 384×384 の重ね絵を別スレッドで描き、フィールドごとにキャッシュ）。左上に
  パネル: フィールド名・推奨レベル・説明・転移碑（記録済みか）・ダンジョン（推奨レベル）・封印/未踏。
- **全域マップ**: 王国全体（x −1700〜1700, z −1500〜1300）が収まる倍率。全フィールドの名前と推奨レベル（封印中は灰色）。
- 共通: 全図の絵（`AtlasPainter`、1024×1024、初回のみ約0.5秒）、王都・終焉の塔・ダンジョン入口・**転移碑**（記録済みは青く光る）・
  近くの町NPC（拡大時）・パーティーメンバー・自分。
- **転移メニュー**（転移碑に触れたとき、`openTravel`）: 全域マップ＋右側に転移碑の一覧。フィールドごとの見出し（記録数/総数）の下に
  記録済みの転移碑（今いるフィールドは全部、未記録は灰色）。ホイールでスクロール。記録済みの転移碑を一覧か地図でクリックして
  「転移する」。クールダウン中は残り秒数。決定はサーバーが検査する（worldgen.md §1.1）。
- **生息地**（`world.field.Habitats`）: フィールドタブでは そのフィールドの、全域でも拡大すると全フィールドの生息地を円で描く
  （中心部の円と、魔物が湧いて歩き回る1.5倍の範囲の薄い輪。2026-11-12）。
  色はプレイヤーのレベルとの比較（緑＝格下、金＝適正、赤＝格上）。さらに拡大すると魔物の名前とレベル、マウスを乗せると
  レベル・主な落とし物。
- ダンジョン内で開くと、そのインスタンスの見取り図（入口の広間・通路・部屋（攻略済み=緑、現在=金）・ボスの間（戦闘中は点滅）・罠・
  メンバー・自分）を表示。
- アストリアのないサーバー（オーバーワールドが舞台）では、バイオームの代わりに地域の輪だけを描く（ダンジョン入口は出ない）。

## 4. サーバーが送るもの（`world.forge.MapSync` → UIチャンネル `map`）

新しいパケットは追加していない（既存の `UiDataPacket`、プロトコル版は変更なし）。毎秒1回、内容が変わったプレイヤーにだけ送る
（ログイン時は必ず送る）。形式は純粋な `world.map.MapView`（`toJson` / 寛容な `fromJson`。欠けた値は既定値、リストは上限で切る）。

| キー | 内容 |
|---|---|
| `realm` | 舞台の次元ID・輪の中心・アストリア次元かどうか |
| `unlocked` / `discovered` / `final` | 解放済み地域（`WorldProgress`）、本人が訪れた地域（`Discovery`）、最終ボス解放 |
| `waystones` | 本人が記録した転移碑のID（なければ省略） |
| `party` | 自分以外のオンラインメンバー: UUID・名前・次元・座標・向き・HP割合・リーダー（最大40） |
| `npcs` | 自分から水平96ブロック以内の町NPC: 座標・役割・名前（テキスト部品のJSON）・クエスト印（最大64、近い順） |
| `dungeon` | 参加中のインスタンス: ID・名前キー・原点・広間/部屋/通路/ボスの間の矩形・現在の部屋・ボス戦中か・固定位置の罠 |

クライアントが自分で知っているもの: 地域の輪・名前・推奨レベル（`Areas`）、バイオーム（`AstoriaLayout`）、ダンジョン入口と推奨レベル
（`MapMarkers` ← `LandmarkSites` / `Dungeons`）、王都・塔の位置、地形（読み込み済みチャンク）。
パーティーメンバーが描画範囲内にいるときはクライアント側の実体の位置を使う（滑らか）。

## 5. 構成

| パッケージ | 内容 |
|---|---|
| `world.map`（純粋） | `MapView`（送信形式）, `MapMarkers`（固定マーカー・転移碑）, `AtlasPainter`（全図の画素）, `FieldMaskPainter`（フィールドマップの重ね絵）, `MapMath`（色・陰影・ミニマップ座標）, `MapViewport`（パン・ズーム） |
| `world.forge.MapSync` | 送信（`@Mod.EventBusSubscriber`、サーバーtick） |
| `dungeon.forge` | `DungeonService.mapView(uuid)` → `DungeonInstance.mapView()` |
| `client.map` | `MapKeys`（キー・HUD登録）, `MapClientEvents`（キー処理・毎tick処理・ログアウト時の破棄）, `ClientMapState`, `Minimap`, `ChunkColors` |
| `ui.map` | `MinimapOverlay`, `WorldMapScreen`（タブ・転移メニュー）, `AtlasTexture`, `FieldMaskTexture`, `TravelFlashOverlay`（転移の白い光）, `MapDraw`（円・環・三角・転移碑・テクスチャ付き円・点々の描画） |
| `quest.QuestGuide`, `world.guide`（純粋） | 道案内の行き先（`QuestGuide`）、アストリアの場所（`AstoriaPlaces`）、道探し（`PathSearch`）。§7 |
| `quest.forge.QuestGuides`, `npc.forge.NpcWhereabouts` | 行き先の送信、クエストNPCの居場所 |
| `client.guide` | `GuideClient`（道探しと点々）, `ClientTerrain`（地形の判定）, `GuideRenderer`（地面の点々） |

共有ファイルへの変更は小さな追加のみ: `JournalScreen`（「地図」ボタン）、`ERClientConfig`（`[minimap]`）、`DungeonInstance` / `DungeonService`
（見取り図）。キーとHUDの登録は `client.map.MapKeys` が自前で行う（`ClientKeyMappings` のカテゴリーを共有するのでキー衝突の自動回避の対象）。

## 7. クエストの道案内（`quest.QuestGuide`, `world.guide`, `client.guide`, 2026-11-13）

入り組んだ道で迷わないように、案内中のクエストの次の目的地まで、地面に**黄色い点々**を並べる（ミニマップにも点々と金の星）。

- **どのクエストを案内するか**: 冒険手帳のクエストのページで、受けているクエストごとの「案内」ボタン。押したクエストが「案内中」
  （金色）になり、もう一度押すと案内をやめる。何も選んでいなければメインクエスト、なければ最初に受けたクエスト（`QuestGuide.guided`）。
  選んだクエストを報告・破棄すると既定に戻る。選択はログアウトで忘れる。
- **行き先（サーバー、`QuestGuides` → UI チャンネル `quest_guide`、毎秒・変わったときだけ）**: 報告できるなら依頼主（その地域の
  クエストNPC）、でなければ最初の未達成の目的（`QuestGuide.target`）:

  | 目的 | 行き先 |
  |---|---|
  | NPC と話す／報告 | その NPC の居場所（サーバーが最後に見た位置 `NpcWhereabouts`。まだ見ていなければ、各地のクエストNPCは自分の地域の決まった門の横、草原の NPC は王都の中央） |
  | 地域に着く | いまの位置からその地域の中心へまっすぐ進み、地域に入って 24 ブロック先 |
  | 魔物を倒す | その魔物のいちばん近い生息地（`Habitats`。地域の指定があればその地域のもの。「どの魔物でも」は地域の最寄りの生息地） |
  | 物を集める | その物を落とす魔物のいちばん近い生息地 |
  | ダンジョン／ボス | そのダンジョンの門（終焉の塔は塔の門） |

  アストリアの外（ダンジョンの中など）では案内しない。行き先は整数ブロックに丸めて送る。
- **道（クライアント、`GuideClient`）**: 読み込み済みのブロックの上で A*（`PathSearch`）。1tick に 1500 か所まで調べ、半径 96 ブロック・
  3万か所まで。歩ける所＝足と頭の2マスが空いていて床がある（ハーフブロック・カーペット・少しの雪も床。木のドアと柵の門は通れる）。
  1段の段差は登り、3段までは飛び降りる。斜めは平らな所だけで角は切らない。水は泳げるが遠回りより高くつき、溶岩・火・マグマ・サボテン・
  スイートベリー・粉雪・ウィザーローズの上は通らない。行き先まで届かないとき（遠い・読み込まれていない）は**いちばん近づける所まで**の
  点々を出し、歩くにつれて（3秒ごと・12ブロック動いたら）探し直す。点々から 4 ブロック以上外れたらすぐ探し直す（最短 0.5 秒おき）。
  通り過ぎた点は消える。行き先の 3 ブロック以内に着くと点々は消える。
- **見た目（`GuideRenderer`）**: 1.25 ブロックおきの小さな光る円盤（芯は明るい黄、まわりは淡い金のにじみ）。光の波が足元から行き先へ
  ゆっくり流れる。56〜80 ブロックで薄れて消え、足元の点は淡い。行き先まで届いた道の終わりには金の光の柱と脈打つ輪。深度は書かず、
  地面より少し上（壁の向こうの点は見えない）。描画エラーが出たら点々だけ止まる（ログに記録）。
- **ミニマップ**: 点々（縮尺にかかわらず約 3.5 px おき、まとめて1回の描画）、行き先の金の星（脈打つ）、地図の外なら縁の金の三角。
  下段に「▶ 森の賢者と話す 238m」（行き先までの水平距離）。
- **設定**: 設定画面「クエストの道案内」（`[guide] questPath`、既定オン）で点々・星・下段の行をまとめて消せる。

テスト: `PathSearchTest`（まっすぐ・壁を回り角を切らない・1段は登り2段は登らない・3段までの飛び降り・溶岩を通らず水は高くつく・
届かないときは半径内のいちばん近い所まで・少しずつ探せる・立てない所からは失敗・カーペットの上を歩く・点々の間隔）、`QuestGuideTest`
（地域に着く→その地域の依頼主・狩りは最寄りの生息地・ダンジョン／ボスは門で報告は依頼主・集めるは落とす魔物の生息地・サーバーが見た
NPC の位置が優先・地域の中ならその場・メインクエストが既定で選べば選んだもの）。**未確認**（実機クライアントが必要）: 点々の見た目と重さ、入り組んだ王都での道の質、遠い行き先で
探し直すときの点々の伸び方、ミニマップの星と縁の三角、橋・はしご・ツタ（はしごとツタは道に使わない）。
