# ボス・ダンジョン（`boss` / `dungeon` パッケージ）

純粋モジュール（Minecraft非依存）。ボスが「いつ・何を」するか、ダンジョンの「形」と「進行」を決める。実際の描画・ダメージ・召喚・ブロック設置は Forge 層が行う。
時間はサーバーtick（`long`）、乱数は注入（`RandomGenerator` / レイアウトはシードから `java.util.Random`）。同じ入力とシードなら必ず同じ結果。サーバースレッド専用。

## 1. 主なクラス

| パッケージ | クラス | 役割 |
|---|---|---|
| boss | `BossDefinition` / `BossPhase` / `BossAbility` / `AbilityKind` / `DifficultyTuning` / `Difficulty` | 不変の定義（検証付きレコード）。`BossPhase` は変身技（`transitionId`）と激昂フラグ（`enrages`）を持てる |
| | `BossBrain` | ボス1体ごとの状態マシン。`tick(now, hp割合, ボス位置, 対象一覧)` → `BossCommand` の列。`setArena(中心, 半径)` で闘技場を教えると盤面・安全地帯・散布が床に揃う |
| | `BossShape`（Circle/Cone/Line/Ring/Arena/Square/Cross/Outside） | 絶対座標の攻撃範囲。`contains(x,y,z)` でプレイヤー（足元）を判定。Line は描画どおりの長方形（端の丸みなし） |
| | `BossCommand` | PhaseChanged / AbilityStarted / Telegraph / SafeSpot / Cancelled / Execute / Volley / Displace / Hazard / Dash / Summon / Teleport / ShieldChanged / Enraged / Heal / Buffed |
| | `AbilityLook` | 技ごとの見た目: 予兆の色（`Telegraph.Style`）、命中時の演出（`Effect`）、小道具のブロック。全技に定義（テスト） |
| | `BossMarkers` | `BossShape` → 地面マーカー（`combat.Telegraph`）。全体攻撃と安全地帯の外側は闘技場サイズの円 |
| | `DefeatSequence` | 撃破演出のタイムライン（崩れ落ち・閃光・爆発・衝撃波・光の柱・消滅）。通常5秒、終焉の王9秒 |
| | `BossTexts` | 演出用の文言キー（安全地帯/頭割りの案内、変身・討伐のタイトル、ダメージタイプの死亡メッセージ） |

| | `InstanceAllocator` / `InstanceSlot` | 専用ディメンション内の区画（x = i×1024）の割り当て（既定16） |

## 2. ボスの規則

- **開始**: 対象が1人以上いる最初のtickで戦闘開始（PhaseChanged(0)、激昂タイマー開始）。対象がいない間は新しい技を始めない（予兆済みの技は解決する＝場外に出ても回避扱いにならない）。
- **技＝ウェーブの列**: 技は1つ以上のウェーブからなる。各ウェーブは「配置tick」に範囲を確定して `Telegraph`（範囲ごと、`hitKind` 付き）を出し、「発動tick」にちょうどその範囲へ `Execute` 等を出す（予兆と同じ範囲・予兆時間＝発動までの時間）。単発の技はウェーブ1つ（開始時に配置、telegraphTicks 後に発動）。
  連続技（`AbilityKind.extraTicks()` > 0）は後続ウェーブがそれぞれ自分の予兆（最低10tick）を持つ。拘束時間 = telegraphTicks + extraTicks + castTicks。技の実行中ボスは静止させる。同時に1つだけ。
- **選択**: フェーズの「オープナー」（フェーズ開始直後に順に使う看板技、CT無視）→ 準備完了の技から weight による重み付き抽選。状況条件: SOAK（およびSOAKを含むSequence）は対象 ≥ minPlayers、HEAL は失ったHP ≥ 回復量、SHIELD/BUFF は効果中は不可。
- **対象規則**: NEAREST / FARTHEST（水平距離）/ RANDOM / HIGHEST_THREAT（同値は近い方）。対象は UUID 順に並べてから判定（呼び出し側の順序に依存しない）。後続ウェーブの配置時に対象がいなければボスの向きを使う。
- **形態（フェーズ）**: HP割合がしきい値以下になると現在の技を取り消し（`Cancelled`）、`PhaseChanged`、無敵の変身時間（`BossDefinition.transitionTicks`、既定60tick）。そのフェーズに変身技（`transitionId`、全ボスで周囲の衝撃波 Knockback）があれば変身と同時に開始し、変身時間内に終わる。`enrages` の形態に入ると激昂（スキップした形態の激昂も適用）。フェーズは戻らない。複数しきい値を一度に越えたら最後のフェーズへ直行。オープナーは変身終了と同時。
- **激昂**: 戦闘開始から enrageAfterTicks（ソフト）または激昂する形態に入ったとき、1回だけ `Enraged`。以後ダメージ×1.5、CT×0.6。
- **予兆の最低長**: ダメージ技 ≥10tick（反応＋遅延でも回避の無敵8tickが間に合う）、全体攻撃 ≥20、頭割り ≥30、安全地帯 ≥40。倍率2.0以上の技は全ウェーブ ≥20tick（内容テスト）。
- **防御フラグ**（`AbilityKind`、Execute は当たった種類 `hitKind` のフラグを持つ）: 全体攻撃=回避のみ（ガード不可）。頭割り(SOAK)と安全地帯=回避・ガード不可（頭割りはダメージを範囲内人数で分割）。その他=回避・ガード・パリィ可。残留ハザード=回避・ガード不可（出ればよい）。
- **大きな体**: ボスは高さ約6〜10ブロックの巨体（[entity.md](entity.md) の大きさ表）。ボスを中心とする攻撃（周囲の円・扇・直線・環・十字・回転光線・衝撃波）は
  体の縁から以前と同じだけ外へ届くよう、体の半径の増加分だけ大きくした（近接で張り付くプレイヤーの逃げる距離は変わらない）。突進の帯は体の幅以上、環の内側の安置は体の縁から1.5ブロック以上（内容テスト）。
  取り巻きは体の縁から2.5ブロック以上離れた円に召喚、瞬間移動先の印は体の大きさ、エクサフレアの最初の列は体の縁から。
- **体の動作とインパクト**: 技の開始時、体は予兆の溜め（roar ループ）を見せ、技の動作（`BossActions.actionFor`）を「発動tick − 動作のインパクトtick」に始める
  （大剣が床を打つ・魔法が手を離れる・竜が着地する瞬間がダメージの瞬間）。予兆は動作の溜め以上の長さ（`BossesContentTest`、連続突進の2回目以降と変身の咆哮も）。
  追跡（Trail）は単発の命中がないので詠唱を最初から流す。全体攻撃・バフ・安全地帯は roar のまま。
- **範囲判定**: 水平判定＋上下3ブロック以内。視線判定なし（柱に隠れても当たる＝予兆どおり）。yaw は Minecraft 準拠（0=+Z、90=-X、`combat.HitGeometry` と同じ）。マーカーと判定は一致（テストで格子サンプリング）。
- **シールド技**: 実行時に取り巻き（`<bossId>_minion`）を召喚し、全滅かタイムアウトまで無敵。取り巻きの死亡ごとに `onAddKilled()`。
- **式**: 最大HP = baseHealth × (1 + 0.7 × (人数−1)) × 難易度HP倍率。1撃 = damage × 技倍率 ×（Sequenceの段の割合）× 難易度ダメージ倍率 × 激昂 × バフ。残留ハザードは1回 = 命中ダメージ×0.25、10tickごと。
  HARD: HP×1.4・ダメージ×1.3・CT×0.9。EX: HP×2.0・ダメージ×1.6・CT×0.8＋各フェーズに専用技を1つ追加。
- **バランス**（`BossesContentTest`）: 適正Lvの1撃 = 8〜45（Lv1〜50）、実効1.5撃/秒、バニラ防具式で軽減。NORMAL で1人≈3分、5人≈2.3分（最終ボスは10〜20人で≈5.5分。2026-11-11 にHP1.5倍、それまでは≈3.6分）。ダンジョンのボスは2〜4分、最終レイドは3〜6分、フィールドのボスは最少人数で3〜7.5分に収まり、激昂はその後に来ることをテスト。連続技の拘束は8秒以内。

### 2.1 連続技・特殊攻撃の種類（`AbilityKind`）

| 種類 | 動き | 読み方 |
|---|---|---|
| `Checkerboard(タイル, 一辺, 波, 間隔)` | 闘技場（不明ならボス）中心の格子の半分のタイルが爆発、次の波で残り半分。各波は前の波の爆発と同時に出る | 今爆発したタイルへ移る |
| `Crosses(腕長, 腕幅, 波, 間隔)` | ボス中心の十字、波ごとに45°回転（＋→×→＋） | 腕の間に立ち、次は腕だった所へ |
| `Trail(半径, 人数, 回数, 間隔, 残留)` | 追われるプレイヤーの足元に間隔ごとに円、それぞれ予兆後に爆発。残留>0 で危険地帯が残る | 止まらずに走り、他の人から離れる |
| `Exaflare(方向数, 列数, 列幅, 列の長さ, 間隔)` | ボスから外へ進む列（最初の方向は対象へ）。全列を同時に表示し、近い列から順に爆発 | 爆発した直後の列へ踏み込む／横へ |
| `Scatter(個数, 半径, 範囲, 間隔, 残留)` | 闘技場（不明ならボス周辺）に散らばる円（隕石・宝珠・爆弾）が順に爆発 | 印の少ない所へ |
| `Charge(長さ, 幅, 回数, 間隔)` | 帯の予兆→ボスが帯の端まで突進（壁で止まる）。次の突進は到着後に狙い直す | 帯から横へ |
| `Knockback(半径, 強さ)` | ボス周囲に衝撃。強さ>0 で吹き飛ばし、<0 で引き寄せ（紫の予兆） | 引き寄せの後は外へ |
| `RotatingBeam(本数, 長さ, 幅, 角度, 段数, 間隔)` | ボスから等間隔の光線が段ごとに回転（向きはランダム） | ボスの周りを回る |
| `SafeZones(個数, 半径, 範囲)` | 緑の安全円。円の外の全員が被弾（回避・ガード不可） | 緑の円に入る |
| `Sequence(段...)` | 単発攻撃の連携。最初の段は技の予兆、以後は前の段の発動時に現れ自分の予兆後に発動。段ごとに威力割合と防御フラグ | 例: 引き寄せ→周囲爆発、外→内（ドーナツ）、吹き飛ばし→外側の環 |

### 3.2 変身（形態変化）の演出

`PhaseChanged`（1以上）で Forge 層は: 見た目を形態のものに（`ERBoss.setPhase` → `lookKey` が `<id>_p<n>`、オーラ層が形態の色で強まり、発光色も形態色へ、モデルと当たり判定が形態ごとに4%大きく、変身直後に白い閃光）、
全身で咆哮する PHASE_CHANGE アニメーション（咆哮の頂点＝インパクトが変身技の衝撃波の発動tickに重なるよう遅らせて開始）、変身技の衝撃波（予兆円→ダメージ＋吹き飛ばし）、タイトル「◯◯が姿を変える！／第n形態」、形態の台詞、カメラの揺れと形態色の画面フラッシュ、
効果音（`boss.form_sting` の管弦楽のスティング＋`boss.phase_change`＋咆哮）、移動速度を形態の倍率に、ボスバーの色。

### 3.3 撃破演出（`DefeatSequence`）

HPプールが0になったtickを「とどめ」として記録（`killTick`、`onKilled` コールバック）。次のtickから: 予兆・残留・弾・突進・小道具をすべて消し、頭脳を停止、
ボスは無敵・AI停止・死亡アニメーション（最後の姿勢を保持）、取り巻きは消える。演出の拍（通常100tick／終焉の王180tick）:
崩れ落ち（咆哮・`boss.collapse`・大きな揺れ）→ 閃光と粒子の爆発を交互に → 地面の衝撃波（死亡アニメーションで体が床に倒れる瞬間。倒れた体の足元から頭まで土煙と床の破片・亀裂、`RigData.fallen`）→ 光の柱（遠くからも見える） → 光に溶ける（クライアントで白く輝きながら縮み浮かぶ）→ 消滅（白い画面フラッシュ）。
最後に体を取り除き、タイトル「討伐成功／◯◯を打ち倒した」、`onDefeated`（報酬・物語・ジングル）。
ダンジョンはとどめの時点で `DungeonRun.onBossDefeated` を呼ぶ（制限時間・タイムアタックはとどめの時刻）が、`Cleared` の処理（報酬・メッセージ・退出タイマー）は演出の後に行う。

### 3.4 フィールドのボス（`FieldBosses`、25体）

フィールドの地上で戦うボス。**災厄**（`c_*`、各フィールド1体・計10体、3形態）は瘴気があふれたときに巣に現れ、**放浪する大物**（`w_*`、計15体、2形態）は
プレイヤーがいるフィールドに時々現れる（出現の規則・報酬は [field_threats.md](field_threats.md)）。名前と技名は `docs/i18n/bosses_field.json`。

- **戦い方**: 地上の `BossFight`（ノーマル、闘技場は半径20、2人以上として調整・近くの人は途中参加）。ダンジョンの一覧 `Bosses.ALL` には入れず、
  `Bosses.everyBoss()`（`byId`・全ボスのテスト）に入る。
- **作り**（`FieldBosses.boss`）: 形態の境界は 100/65/30%（災厄）・100/50%（放浪）。形態ごとに技が加わり、その形態の最初の技はオープナー。
  変身技は「変貌の咆哮」（吹き飛ばし、予兆40tick）。後の形態ほど速く（移動+8%/形態）、技の間隔が短い（36→31→26tick）。災厄は最終形態で激昂。
  EX は形態の技にない1技を加える。2人目以降1人ごとに体力+55%、6分で激昂。推奨人数は災厄3〜8人・放浪2〜8人（体力は戦い始めの人数で決まり、1人でも2人分）。
  技はすべて既存の種類（`AbilityKind`）の組み合わせで、予兆は `combat.Telegraph` のマーカー。各ボス5種以上の連続技・8種類以上、突進の帯は体の幅以上、
  ボス中心の攻撃は体の縁から2ブロック以上届く（`BossesContentTest` が全25体を検査）。
- **技の見た目**: ボスの属性（`FieldBosses.element`: 影・月・鍛冶・水・炎・石・氷・虚無・枯死・嵐）の予兆色（闇・魔法・炎・氷・危険）と破片のブロック、技の種類ごとの演出
  （扇・直線＝斬撃、周囲・連携＝叩きつけ、吹き飛ばし・環・突進＝衝撃波、散布＝隕石、盤面・列＝棘、回転光線・十字＝光線、弾＝宝珠）（`AbilityLook`）。
- **体と見た目**: 5つのボスの体（王・樹人・巨像・女王・竜）の上に、同じ体のダンジョンのボスを土台にした専用の見た目（`tools/art_entities/field_bosses.py`）。
  見せる／隠す部位、部位の大きさ・角度（例: 竜は 大角と広い翼／翼の小さい重い顎獣／細身で翼の広い飛竜／巨大な翼と扇形の尾の巨鳥／首と尾の長い大蛇）、
  全体の大きさ、3色の配色（暗・中・明）と発光色。2形態目以降は体に発光する脈と亀裂（`<id>_p1`, `<id>_p2`）。動きは土台のボスのもの。
  エンティティ型はボスごと（`eternalrealm:boss_<id>`、`BossKind`、テクスチャ `textures/entity/<体>/<id>.png`）。

HP は 2026-11-11 のオーナー指示（「全レイドボスのHPを今の1.5倍に」）で、最終レイドの終焉の王と災厄・放浪する大物（大勢で戦うボス）すべてを1.5倍にした（表は新しい値。`FieldBosses.RAID_HEALTH`、`Bosses.FINAL_BASE_HEALTH`）。激昂までの時間も合わせて伸ばした（フィールドのボス 6→9分、最終レイド 7分30秒→11分15秒）。ダンジョンのボス（b1〜b8、1〜5人）は変えていない。

## 5. DungeonRun の状態遷移

`CREATED → startBuilding() → BUILDING → onBuilt() → READY → onStart(now) → IN_PROGRESS(部屋, ウェーブ) → BOSS → onBossDefeated(now) → CLEARED → close() → CLOSED`。
失敗 `FAILED`: 制限時間（開始＋制限ちょうどのtick、期限ちょうどのボス撃破も失敗）、全員不在が猶予（既定60秒）を超える、死亡数が上限（既定は無制限）、未完了での `close()`（ABORTED）。設定は `FailurePolicy`。
メンバーは生成時に固定（重複不可、人数は定義の範囲内）。ウェーブ全滅で次のウェーブ、最後のウェーブで `OpenDoor(部屋)` と次の部屋の `SpawnWave`、最後の部屋で `StartBoss`。レイドは開始と同時に `StartBoss`。
違う部屋・余分な撃破・終了後の入力は無視（イベントなし）。ライフサイクルの誤用は `IllegalStateException`。

## 6. Forge 層がやること

1. **ボス**: `BossFight.start(level, 定義, 難易度, 出現位置, 闘技場の中心, 半径, 参加者, onKilled, onDefeated)`。`BossBrain(definition, 人数, 難易度, rng)` に `setArena`。MAX_HEALTH は固定（戦闘のHPプールを使う）、ARMOR=`armor()`、攻撃力=`meleeDamage(now)`、移動速度×形態の倍率。
2. 毎tick `tick(now, hp/maxHp, BossPosition(足元・yaw), 対象)`。対象 = アリーナ内の生存プレイヤー（観戦者除外）、threat は与ダメ・回復・挑発から算出。
3. `currentAbility()` か変身中（`isTransforming`）か突進中はボスを静止させる。
   - `Telegraph` → `AbilityLook` の色で地面マーカー（`Telegraphs.show`、発動tickまで溜まる）。`SafeSpot` → 緑のマーカーと光の柱。`Cancelled` → その技のマーカー・小道具・予約演出を消す。
   - `Execute` → 範囲内の全員に damage（`BossDamage`: 回避＋ガード可=mobAttack、回避のみ=`eternalrealm:boss_unguardable`（`bypasses_shield`）、どちらも不可=`boss_unavoidable`（攻撃者なし、VIT軽減はここで適用）、`splitsDamage`=人数で割る）。マーカーを発火（白く光って消える）、`BossVfx` の命中演出。
   - `Displace` → 半径内のプレイヤーを押す／引く（速度を設定）。`Hazard` → 残留マーカーと10tickごとの `boss_hazard` ダメージ。`Dash` → 4tickで帯の端へ（壁で停止。体は帯の向きへ即座に向き、2回目以降の突進も溜め直してインパクトが突進の瞬間）。
     `Volley` は粒子の弾: 詠唱のリリース時の手・宝珠・核・口の位置（`RigData.muzzle`）の高さから予兆の扇の線に沿って出て、急角度で胸の高さまで降りてから水平に飛ぶ（近くの相手も外さない）。`Summon` / `Teleport` / `Heal` / `Buffed` / `Enraged` / `ShieldChanged` は従来どおり＋演出。
4. ダメージイベントで `isInvulnerable` なら無効化（変身・シールド・撃破演出中）。
5. **演出（`BossVfx`）**: 技の `Effect` ごとに粒子・音・小道具（叩きつけ系はボスの武器が床を打つ位置に、体の大きさに比例した放射状の亀裂（薄い黒い板）と跳ね上がって床に半ば埋まる床の破片）（`BossProps`: `minecraft:block_display` を補間付き変形で動かす。床から突き出る柱・棘・根、空から落ちる隕石、浮かぶ宝珠、爆弾。ブロックは一切置かない。寿命・戦闘終了で削除、チャンク読み込み時に残骸を破棄）、視覚のみの雷、光線、衝撃波。画面効果は UI データ `boss_fx`（`BossFx` → クライアント `BossScreenEffects`: カメラの揺れ・画面フラッシュ）。同じtickの同じ音・揺れ・雷は1回にまとめる。
6. **ダンジョン**: `InstanceAllocator.allocate()`（満員なら `FULL_MESSAGE_KEY`）→ `DungeonLayoutGenerator.generate(def, seed)`（レイドは `raidArena`）→ `startBuilding()` → 建築計画を数tickに分けて設置（原点 = スロット原点＋基準高さ）→ `onBuilt()` → メンバーを入口へ → `onStart`。毎tick `run.tick(now)`。
7. ウェーブのモンスターに（インスタンス, 部屋）タグを付け、死亡・消滅ごとに `onMonsterKilled(部屋)`。湧き点は順番に使い回す。`OpenDoor` で扉の箱を空気に。`StartBoss` でボス部屋中央に召喚（闘技場 = ボス部屋の床）。死亡/退出/再接続を通知。
8. 終了時: メンバーを外へ → `close()` → `occupiedBoxes()` を空気で消去・エンティティ除去 → `release(slot)`。再起動後は前回の内容が不明なので、ディメンションのリセットか区画全体の消去を行う。
