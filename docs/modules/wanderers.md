# 放浪の冒険者（wanderers）: シングルプレイの隠し要素

オーナーの依頼（2026-11-12）: 4人のキャラクターを隠し要素としてフィールドに出現させ、AIを備えて実際に冒険したり宿にいたり
買い物したりするように。シングルプレイの際だけ出現。言動・アニメーション・スキルや魔法の見た目と効果も高品質に。

依頼の画像は他社作品（アニメ）の登場人物だったため、その姿・名前・台詞・技をそのまま再現することはしていない
（著作物の複製になる）。代わりに、依頼の骨組み（隠し要素・AIで冒険・宿・買い物・シングルプレイ限定・派手な技・個性のある言動）を
そのまま満たす **オリジナルの4人** を作った。どの作品の人物の目印になる特徴（黒衣の二刀流、白と赤の細剣の騎士、銀髪ツインテールの
エルフの魔法使い、青い髪のスライム）も持たせていない。

| 場所 | 内容 |
|---|---|
| `npc.Wanderers`（純粋） | 4人のデータ（体・戦い方・射程・通常攻撃）、技8種、居場所の巡り（フィールド→道具屋・宿→フィールド）、狩り場の選び方、台詞のキー、出会った人の記録 |
| `npc.forge.WandererEntity` | 体（町のNPCと同じ体の仕組み）。フィールドでは狩り場を歩いて魔物と戦い、町では店や宿の自分の場所にいる。話しかけられると向き直る |
| `npc.forge.WandererSkills` | 通常攻撃と技の演出（パーティクルの振り付け）と効果（敵の最大HPの割合のダメージ、ノックバック、回復） |
| `npc.forge.WandererDirector` | シングルプレイかの判定、4人の巡り（ワールドに保存）、プレイヤーの近くでの出現と退場、出会い・会話・技の掛け声 |
| `npc.forge.WandererWorldState` | 4人の居場所の保存（`data/eternalrealm_wanderers.dat`） |
| `tools/art_entities/npc_cast_wanderers.py` | 4人の姿と肖像（スクリプトで描くオリジナルの絵） |

## 1. 4人

| | 姿 | 戦い方（射程） | 技 |
|---|---|---|---|
| **地図描きのボルド** | ドワーフの探検家。真鍮のゴーグル、銅色のひげ、オリーブの外套、地図の巻物を積んだ背負い袋、羅針の宝石が光る真鍮の杖 | 杖から真鍮の光弾（5.5） | **星図結び**: 敵の周りに星が6つ灯り、光の線で2つの三角に結ばれ、弾ける（範囲・浮かせる） / **羅針の光**: 足元に羅針盤が描かれ、光の針が彼の周りを一周して触れた敵を斬る |
| **鷹匠のミルカ** | 小柄な狩人。緑の鉢巻、羽根の縁取りの森色のマント、肩に鷹のフィン、矢筒と長弓 | 矢（8.5） | **鷹落とし**: 鷹が空高く昇り、金色の尾を引いて急降下（単体に大ダメージ） / **羽嵐**: 9本の羽根の矢が扇形に飛ぶ |
| **鐘の騎士グラウス** | 緑青の青銅鎧、生成りの羽根飾りの兜、鐘の紋章の陣羽織、ハルバード、背中に大きな青銅の鐘 | ハルバードのなぎ払い（2.6） | **鐘打ち**: 背の鐘を鳴らし、音の輪が3重に広がって敵を押し返す / **大鐘落とし**: 光の大鐘が敵の頭上から落ち、地響きと共に鳴る |
| **潮歌いのセレ** | 海辺の吟遊詩人。暗いバラ色の長い波打つ髪に貝の髪飾り、泡色の胴衣に珊瑚色の波、裾が深い青緑に変わるドレス、真珠色のリュート | 泡の音（6.5） | **潮騒の歌**: 歌から3つの波が扇形に寄せ、敵を押し流す / **泡沫の守り**: 体力が7割を切ったプレイヤーの周りに泡が昇り、HP を最大の25% 回復＋再生4秒（味方の回復は戦っていなくても） |

- 技は掛け声（会話ボックス、肖像つき。同じ人は20秒に1回まで）、技の身振り（体の会話の動き）、効果音（鐘・水晶・羽ばたき・水音など
  バニラの音）と一緒に出る。演出はサーバーのパーティクルなので、シェーダーパックでもそのまま見える。
- ダメージは敵の最大HPの割合（通常 6〜9%、技 15〜34%）: どのLvの魔物にも役に立つが、プレイヤーの獲物を奪うほどではない。
  とどめを刺しても経験値やお金は誰にも入らない（プレイヤーが一度でも攻撃していればその人に入る）。プレイヤーは絶対に傷つけない。
- 体は町のNPCと同じ（歩く・息づかい・まばたき・作業の動き・会話の身振り）。作業の動きは、ボルドは杖、ミルカは肩の鷹の羽ばたき、
  グラウスは構え、セレはリュート。セレは宿でリュートを弾き、音符が浮かぶ。
- 4人とも不死身（町のNPCと同じ）。押されない。

## 2. 暮らし

- **シングルプレイだけ**: 統合サーバー（シングルプレイのワールド）で、LAN に公開しておらず、ワールドの持ち主1人しかいないとき。
  LAN に公開した・ほかの人（テストボットを含む）が入った → その場で姿を消す（マルチプレイの再現にならないように）。
  専用サーバーには出ない。
- **巡り**: フィールド（6〜10分）→ 道具屋（2〜4分）か宿（3〜6分、夜は6〜10分）→ … → フィールド。フィールドでは生息地の1つに
  いて、そこの魔物と戦い、合間に狩り場を歩く。狩り場は6割の確率でプレイヤーから240ブロック以内の生息地（そうでなければどこか）、
  直前と同じ場所は選ばない。巡りはワールドに保存され、プレイヤーがいない間（ワールドを閉じている間）は進まない。
- **出現**: 居場所から56ブロック以内にプレイヤーが来ると、その場に現れる（近くで見ていればウェイストーンの旅のような光と音）。
  104ブロック離れると消える（状態は巡りに残る）。体はワールドに保存されない。
- **移動**: 次の場所へ移るときは光と共に旅立つ（戦っている最中・話している最中は少し待つ）。
- **道具屋**: カウンターの店主の近くに立ち、ときどき店主と言葉を交わして買い物をする（身振り・硬貨の音と光）。
- **宿**: 女将のいるロビーで休む。

## 3. 出会いと会話

- 初めて7ブロック以内で姿が見えると **出会い**: 2行の自己紹介（会話ボックス、肖像つき）と「放浪の冒険者に出会った: 名前（n/4）」の
  知らせと効果音。出会った人はキャラクターの拡張データ（`wanderers_met`、シーズンごと）に残る。
- 右クリックで話しかけると、立ち止まって向き直り、居場所（フィールド・道具屋・宿）ごとの台詞（各3つ）から1つ。
  出会う前なら出会いの台詞。

## 4. 見た目の作り方

- 体と肖像は `tools/art_entities/npc_cast_wanderers.py`（NPC の絵のパイプライン、[npc.md](npc.md)）でスクリプトから描いた
  オリジナルの絵。`python3 tools/art_entities/generate_npc.py` で `textures/entity/npc/wanderer_*.png`（ボルドとセレは発光の層つき）と
  `textures/gui/portrait/wanderer_*.png`、`NpcBodies` の表が更新される。既存の64人の絵は変わらない。
- 体の大きさ: ボルド 0.84、ミルカ 0.8、グラウス 1.06、セレ 0.96。

## 5. テスト

- 純粋: `WanderersTest`（4人それぞれ体・テクスチャ・肖像・名前・出会い・居場所ごとの台詞・技の掛け声が日英そろう、肖像は会話の
  話し手のキーで見つかる、戦い方がそれぞれ違う、技は敵を一撃で倒さない、巡りがフィールドから町へ・宿からフィールドへ、
  滞在時間、狩り場はプレイヤーの近くが多く直前と同じ場所は選ばない、計画の検証、出会った人の記録の読み書き）。
- GameTest `WandererGameTests`: テストサーバー（シングルプレイでない）には出ない / グラウスが魔物に近づいて攻撃と技で HP を削り、
  自分は傷つかない。体は自分の見た目。

## 決定事項（Decisions）

- **他作品のキャラクターは再現しない**: 依頼の4人は他社の著作物のキャラクターなので、姿・名前・台詞・技の再現はせず、依頼の仕組みを
  満たすオリジナルの4人に置き換えた（D-WANDERERS）。
- **体は町のNPCの仕組みを使う**: 歩き・待機・作業・会話の動きと肖像がそろっていて、絵もスクリプトで描ける。戦いの動きは技の身振りと
  パーティクルで見せる。
- **出現はプレイヤーの近くだけ**: 4人は「巡り」だけを持ち、体はプレイヤーが近くに来たときに作る。遠くで戦い続けて負荷になることも、
  ワールドに古い体が残ることもない。
- **狩り場はプレイヤーの近くが多め**: 隠し要素として出会えるように、6割はプレイヤーの周り240ブロック以内の生息地へ行く。
