# 復活システム（revival）

アストリアとダンジョンでは、致命傷を受けたプレイヤーは死なずに **戦闘不能** になる。`/kill` と奈落（無敵を貫通するダメージ）、ほかの次元では通常の死亡。

## 流れ
1. `RevivalService.onLivingDeath`（最優先）が死亡をキャンセルし、HP1・無敵（`abilities.invulnerable`）にしてその場に固定する。
   魔物はターゲットを外し、ボスの攻撃対象からも外れる（`BossFight.targets`）。攻撃・アイテム使用・ブロック操作・拾得・戦闘リクエストは拒否。
2. 本人には復活画面（チャンネル `revival`）、同じ次元の全員には倒れている体の一覧（`revival_bodies`）。クライアントは体を寝かせ、上に「✝ 戦闘不能」。
3. 立ち上がる方法（`RevivalRules.Way`）
   - **その場で復活**（永久花の花びら、HP50%）
   - **仲間が花びらを使う**（右クリック、4.5ブロック以内、HP50%）
   - **蘇生魔法**（`RevivalService.resurrect(caster, target, fraction)`、範囲用に `fallenNear`）
   - **帰還地点で復活**（HP100%）: フィールド＝そのフィールドで記録済みの最寄りの転移碑（なければ王都）、王都＝広場、ダンジョン＝入口。
     2秒後から選べ、フィールド60秒・王都10秒・ダンジョン30秒で自動。
4. 立ち上がった後は3秒間無敵。ログアウト中に倒れていたら帰還地点へ。サーバーが落ちても、ログイン時に印（永続データ）を見て立ち上がらせる。

## 規則（`revival` パッケージ、Minecraft非依存）
- `RevivalRules`: 場所ごとの自動帰還時間、帰還ボタンの解禁、方法ごとのHP、フィールドだけ経験値ペナルティ（設定 `deathExpPenalty`）。
- `RevivalTips`: 復活画面の「強くなるには」。推奨レベル未満・未使用ステータス/スキルポイント・回復薬なし・未強化装備2個以上・ソロでダンジョン/ボス、最後の枠は回避やボスの予兆のヒント。

## 他の仕組みとの関係
- ダンジョン: 戦闘不能は従来の死亡と同じく数える（`DungeonService.onPlayerDeath`）。帰還は `reviveAtRevivalPoint`（入口）。
- ボス戦: 戦闘不能は戦功の減点（`BossFight.recordFall`）。
- パーティ枠: `down` で「戦闘不能」表示。
