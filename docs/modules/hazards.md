# フィールドの攻撃予告: ダンジョンの罠と強敵の大技（`dungeon.hazard` / `monster.SpecialMoves` / `entity.ERMonster`）

ボスと同じ地面の予告（`combat.Telegraph`、赤い円・四角など）を、ダンジョンの罠・地形ギミックと、強いモンスターの大技にも使う。
**必ず予告が先に出て、予告の円が満ちた瞬間に、その範囲内（`Telegraph.contains`）にいる者だけに当たる。** 予告が出たら必ず発動する
（途中で誰もいなくなっても空振りで発動する）。サーバー権威。ブロックは一切変えない。

## 1. ダンジョンの罠（`dungeon.hazard`、`dungeon.forge.DungeonHazards`）

### 配置（`HazardPlanner`、純粋・決定的）
- インスタンスのレイアウトのシードから決まる（同じレイアウトなら同じ罠）。入口の広間とボスの間には置かない。
- 通路: 長さ8ブロック以上の通路に1つ（18以上は2つ）。帯状の罠は通路に沿って通路幅いっぱい。
- 戦闘部屋: 1つ（内側の面積 17×17 以上は2つ、種類は別）。固定位置の罠は壁から3ブロック以上離す（扉の前をふさがない）。
  狙い撃ち型は部屋・通路ごとに1つまで。
- 最終レイド（終焉の玉座）には罠なし（終焉の王の攻撃で十分）。

### 発動（`HazardField`、純粋）
- 罠ごとに「区域」（通路の通り道／部屋の内側）があり、区域に誰か（メンバー、観戦・クリエイティブ除く）がいる間だけ動く。
  入ってすぐは猶予（20〜60tick）。
- **周期型**: 決まった場所で一定間隔。**接近型**: 床の罠を踏むと予告→発動、その後休止。**狙い撃ち型**: 区域内の誰かの足元に予告
  （対象の選び方はシードとtickで決定的。区域の端では内側に寄せる）。
- 予告時間は16〜32tick（0.8〜1.6秒）。ダメージは最大HPの8〜16%（ノーマル）、ハード×1.3、EX×1.6。
  ダメージ種別 `eternalrealm:trap`（`data/eternalrealm/damage_type/trap.json`、死亡メッセージ「〜は罠にかかって倒れた」）:
  攻撃者がいないのでVIT軽減とガードは効かないが、防御バフは効く。回避の無敵では避けられない（予告の外へ出ること）。
- 当たった人には罠の名前が赤くアクションバーに出る。マップ・ミニマップには固定位置の罠が赤い三角で出る。

## 2. 強敵の大技（`monster.SpecialMove` / `SpecialMoves`、`entity.ERMonster`、`EnemyCombatGoal`）

### ルール（`SpecialMoves.moveCount`）
| 対象 | 大技 | 間隔 |
|---|---|---|
| エリート（金色の名前。フィールドのエリート、ダンジョンのウェーブ隊長） | 体の大技2つを交互に | 約8〜10秒 |
| Lv30以上の通常モンスター（ドラゴニア火山以降、後半のダンジョン） | 1つ目の大技のみ | 約15〜17秒 |
| それ以外（Lv30未満の通常モンスター、ボスの召喚） | なし（従来どおり） | — |

戦闘開始から2.5〜4.5秒は使わない。サーバー設定 `monsters.specialMoves` で無効化できる。
- アニメーション付きの体（`entity` のリグ）: `MonsterFactory` が生成時に回数を設定（NBT `SpecialMoves` に保存）し、`ERMonster` が実行。
- バニラの体（例: ドラゴニアのエリート `dragonkin_berserker`、セレスティアの `celestial_paladin`、Lv30以上の `lava_slime`・`sky_archer`）:
  `monster.forge.VanillaSpecialMoves` がレベルに入るたびにゴール（優先度1）を付け、同じルール・同じ予告で実行（スロー再生の代わりに
  立ち止まって溜め、発動時に腕を振る）。技は体の種類から（弓兵: 矢の雨・薙ぎ払い、術士: 魔法陣・爆発、スライム: 踏み鳴らし・叩きつけ、
  クモ等: 飛びかかり・旋回、ラヴェジャー: 突進・踏み鳴らし、その他: 薙ぎ払い・叩きつけ）。クリーパーは爆発がそのまま大技なので対象外。

### 予備動作とヒット
- 開始時に予告を地面に表示し、その方向へ向きを固定。攻撃アニメーションを**スローで再生**（エンティティイベント 72〜119: 攻撃1/攻撃2/詠唱 ×
  溜め時間16段階。クライアントの `EnemyModel` が再生速度を落とし、当たりのフレームが予告の満ちる瞬間に来る）。溜め中は体の周りにスタイルの粒子。
- 予告が満ちたら発動: 範囲内の全員（プレイヤー、狙っている相手、モンスター以外の生き物）に通常攻撃の1.4〜1.8倍。プレイヤーへの
  ダメージは `MonsterEvents` がモンスターのレベルの攻撃力×倍率で決める（防御・ガード・回避・パリィは通常どおり有効）。
  属性: 炎=炎上3秒、氷=鈍足＋凍え、闇=衰弱2秒、魔=短いしびれ。
- 突進（CHARGE）と飛びかかり（POUNCE）は、ヒット後に予告の線／円の位置まで素早く移動する。
- 予備動作中に死亡・消滅すると予告は取り消し（`Telegraphs.cancel`）。

### 体ごとの大技（1つ目が「Lv30以上」で使う技）

| 体 | 大技 |
|---|---|
| 人型の戦士（bandit, ghoul, mummy, prisoner, shade など） | 薙ぎ払い（前方の扇形）、叩きつけ（前方の円） |
| jailer | 鎖の旋回（自分の周りの円）、叩きつけ |
| dark_knight, ice_knight | 衝撃波（前方への帯）、薙ぎ払い |
| 術士（cultist, frost_mage, fire_imp, void_mage, dryad） | 魔法陣（狙った相手の足元の円）、爆発（自分の周りの円） |
| crossbowman | 矢の雨（相手の周りの円）、貫通矢（前方への長い帯） |
| 獣（wolf, snow_wolf） | 突進（相手を貫く帯）、飛びかかり（相手の位置の円） |
| salamander, frost_hound | ブレス（扇形、炎/氷）、突進 / abyss_hound: 突進、ブレス（闇） |
| scorpion | 飛びかかり、尾の旋回 / cave_rat: 飛びかかり、突進 |
| ゴーレム（treant, sand_golem, ice_golem, lava_golem, ruin_construct） | 叩きつけ（前方の円）、踏み鳴らし（環。体の真横は安全） |
| 飛行（ice_wraith, fire_spirit） | 魔法陣、爆発 / harpy: 急降下（円）、羽ばたき（周囲） / storm_spirit: 雷の十字、魔法陣 / sky_sentinel: 光線、魔法陣 |

予告の色は体の属性（炎=橙、氷=青、闇=暗紫、魔=紫、聖=金）、物理技はボスと同じ赤。

## 3. 構成とAPI

| クラス | 内容 |
|---|---|
| `dungeon.hazard.HazardKind` | 罠の種類（形・色・型・配置・予告時間・間隔・ダメージ割合・追加効果）とテーマ別の一覧 |
| `dungeon.hazard.HazardPlanner` / `HazardSite` | 配置（決定的）／1つの罠（区域・中心・向き・大きさ・初回猶予） |
| `dungeon.hazard.HazardField` / `HazardEvent` | 実行（`tick(now, victims)` → 予告 `Warn` / 発動 `Strike(hit)`） |
| `dungeon.forge.DungeonHazards` | ワールドでの実行（予告表示・演出・ダメージ・効果）。`DungeonInstance` が建設完了時に作り、進行中だけ動かし、クリア・失敗・終了で止める |
| `monster.SpecialMove` / `SpecialMoves` | 大技の形・溜め・射程・倍率、対象ルール、体ごとの技、色 |
| `entity.ERMonster` | `setSpecialMoves(n)`, `specialMoves()`, `trySpecialMove(target)`, `startSpecialMove(move, target)`, `currentSpecialMove()`, `currentSpecialTelegraph()`, `hitMultiplier()`, `animationSpeed(anim)` |
| `monster.forge.VanillaSpecialMoves` | バニラの体のモンスター用のゴール（`EntityJoinLevelEvent` で付与）、`hasGoal(mob)`, `windingUp(mob)` |
| `combat.forge.TelegraphFx` | 予告のスタイル別の粒子・音（罠と大技で共用） |

サーバー設定（`eternalrealm-server.toml` の `[monsters]`）: `specialMoves`（既定 true）, `dungeonTraps`（既定 true）。

## 4. テスト

- 単体: `HazardPlannerTest`（全テーマに通路・部屋の罠、決定性、広間とボスの間に置かない、部屋からはみ出さない、通路の帯の向き、レイドは罠なし）,
  `HazardFieldTest`（予告→満ちた瞬間に発動、範囲外は当たらない、無人なら動かない、予告後は必ず発動、休止、接近型、狙い撃ちの位置と端の寄せ、
  決定性）, `SpecialMovesTest`（ルール、全バリアントに2つの技、溜め時間の下限、属性色、予告の向き・位置）。
- GameTest `HazardGameTests`: 罠が予告してから当たり、予告の外のゴーレムは無傷／罠のダメージ種別が読み込まれている／エリートの叩きつけが
  溜め中は当たらず、発動時に予告内の相手だけに当たる／`MonsterFactory` がルールどおりに大技を与える（バニラの体のエリートにはゴール）／
  バニラの体のエリート（celestial_paladin）が実際に予告を出し、溜め中は当たらず発動で当たる。
- **未確認**（実機クライアントが必要）: スロー再生の予備動作の見え方、粒子・音の量、難易度の手触り。
