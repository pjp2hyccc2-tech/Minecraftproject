# フィールドの脅威（ヌシ・瘴気・災厄・放浪する大物）

## ヌシ（`FieldThreats.Lord`）
- 各フィールド3体（計30体）。どれも専用の見た目とテンプレート（`lord_<id>`、ELITE）を持つ中ボス（一覧は [bestiary.md](bestiary.md)）。
  出現表からは湧かず、ここからだけ現れる。Lvはフィールド上限+2、体力は強敵の6倍、攻撃1.35倍。
  体力が属性の上限（1000）を超える分は被ダメージ倍率（`er_toughness`）で表す。
- 戦い方: 体の特技を3つすべて使う（強敵は2つ、`SpecialMoves.LORD_MOVES`、間隔5.5秒前後）。体力70%と30%で同じフィールドの魔物を2体ずつ呼び、
  50%で咆哮（近くのプレイヤーを吹き飛ばす）して以後は激昂（移動速度上昇・攻撃1.2倍）（`LordTurns`）。
- 戦闘中は近く（28ブロック、攻撃した人は48）のプレイヤーにボスHUDを出す: 本当の体力（上限超え分込み）・段数・特技の詠唱バー（技名）・激昂表示・与ダメージ順位。
- 巣から96ブロック以内に人が来て、出現時刻を過ぎていれば現れる。縄張り（24〜34ブロック）を歩き回る（`restrictTo`）。160ブロック以内に1分間誰もいなければ眠る（体を消し、次に誰かが来たら全快で現れる）。
- 倒されると7〜16分後（ヌシごと）に再び現れる。サーバー起動直後は時間をずらして現れる。
- 報酬: 与ダメージの3%以上（または殊勲）の全員に、そのフィールドの珍しい素材2〜3・強敵の素材1（殊勲は2）・装備（20%、殊勲は45%でレア以上）・花びら（15%）・経験値（ヌシの2倍）・ゴールド。
  通常の撃破報酬（とどめを刺した人とパーティ）も別にある。

## 瘴気（`Miasma`）
- フィールドごとのゲージ（0〜1000）。魔物を倒すと増える（普通8・強敵25・ヌシ150）、10秒ごとに1自然に増える。
- 満タンで **兆し**（60秒）→ **顕現**。顕現中は戦われないまま5分、または20分で **去る**（ゲージは400まで残る）。
  鎮めると **浄化**（10分、ゲージ0、魔物の経験値1.25倍）→ **静穏**。
- ゲージはアストリアのデータ（`eternalrealm_field_threats.dat`）に保存。再起動時の状態はすべて静穏（顕現中だったフィールドは800から）。

## 災厄（`FieldThreats.Calamity`）
- 各フィールド1体。顕現後、誰かが巣から56ブロック以内に来ると、巣（半径20+縁2）を中央値の高さに平らにした「爪痕」（フィールドごとの地面ブロック、縁は石レンガ）に変え、ボス戦を始める（`BossFight`、ノーマル、2人以上として調整。大勢で戦うボスなので 2026-11-11 にHPを1.5倍・激昂を9分にした）。
- 近くにいる人は自動で参加（ボスHUDと戦功ランキング）。戦闘不能・被ダメージ・与ダメージはダンジョンのボス戦と同じく記録。
- **ボス**: 災厄ごとの専用ボス（`boss.FieldBosses`、3形態・最終形態で激昂、技・見た目・Lv は [boss.md](boss.md) 3.4）:
  草原を呑む影 `c_meadow` Lv15／月蝕の巨樹 `c_moon_forest` Lv20／坑底の破壊獣 `c_iron_mine` Lv25／堕ちた滝守 `c_sacred_falls` Lv30／
  遺跡を焦がす焔 `c_ancient_ruins` Lv40／峰を砕く巨像 `c_summit` Lv50／終焉より来るもの `c_end_forest` Lv55／実りを枯らす根 `c_farm` Lv20／
  湖底の破壊獣 `c_lakeside` Lv25／嵐を呼ぶ呪術師 `c_harbour` Lv30。
- 報酬: 与ダメージ3%以上（または殊勲）の全員に、そのフィールドのボスの魂1（殊勲2）・強化石（評価で2〜5）・強敵の素材1・装備（50%、殊勲は確定でレア以上）・
  花びら（35%）・経験値とゴールド（そのフィールドの最初のヌシのテンプレートをボスのLvで、経験値25倍・ゴールド12倍。取り巻きのテンプレートがあるボスはそれを使う）。
  結果はクリア報酬画面（災厄討伐）。
- 専用ドロップ（武器庫の仕組み、[armory.md](armory.md)）: 災厄ごとの武器1本（殊勲30%・ほか10%、レア以上）と防具セットの1部位（殊勲50%・ほか20%）
  （`Signatures.calamityWeapon` / `ArmoryDrops.calamityPiece`、災厄の id `meadow`〜`harbour` ごと）。放浪する大物には専用の装備はない。

## 放浪する大物（`Wanderers`）
- **誰がどこに**: 15体。各フィールド1体、Lvの高い5つのフィールド（聖なる滝・古代遺跡・天翔の峰・終焉の森・風の港）は2体。
  各体は専用ボス（`boss.FieldBosses` の `w_*`、2形態）で、名前はボスの名前:
  草原 野茨の遍歴騎士 Lv12／月影の森 月光蛾の魔女 Lv18／鉄鉱の鉱山 鉱滓の巨人 Lv23／聖なる滝 瀑流の飛竜 Lv28・霧籠りの仙人 Lv30／
  古代遺跡 歩く碑文 Lv36・灰の先触れ Lv38／天翔の峰 雷鳴の巨鳥 Lv45・氷河を背負う者 Lv48／終焉の森 虚ろなる巡礼者 Lv52・墓花の大樹 Lv54／
  豊穣の農場 案山子の王 Lv17／湖畔 葦原の大蛇 Lv22／風の港 沈まぬ船長 Lv27・潮呼びの巫女 Lv29。どのフィールドでも災厄のLvは放浪する大物以上。
- **出現の規則**（`Wanderers.Schedule`、純粋）:
  - フィールドの時計は**そのフィールドにプレイヤーがいる間だけ**進む。次の出現まで12〜25分（ランダム）、サーバー起動後の最初はその半分。
  - 1フィールドに同時に1体まで。フィールドの災厄が兆し・顕現中は現れない（現れていて誰も戦っていなければ、災厄の気配に姿を消す）。
  - 誰も戦わないまま8分で去る。去った（倒された）体は30分間は再び現れない（2体のフィールドではもう1体が来られる）。
  - 出現場所はフィールドごとに4か所までの候補から（下記）。
- **出現場所**（`Wanderers.findSpots`、純粋・決定的、サーバー起動時に別スレッドで約2秒）: 16ブロック格子の候補のうち、フィールドの中心（地図の名前の位置）から520ブロック以内、
  闘技場（半径20）の地面の高低差が2以内で水がない（地形関数 `FieldTerrain` で判定）、そして
  道から30（道幅の外から）・転移碑から64・ダンジョンの入口（`LandmarkSites`、広場の半径＋48）・建造物（`FieldPieceData` の箱から32）・
  ヌシの縄張り（縄張り＋40）・災厄の巣（巣の半径＋80）・王都（120）・フィールドの境（36）・世界の端（96）・海岸と川（28）・湖から離れた場所。
  そこから互いに140ブロック以上離れた4か所（最初は中心に最も近い所、以後は既に選んだ所から最も遠い所）。全フィールドに4か所ずつ見つかる。
- **流れ**（`world.forge.WandererService`）:
  1. 出現: 全員に告知（フィールド・名前・Lv・そのフィールドの転移碑からの方角と距離・座標）。そのフィールドにいる人に咆哮の音。
     手配書・地図・ミニマップの下に表示。出現場所の上に遠くから見える光の柱（192ブロック以内の人に）。
  2. 目覚め: 誰かが40ブロック以内に来ると（チャンクが読み込まれていれば）、地面を踏み荒らす（半径22: 木・草花・キノコ・地面から4ブロック以上上にある物を消し、水たまりを埋める。
     地面が粗い（高低差が4を超える）まれな場合だけ、災厄の爪痕のように中央値の高さに平らにする）。
  3. 戦い: 地上の `BossFight`（ノーマル、闘技場の半径20、2人以上として調整）。56ブロック以内の人は自動で参加。
     戦う人（戦闘不能でない参加者）が56ブロック以内に90秒いなければ立ち去る（体が消える）。チャンクごと読み込みが外れた場合も立ち去る。
  4. 撃破: 全員に告知（殊勲の名前）。与ダメージ3%以上（または殊勲）の全員に報酬と結果画面（クリア報酬画面の「WANDERER DEFEATED」）。
- **報酬**（災厄より一段下）: そのフィールドの珍しい素材3（殊勲4）・強敵の素材1（殊勲2）・強化石（評価で1〜4）・装備（殊勲は確定でアンコモン以上・35%でレア以上、
  ほかは50%でアンコモン以上）・花びら（20%、殊勲30%）・経験値とゴールド（そのフィールドの最初のヌシのテンプレートをボスのLvで、経験値10倍・ゴールド5倍、殊勲は1.5倍）。
  評価（S〜C）は6分を基準に、時間と戦闘不能の数で決まる。
- **保存しないもの**: 時計・待ち時間・出現中の体はサーバーを止めると消える（再起動後は最初からやり直し）。前回の体がチャンクに残っていても読み込み時に消す。
- 管理者コマンド: `/eternalrealm threat wanderer <id>`（その場所の候補のどれかに今すぐ出す）、`... <id> here`（自分の位置に出す。アストリア内）。

## 画面
- ミニマップの下: 今いるフィールドの瘴気ゲージ（兆しは赤く点滅、顕現中は災厄の名前、浄化中は残り時間）。ヌシ討伐の結果（戦功の順位・割合・獲得物）。
- 霧: 兆し・顕現中のフィールドでは紫に濃くなる。
- 脅威ゲージ（HUD の配置 `layout.threat()` の中）: 今いるフィールドに放浪する大物が出ていれば、右端に脈打つ琥珀色の印（交戦中は赤）と、
  3秒おきにゲージの文字の行にその名前。
- 地図: 出現中のヌシ（紫の菱形）、災厄の巣（目覚めると赤く脈打つ）、出現中の放浪する大物（脈打つ輪の琥珀色の点、交戦中は赤。名前・Lv・去るまでの時間）。
  地図上部の「討伐手配書」で全フィールドの一覧（放浪する大物ごとに1行: 出現中と去るまでの時間／交戦中／どこかを放浪中）。
- 告知（全員）: 兆し・顕現・鎮圧・去る・浄化、放浪する大物の出現（場所つき）・去る・立ち去る・討伐。ヌシの出現と討伐は近くの人に。
- 盤面のデータ（`threat_board`）: フィールドごとに `wanderers: [{id, name, level, out, x, z, fighting, bx, bz, leaves}]`（位置と時間は出現中の体だけ）。
