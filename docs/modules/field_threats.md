# フィールドの脅威（ヌシ・瘴気・災厄）

## ヌシ（`FieldThreats.Lord`）
- 各フィールド2体（計20体）。そのフィールドの強敵と普通の魔物の上位個体に名前をつけたもの。Lvはその魔物の上限+2、体力は強敵型6倍・普通型14倍、攻撃1.35倍。
  体力が属性の上限（1000）を超える分は被ダメージ倍率（`er_toughness`）で表す。
- 巣から96ブロック以内に人が来て、出現時刻を過ぎていれば現れる。縄張り（24〜34ブロック）を歩き回る（`restrictTo`）。160ブロック以内に1分間誰もいなければ眠る（体を消し、次に誰かが来たら全快で現れる）。
- 倒されると7〜16分後（ヌシごと）に再び現れる。サーバー起動直後は時間をずらして現れる。
- 報酬: 与ダメージの3%以上（または殊勲）の全員に、そのフィールドの珍しい素材2〜3・強敵の素材1（殊勲は2）・装備（20%、殊勲は45%でレア以上）・花びら（15%）・経験値（ヌシの2倍）・ゴールド。
  通常の撃破報酬（とどめを刺した人とパーティ）も別にある。

## 瘴気（`Miasma`）
- フィールドごとのゲージ（0〜1000）。魔物を倒すと増える（普通8・強敵25・ヌシ150）、10秒ごとに1自然に増える。
- 満タンで **兆し**（60秒）→ **顕現**。顕現中は戦われないまま5分、または20分で **去る**（ゲージは400まで残る）。
  鎮めると **浄化**（10分、ゲージ0、魔物の経験値1.25倍）→ **静穏**。
- ゲージはアストリアのデータ（`eternalrealm_field_threats.dat`）に保存。再起動時の状態はすべて静穏（顕現中だったフィールドは800から）。

## 災厄（`FieldThreats.Calamity`）
- 各フィールド1体。顕現後、誰かが巣から56ブロック以内に来ると、巣（半径20+縁2）を中央値の高さに平らにした「爪痕」（フィールドごとの地面ブロック、縁は石レンガ）に変え、ボス戦を始める（`BossFight`、ノーマル、2人以上として調整）。
- 近くにいる人は自動で参加（ボスHUDと戦功ランキング）。戦闘不能・被ダメージ・与ダメージはダンジョンのボス戦と同じく記録。
- 報酬: 与ダメージ3%以上（または殊勲）の全員に、そのフィールドのボスの魂1（殊勲2）・強化石（評価で2〜5）・強敵の素材1・装備（50%、殊勲は確定でレア以上）・花びら（35%）・経験値・ゴールド。結果はクリア報酬画面（災厄討伐）。
- 体は現在ダンジョンのボス（b1〜b8）を流用し、名前は災厄ごと（例: 草原を呑む影）。

## 画面
- ミニマップの下: 今いるフィールドの瘴気ゲージ（兆しは赤く点滅、顕現中は災厄の名前、浄化中は残り時間）。ヌシ討伐の結果（戦功の順位・割合・獲得物）。
- 霧: 兆し・顕現中のフィールドでは紫に濃くなる。
- 地図: 出現中のヌシ（紫の菱形）、災厄の巣（目覚めると赤く脈打つ）。地図上部の「討伐手配書」で全フィールドの一覧。
- 告知（全員）: 兆し・顕現・鎮圧・去る・浄化。ヌシの出現と討伐は近くの人に。
