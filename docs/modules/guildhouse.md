# ギルドハウス（guild houses）とギルド門の広場

オーナーの依頼（2026-11-11）:「ギルドハウスというものを購入できるようにして。（中略）それぞれの大きさやクオリティで値段を分けて。」
「ギルドハウスのテーマはひとつも被らないようにして。」「細かいテクスチャとシステム、ギミックに力を入れて高クオリティのものを提出してください。」

王都の **ギルド門の広場**（Guild Gate Terrace）に、ギルドハウスの間取りごとの門が 20 基並ぶ。ギルドマスターが間取りを買うと、
そのギルドだけのギルドハウスが屋敷の次元（[estates.md](estates.md)）に建ち、**その間取りの門** をくぐったギルドの仲間だけが
**自分のギルドの** ハウスに入れる。ほかの人は門の光に押し返される。

## 1. ギルド門の広場（王都の地区 `guild_gates`、x −98..−10, z −86..−47）

城の崖の下、高架橋の西の二段のテラス。段の高さが間取りの段（tier）に対応する。

- **通りの壁**（z −49、通り `street_n1` に面する）: 段 1 の 4 基とドワーフの坑口。壁龕のベンチとランタン。中央の大階段（x −59..−49）の
  両脇を二筋の滝が落ちる。
- **下の広場**（上面 y 6）: 仲介人セレスタン（`npc.guild_estates`）の東屋、噴水、桜、ベンチ。西端に温室の門。東端は高架橋の西の欄干の
  通路（x −9..−6, z −54..−53）の着地点（x −10）で、そのまま広場に入れる。
- **上の壁**（z −65）: 段 3 と段 2 の 6 基。第二の大階段で
- **上の広場**（上面 y 12）: 段 4・段 5 の 8 基が崖を背に並び、中央にギルドの旗の大マスト。
- **地下回廊**: 高架橋の地上のアーチの奥。20 の門の色の旗、通りへの扉。

門はどれもその間取りの姿（芝屋根の玄関、紅天狗茸、竜の頭骨…）で、開口に **門の光**（`eternalrealm:guild_portal[axis, theme]`）が
揺らめく。銘板（看板）には間取りの名前・段の星・値段・「右クリック」。銘板を右クリック → カタログ画面がその間取りを開く。
スポット `guildgate.<id>` は光の面の中央・足の高さ、向き = 門に入るときの向き。

## 3. 買う・模様替え・売る（`GuildHouseService` / `GuildHouses`）

- **買う**: ギルドマスターだけ。ギルドにつき 1 軒。支払いは **基金から先に**、足りない分をマスターの所持金から。買うとすぐ建築が
  始まり（屋敷の核）、建ち終わるとギルド全員に知らせが届く。広場（仲介人か門の銘板）でだけ買える。
- **模様替え**: マスターだけ。高い間取りへは差額を払い、安い間取りへは差額の **50 %** が基金に戻る。古いハウスは新しいハウスが建つまで
  使え、建ち終わると保管物は同じ名前の家具へ移る（[estates.md](estates.md) §4）。
- **売る**: 値段の 50 % が基金へ。ハウスの中の人は外へ、残った物はギルドの預かり品へ。
- **基金**: 誰でも寄付できる（所持金から）。上限は財布と同じ。
- **ギルドの解散**: ハウスは手放され、基金と売値の半分は最後のマスターへ（オンラインなら所持金、いなければ郵便）。
- 保存: `guild_houses.json`（間取り・基金・ひとこと・メモ・保管の記録 200 件）。

## 4. 門をくぐる（`GuildGates`）

- 光に入る → **その間取りを持つギルドの仲間** なら、門の前（外向き）を戻り先に記録して自分のギルドのハウスの `entry` へ。
- ちがう人は門の光にそっと押し返され、理由が表示される: ギルドに入っていない／ギルドがハウスを持っていない／
  あなたのギルドのハウスは別の門（間取りの名前を表示）。
- 建築中は進み具合（%）を表示して押し返す。2 秒のクールダウンで往復のループを防ぐ。
- **テスト用**: 見学パスを持つ人（`/er admin test unlock`、[testkit.md](testkit.md)）は、自分のギルドが持っていない間取りの門から
  その間取りの **見学用のハウス**（どのギルドのものでもない）へ入る。まだなければ建てはじめ、進み具合を表示して押し返す。
  見学用のハウスでは集合の鐘は誰も呼ばず、金庫は見学者に開き、出し入れは記録しない。
- ハウスの中の **帰りの門** に入る → 来た場所（広場の門の前）へ。中に入ってよいかは 0.5 秒ごとに屋敷の核が確かめる（ギルドを抜けた人は外へ）。

## 5. ハウスの中のしかけ

- **ギルド掲示板**（`eternalrealm:guild_board`、壁の 3×2）: ギルド名・**今日のひとこと**（マスターと幹部が書く）・メモ（一人 2 枚、
  全体 16 枚）が板にそのまま描かれる。右クリックで画面: 掲示板・**出し入れの記録**（誰が何を何個、金庫の印付き）・メンバー。
  ハウスに入るとタイトルにギルド名、サブタイトルにひとこと。
- **共有の保管**: `chest.*` は仲間全員、`vault.*`（赤い掛け金のトラップチェスト）はマスターと幹部だけが開ける。チェストを閉じたときに
  出し入れを品目ごとに記録する（同時に開いている人の分は差し引く）。
- **練習用の案山子**（`eternalrealm:training_dummy`）: 剣でもスキルでも矢でも、当てると揺れて音が鳴り、そのダメージが頭上に浮かぶ。
  アクションバーに今の一連の攻撃の回数・合計・毎秒ダメージ（5 秒何もしなければ区切り）。倒れず、動かず、ランキングには数えない
  （ヒットをすべて断るので戦闘のコードは何も数えない）。見た目は藁・甲冑・的の 3 種。
- **集合の鐘**: 仲間が鳴らすと、オンラインのギルド全員に「○○さんが△△の集合の鐘を鳴らした！」と鐘の音（ギルドごとに 1 分に 1 回）。
- **作業台・かまど・金床・醸造台・魔法台・機織り機…** はそのまま使える。額縁と防具立ては記念品と装備を飾れる（模様替えでも引っ越す）。
- そのほか間取りごとのしかけ: 噴水（温室・離宮・宮殿・天空の神殿）、ボタンで開く鉄扉の宝物庫（ドワーフ）、溶岩の幕、
  胞子の花、ガラスの管の階段で降りる海底のドーム（珊瑚）、螺旋階段（大樹・魔導の塔）、煙を上げる煙突と火口、時計塔、
  望遠鏡のドーム、太陽系儀、浮かぶ水晶など。

## 7. 間取りを作る（`tools/estates/guild/`）

```
python3 tools/estates/guild/build.py                  # 20 軒を作って書き出し・検査・大きさを designs.json へ・サムネイル
python3 tools/estates/guild/build.py great_tree --no-thumbs --views great_tree_hall --scale 0.6
python3 tools/estates/build.py                        # 屋敷の全間取り（客室も）を作って書き出し・検査
python3 tools/capital/build.py                        # 広場と門（王都）
```

- 各間取りは浮島の上に建つ（ローカル y 0 = 屋敷の次元の y 100、日は西から）。帰りの門は `_gate_kit` の同じ門を島の西に建てる。
- 検査: 屋敷の核の検査（スポット・保管家具の名前・階段など）＋ `build.py` の検査（チェストの蓋の上がふさがっていない、掲示板の
  後ろに壁・前が空いている、出口の隣に門の光）。段ごとの数は `hkit.REQUIRED`。
- プレビュー: `tools/estates/previews/<id>_arrive|_aerial|<部屋>.png`、カタログのサムネイルは
  `textures/gui/guildhouse/<id>.png`（128×72）。

## 決定事項（Decisions）

- **門は間取りごと、ハウスはギルドごと**: 王都に 20 基の門だけを置き、ギルドのハウスは屋敷の次元の別々の区画に建てる。何十のギルドが
  同じ間取りを買っても、門をくぐった人は自分のギルドのハウスに着き、ほかのギルドとは会わない。
- **広場の段 = 間取りの段**: 安い門は通りから、豪華な門ほど上の段に。歩くだけで格の違いが分かる。
- **帰りの門は王都の門の双子**: 入ってきた門がそのままハウスの島に立っていて、くぐれば戻れる。
- **保管は世界の中の本物のチェスト**（屋敷の核の方式）: 金庫は名前（`vault.*`）で区別し、権限と記録だけをこのモジュールが足す。
- **案山子はヒットを断る**: ダメージを受けないことで、ランキングの与ダメージや吸血などの戦闘効果がいっさい動かない。数字は自分で出す。
- **屋根瓦を新しく作った**: 既存の素材では急な屋根が「使えない階段」になるため、名前に roof を含む屋根専用のブロックを 6 種描いた。
- **値段と大きさは designs.json 一つに**: 間取りを建て直すと大きさが自動で書き戻り、段の広さが逆転すると検査で止まる。
