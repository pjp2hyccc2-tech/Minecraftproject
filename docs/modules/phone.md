# 魔導スマホ（`social.phone` / `social.phone.forge` / `client.phone` / `ui.phone`）

2026-11-13 のオーナーの依頼「ファンタジー風の見た目のスマホをつくってフレンドと連絡を取り合ったり、スクショを投稿したり、
ゲーム内SNSも作って」。P キー（または冒険手帳の「魔導スマホ」ボタン）で開く、黒檀と金のスマホ。ゲームは止まらない。

## 1. 見た目と操作（`ui.phone.PhoneScreen`・`PhoneArt`）

- 168×280 の本体（黒檀に紫の艶、金の縁、四隅のサファイア、上に水晶のレンズ、下にルーンのホームボタン）。小さな窓では全体を
  縮める（マウスは本体の座標に直す）。画面の上に時刻（ゲーム内の時刻・☀/☾）と魔力のアンテナ。
- **ホーム**: 月夜の城の壁紙、大きな時計とアストリア暦の日付、オンラインのフレンド数、5つのアプリ（未読などのバッジ付き）。
- 操作: クリック、ホイールでスクロール、Enter で送信、Backspace（入力していないとき）で戻る、ホームボタンでホームへ、P か Esc で閉じる。
  削除・ブロック・フレンド解除は2回押し（1回目で「もう一度押すと実行します」）。
- 素材は `tools/art/phone.py`（`textures/gui/phone/phone.png`、512×512。[ART.md](../ART.md)）。

## 2. アプリ

| アプリ | できること |
|---|---|
| フレンド | 名前で申請（このサーバーで遊んだことのある人ならオフラインでも）、届いた申請の承認／拒否、フレンド一覧（オンラインが上、未読数）、メッセージへ、フレンド解除、申請中・ブロック中の一覧とブロック解除 |
| メッセージ | 会話の一覧（最後の一言・時刻・未読数）、＋で宛先を選ぶ。会話: 自分は右の金の吹き出し、相手は左の青の吹き出し、写真はタップで大きく。写真ボタンで撮った写真を添付。ヘッダーの「ブロック」 |
| カメラ | 「撮影する」でスマホを閉じ、（「HUDを隠して撮る」なら HUD を消して）今の景色を撮ってまた開く。「スクリーンショットにも保存」で F2 と同じ保存も。撮った写真（最新8枚）から選んで「投稿する」「フレンドに送る」 |
| つぶやき | サーバー全体の掲示板。みんな／フレンド／自分のタブ、8件ずつ「もっと見る」。投稿（280文字まで・写真1枚）、♥ いいね（もう一度で取り消し）、コメント（140文字まで）、自分の投稿・コメントの削除（投稿者は自分の投稿へのコメントも消せる） |
| お知らせ | 自分の投稿へのいいね・コメント（最新30件）。開くとバッジが消える |

- チャットにも届く: 新しいメッセージ（「✉ 名前: 本文 [返信]」。その会話を開いていれば出ない）、フレンド申請（[承認] [拒否]）、
  フレンド成立、自分の投稿へのコメント（[見る]）。ログイン時に未読と申請があれば一行。いいねはバッジだけ（多すぎるため）。
- ブロック: フレンドと申請が消え、お互いに申請・メッセージができず、お互いの投稿・コメントが見えなくなる（写真も）。

## 3. 規則（`social.phone`、純粋・テストあり）

- 文字（`PhoneText`）: 書式コード（§）・制御文字・見えない書式文字（右から左への上書きなど）・壊れたサロゲートを消す。メッセージと
  コメントは1行、投稿は5行まで（空行は詰める）。メッセージ200・投稿280・コメント140文字まで（文字数はコードポイント）。
- フレンド（`FriendBook`）: 最大100人、届く申請は50件まで、ブロックは200人まで。相手から申請が来ていれば、こちらの申請でそのまま
  フレンドになる。名前は最後に見た名前（大文字小文字を問わず探せる。改名にも追従）。
- メッセージ（`Messages`）: フレンド同士だけ。会話ごとに最新60件。返信すれば既読、開けば既読。90日動きのない会話は消える。
- 掲示板（`Timeline`）: 最新500件、コメントは1件に50まで。お知らせは1人30件。
- 速さの上限（`PhoneRates`、再起動で戻る）: 投稿 30秒に1件（連続2件まで）・1日40件、コメント 5秒に1件、メッセージ 1秒に1件
  （連続6件）、いいね 0.5秒に1回、フレンド申請 12秒に1件（連続5件）・1日100件、写真 15秒に1枚・1日30枚。
- 写真（`PhotoRules`・`PhotoCodec`・`PhotoShelf`）: クライアントが 384×216 の JPEG（96 KB まで）にして 16 KB ずつ送る。サーバーは
  JPEG の頭と大きさ（640×480 まで。画素を読む前にヘッダーで確かめる）を確かめて読み、自分で JPEG に描き直して
  `<データ>/photos/<16桁の16進>.jpg` に置く（メタデータは残らない）。投稿かメッセージに1回だけ使える（2回目は送り直し）。
  15分使われない写真、投稿・メッセージが消えた写真は消える。最大400枚（古いものから）。見られるのは、ブロックし合っていない人の
  投稿の写真と、自分の会話の写真だけ。

## 4. サーバー（`social.phone.forge.PhoneService`・`PhoneCommands`）

- 保存: `<データ>/phone.json`（フレンド・申請・ブロック・名前・メッセージ・掲示板・お知らせ・写真の目録を1つの文書に。
  `AtomicFileStore`、1つ前の世代つき）。変わっていれば1分ごとに IO スレッドで、サーバー停止時にその場で。読めない（壊れて前の世代も
  ない）ときは空で始めて**保存しない**（ログに記録。ファイルはそのまま）。起動時に目録にない写真ファイルを消す。5分ごとに不要な写真と
  古い会話を片付ける。
- 開いているスマホが見ている画面を覚え、相手の操作（メッセージ・いいね・コメント・投稿）があればその場で送り直す。閉じていれば
  バッジだけ（UI チャンネル `phone.badges`）。
- コマンド: `/phone`（ホーム）、`/phone friends|messages|feed|activity`、`/phone chat <名前>`、`/phone post <番号>`、
  `/phone accept|decline <名前>`（チャットのボタン）、`/phone admin delete <投稿> [コメント]`（権限2。モデレーターはスマホの画面でも
  全員の投稿とコメントに削除ボタンが出る）。
- 通信は [NETWORK_PROTOCOL.md](../NETWORK_PROTOCOL.md) の付録（版 13: 写真のパケット2つ、UI チャンネルと操作）。

## 5. クライアント（`client.phone`）

- `ClientPhone`: 届いた画面（種類ごとの最新）、バッジ、トースト、`phone.open`。冒険手帳のボタンに待っている件数。
- `PhotoCache`: 写真はそれが画面に出たときにサーバーへ頼み（同時に4件まで、15秒で再試行）、別スレッドで JPEG を読んでテクスチャに。
  最近の32枚を保持。
- `Camera`: 撮影（スマホを閉じ、3フレーム待って画面を読み、HUD を戻す。縮小と JPEG は別スレッド）。最新8枚をログアウトまで保持。
- `Uploads`: 添付された写真を一度だけ送り、届いた番号で投稿やメッセージを送る。断られたらトーストで理由、本文は残る。
- キー: P（初期設定）。バニラの「ソーシャル設定」（P）は F9 へ移る（`KeyConflicts`、チャットで知らせる）。

## 6. テスト

- 単体: `PhoneTextTest`（書式・制御・見えない文字・改行・文字数・名前）、`FriendBookTest`（申請・承認・同時申請・拒否・解除・
  ブロック・上限・名前・保存）、`MessagesTest`（既読・未読・一覧・60件・90日・保存）、`TimelineTest`（いいね・お知らせ・コメントの
  上限と削除の権限・投稿の削除・掲示板の絞り込みとページ・500件と写真・保存）、`PhotoTest`（番号・JPEG と大きさ・分割の受信・
  目録の片付けと上限）、`PhotoCodecTest`（スクショ→384×216 JPEG・切り抜き・壊れたもの／大きすぎるものは断る）、`PhoneDataTest`
  （写真を見られる人・文書の往復・壊れた文書）、`PhoneViewTest`（バッジ・オンライン順・ページとブロック・会話）、`PhoneRatesTest`。
- GameTest `PhoneGameTests`: 偽プレイヤー3人で、名前での申請と承認、メッセージ（書式コードは消える）と既読、知らない人は送れない、
  投稿・いいね・コメント・お知らせ、ブロックで見えなくなり送れなくなる、不正な引数（知らない画面・操作・パスのような写真番号）。
- **未確認**（実機が必要）: 画面の見た目と文字の収まり（日本語・英語・GUI スケール）、写真の撮影から投稿・送信・表示までの流れ、
  2人でのメッセージとお知らせの即時の反映、チャットのボタン、P キーの移動、写真の読み込みの速さ。
