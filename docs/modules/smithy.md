# 鍛冶屋（`item.forge.SmithService` / `ui.screen.SmithScreen`）

鍛冶師ゴランに話しかけると開く専用画面。狩りゲームの加工屋のように「左で選ぶ → 真ん中で比べる → 右で必要なものを確かめて押す」の
3列で、何がどれだけ上がるか・何が足りないかが一目で分かる。

| タブ | 左 | 真ん中 | 右 |
|---|---|---|---|
| 強化 | 持っている装備（手に持つ物・盾・着ている防具が先頭、E 印） | 大きなアイコン・名前・種類・必要Lv、攻撃力（防具は防御力と最大HP）と強化ボーナスの **今 → 強化後（緑）**、強化段階の10個の目盛り（次の段が点滅）、成功率のバー、平均試行回数、「失敗しても段階は下がらない」、付加効果 | 素材ごとに「所持 / 必要」（足りれば緑・✔、足りなければ赤・✘）、費用と所持金、「強化する」 |
| 生産 | ティアごとの生産リスト（作れる物は緑の点、必要Lvに届かないティアは灰色） | 完成品の性能・必要Lv・レア度の決まり方 | 同上、「生産する」 |
| 再錬成 | 付加効果のある装備 | 今の付加効果と説明 | 同上、「再錬成する」 |

- 押せないときはボタンの上に理由（素材不足・所持金不足・レベル不足・最大段階など）。
- 結果は画面中央の帯で表示: 成功は金色の帯と火花「強化成功！ +4」、失敗は暗い赤の帯が揺れる「強化失敗…」、生産・再錬成も帯で。
- 画面の数字はすべてクライアントが自分の持ち物と純粋なルール（`Enhancement` / `Reroll` / `Crafting` / `EquipmentStats`）から計算する。
  サーバーへは意図だけを送り（UIアクション `smith.enhance` / `smith.reroll` {slot, id}、`smith.craft` {recipe}）、サーバーが
  装備がまだその場所にあるか（スロット番号と装備の固有ID）・素材・所持金・レベルを**もう一度検査してから**消費する。
  スロット番号: 0〜35 持ち物、36〜39 着ている防具（足・脚・胴・頭）、40 オフハンド。
- サーバー → クライアント: UIチャンネル `smith`（画面を開く、`{"npc"}`）、`smith_result`（`{"kind", "outcome", "plus", "name"}`）。
- **未確認**（実機が必要）: 画面の見た目と大きさごとの収まり、スクロール、結果の帯、装備中の防具の強化が反映されること。
