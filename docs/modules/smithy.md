# 鍛冶屋（`item.forge.SmithService` / `ui.screen.SmithScreen`）

鍛冶師ゴランに話しかけると開く専用画面。狩りゲームの加工屋のように「左で選ぶ → 真ん中で比べる → 右で必要なものを確かめて押す」の
3列で、何がどれだけ上がるか・何が足りないかが一目で分かる。

| タブ | 左 | 真ん中 | 右 |
|---|---|---|---|
| 強化 | 持っている装備（手に持つ物・盾・着ている防具・身に着けた装身具が先頭、E 印） | 大きなアイコン・名前・種類・必要Lv、攻撃力（防具は防御力と最大HP）と **ステータス％（STR％ +33 → +36.3 など。強化1段ごとに自分の+10%）**、強化ボーナスの **今 → 強化後（緑）**、強化段階の10個の目盛り（次の段が点滅）、成功率のバー、平均試行回数、「失敗しても段階は下がらない」、付加効果（倍率込みの値） | 素材ごとに「所持 / 必要」（足りれば緑・✔、足りなければ赤・✘）、費用と所持金、「強化する」 |
| 生産 | ティアごとの生産リスト（作れる物は緑の点、必要Lvに届かないティアは灰色）。各ティアの後とLv50以降に **装身具の段階の見出し**（押すと開閉。初めは作れるいちばん上の段階だけ開く） | 完成品の性能（装身具はステータス％と上乗せ）・必要Lv・レア度の決まり方 | 同上、「生産する」 |
| 再錬成 | 付加効果のある装備 | 今の付加効果と説明 | 同上、「再錬成する」 |

- 押せないときはボタンの上に理由（素材不足・所持金不足・レベル不足・最大段階など）。
- 結果は画面中央の帯で表示: 成功は金色の帯と火花「強化成功！ +4」、失敗は暗い赤の帯が揺れる「強化失敗…」、生産・再錬成も帯で。
- 画面の数字はすべてクライアントが自分の持ち物と純粋なルール（`Enhancement` / `Reroll` / `Crafting` / `EquipmentStats`）から計算する。
  サーバーへは意図だけを送り（UIアクション `smith.enhance` / `smith.reroll` {slot, id}、`smith.craft` {recipe}）、サーバーが
  装備がまだその場所にあるか（スロット番号と装備の固有ID）・素材・所持金・レベルを**もう一度検査してから**消費する。
  スロット番号: 0〜35 持ち物、36〜39 着ている防具（足・脚・胴・頭）、40 オフハンド、41〜46 身に着けた装身具
  （`TrinketSlots.Slot` の保存順: 飾1・飾2・守1・飾3・飾4・守2。強化・再錬成のあと枠へ書き戻し、能力を計算し直して画面へ送る）。
- 装身具の工房（`Trinkets`、156個）のレシピは `Recipes.trinketRecipes()`。中身と値段は `docs/modules/armory.md` の「装身具の工房」。
- サーバー → クライアント: UIチャンネル `smith`（画面を開く、`{"npc"}`）、`smith_result`（`{"kind", "outcome", "plus", "name"}`）。
- **未確認**（実機が必要）: 画面の見た目と大きさごとの収まり、スクロール、結果の帯、装備中の防具の強化が反映されること、
  装身具の見出しの開閉と、身に着けた装身具の強化・再錬成が枠とキャラクター画面に反映されること。
