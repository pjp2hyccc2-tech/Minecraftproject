## 4. 手動テスト手順（Phase 1）

1. ワールド作成直後、左上HUDが「読み込み中…」→「Lv. 1」と EXPバーに変わる
2. ゾンビ等の敵対Mobを倒すと EXP が増える（ゾンビ=20）。レベルアップ時に金色のメッセージと効果音、HUDに未割り振りポイント表示
3. `K` でキャラクター画面。ポイントがある時だけ「+」が押せる。押すと数値が増え、ポイントが減る。Shift+クリックで最大10
4. コマンド: `/er character`、`/er admin exp add @s 5000`、`/er admin level set @s 10`、`/er admin stats reset @s`、`/er admin status`、`/er admin save`、`/er admin backup`
5. 「セーブして終了」→ 再度ワールドを開く → レベル・EXP・割り振りが同じ（**再ログイン後もデータが残る**）
6. `saves/<ワールド>/eternalrealm/` に JSON、`eternalrealm_backups/` に zip ができている
7. 破損テスト（ワールドを閉じた状態で）: キャラクターJSONを壊す → 開くと `.prev` から復旧し `quarantine/` に移動。`.prev` も壊すと障害ID付きで切断され、ログに同じIDが出る
8. `serverconfig/eternalrealm-server.toml` の `maxLevel` をプレイ中に変更 → HUDの上限表示が変わる
9. MOD未導入のクライアントで専用サーバーに接続 → 拒否される

## 5. マルチプレイテスト（Phase 1）

1. 専用サーバー＋クライアント2台（オフラインモードなら別名）で接続
2. それぞれのHUDが自分のデータだけを表示する
3. 片方がレベルアップしても他方の表示は変わらない
4. 切断→即再接続でデータが巻き戻らない（ログアウト直後の再ログイン）
5. サーバー停止→起動後、両者のデータが残っている。停止ログに `Server stopping: queued ...` と `Player data flushed` が出る
6. 「+」ボタンを連打・Enter長押ししても切断されない（クライアント側で4回/秒に制限）

### 6.3 手動テスト手順（Phase 2）

準備: クリエイティブタブ「ETERNAL REALM」から4種の武器を取る（サバイバルなら `/give @s eternalrealm:iron_longsword` など）。
試し斬り用: `/summon iron_golem ~ ~ ~3 {NoAI:1b}`（HP100、反撃しない）

1. 武器を持って左クリック: 腕を振り、効果音、前方の敵に数字（ダメージ）が出る。連打でコンボ（画面左下に「コンボ 2/3」）、最終段は大きいダメージ
2. 武器を持ってブロックを左クリックしても壊れない（採掘道具ではない）。素手・バニラの剣では従来どおり
3. R を押し続ける → 照準の上に溜めゲージ、離すと強攻撃（オレンジの数字）。最大で「MAX」、自動で発動。コンボ中に R → 派生
4. 左Alt: 移動キーの方向へステップ（入力なしは後方）。照準の下のスタミナが減る。回避の瞬間にゾンビの攻撃を受けても「回避！」でダメージなし
5. Z: 武器スキル（片手剣=周囲2回、両手剣=周囲に大ダメージ、双剣=前方6連撃、槍=前方3連突き）。左下の表示がクールダウン秒数に変わる。CT中に押すと「スキルはクールダウン中です」
6. 右クリック長押し: ガード姿勢。ゾンビの攻撃を正面で受けるとダメージ軽減（「ガード」）、押した直後に受けると「パリィ！」（ダメージなし、ゾンビが後退し鈍足）。背後からは防げない。連打してもパリィは出にくい（0.8秒あける）
6b. オフハンドに食べ物や盾を持ち、武器を持ったまま右クリック → ガードになる（オフハンドは使われない）。しゃがみ＋右クリックで食べる／盾を構える。盾を構えている間は攻撃できない
7. ガードし続けてスタミナが尽きると「ガードブレイク！」（短時間行動不能）
8. Kキー（キャラクター画面）に戦闘値（攻撃倍率・最大HP補正・被ダメージ軽減・攻撃速度・クリティカル・スタミナ）。VIT を上げると最大HP（ハート）が増える。`/er character` にも表示
9. AGI を大きく上げる（`/er admin exp add @s 100000` → 割り振り）と通常攻撃が速くなる。LUK でクリティカル（黄色の「!」付き数字）が増える
10. 死亡→リスポーン後もハートの数（最大HP補正）が維持され、満タンで復活する。再ログイン後も体力が減らない
11. オプション → 操作設定 → ETERNAL REALM で R / 左Alt / Z を変更できる

### 6.4 マルチプレイテスト（Phase 2）

1. 2人で接続し、片方の攻撃の腕振り・効果音・パーティクルがもう片方に見える／聞こえる
2. ガード姿勢（武器を構える）が相手からも見える
3. ダメージ数値は攻撃した本人にだけ表示される
4. サーバー設定 `pvp=false` では武器の攻撃がプレイヤーに当たらない。`pvp=true` では当たり、相手のガード・パリィ・回避が効く
5. 片方が高速で連打しても切断されない（正規の入力はレート制限内）

## 17. 魔導スマホ（2026-11-13、[modules/phone.md](modules/phone.md)・DECISIONS D-PHONE）

|---|---|
| Unit `PhoneTextTest` / `FriendBookTest` / `MessagesTest` / `TimelineTest` | 文字の掃除と長さ、申請・承認・ブロック・上限・改名、既読と未読・件数・古い会話、いいね・コメント・削除の権限・掲示板の絞り込み・保存 |
| Unit `PhotoTest` / `PhotoCodecTest` | 写真番号・JPEG と大きさ・分割の受信（順番・大きさ）・目録の片付け、スクショ→384×216 JPEG・壊れたもの／大きすぎるものは断る |
| Unit `PhoneDataTest` / `PhoneViewTest` / `PhoneRatesTest` | 写真を見られる人・文書の往復と壊れた文書、画面の文書（バッジ・順・ページ・ブロック）、速さと1日の上限 |
| GameTest `PhoneGameTests` | 名前での申請と承認、メッセージと既読、知らない人は送れない、投稿・いいね・コメント・お知らせ、ブロック、不正な引数 |

手動（クライアント2つ、またはLANで2人）:

1. P で開く → ホーム（時計・日付・5つのアプリ）。Esc／P で閉じる。冒険手帳に「魔導スマホ」ボタン。P がバニラの「ソーシャル設定」と重ならない（チャットに移動の知らせ）
2. フレンド: 名前を入れて申請 → 相手のチャットに［承認］［拒否］、スマホのフレンドに「届いた申請」。承認 → 両方のフレンドに出る（オンラインが上）
3. メッセージ: 送る → 相手のチャットに「✉ 名前: 本文［返信］」、メッセージのバッジ。相手が会話を開いていればその場で吹き出しが増え、チャットには出ない
4. カメラ: 撮影する → スマホが消えて HUD なしで撮り、また開く。写真を選んで「投稿する」→ つぶやきに写真付きで出る。「フレンドに送る」→ 宛先を選んで会話に写真

6. ブロック: 会話のヘッダーの「ブロック」（2回押し）→ フレンドから消え、お互いの投稿が見えない。ブロック中から解除
7. サーバーを再起動 → フレンド・会話・投稿・写真が残る。`/phone admin delete <番号>`（OP）で投稿が消える
