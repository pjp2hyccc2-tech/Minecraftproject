# 開発ロードマップ

2.0追加仕様の実装優先順位を採用しています（判断: DECISIONS.md D-007）。各フェーズは
**実装 → コンパイル → ユニット/統合テスト → 起動テスト → マルチプレイテスト → 修正 → コードレビュー → ドキュメント更新**
を完了するまで「完了」としません。

## 次の作業（Phase 0〜1 の完了に必要なこと）

1. 実環境で `./gradlew build` と `./gradlew runGameTestServer`（GitHub Actions でも可）
2. `./gradlew runClient` で手動テスト（TEST_PLAN.md の Phase 1 チェックリスト）
3. 専用サーバー＋クライアント2台でマルチプレイテスト
4. 見つかった問題の修正 → 再テスト → Phase 1 完了レビュー
5. Phase 2（戦闘）の詳細設計レビュー
